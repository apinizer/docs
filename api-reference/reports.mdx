## Endpoints

- [API Report](/api-reference/reports/api-report) - Inventory of all API Proxies and API Proxy Groups
- [Organization API Data Model Access Report](/api-reference/reports/organization-api-data-model-access-report) - Organization-level API and data model access report
- [Run Report Generator Report](/api-reference/reports/run-report-configuration) - Runs a saved Report Generator report of a project and returns its rows as JSON
- [Run Saved Query on Traffic Log](/api-reference/reports/search-saved-query) - Runs a saved Query of a project on the traffic log of an environment and returns the matching records, paged

The endpoints on this page are **inventory** reports: what exists and who may reach it. For **consumption** — how many tokens, how much cost and how much quota headroom a subject used in a period — see the [Usage Reports API](/api-reference/usage-reports).

## Authentication

All endpoints require authentication using a Personal API Access Token.

## Permissions

| Endpoint | Backend requirement |
|----------|---------------------|
| API Report | **System admin (`sysAdmin`)** or **system analyzer (`sysAnalyzer`)** |
| Organization API Data Model Access Report | **System admin (`sysAdmin`)** or **system analyzer (`sysAnalyzer`)** |

:::note
A token of any other user receives `401`.
:::
