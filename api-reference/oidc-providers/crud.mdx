## Overview

This section contains endpoints for creating, reading, updating, and deleting OIDC identity providers. All operations identify the provider by its **name** within the project — there is no id-based lookup on this surface.

## Endpoints

- [List OIDC Providers](/api-reference/oidc-providers/crud/list-oidc-providers) - Get all OIDC providers for a project
- [Get OIDC Provider](/api-reference/oidc-providers/crud/get-oidc-provider) - Get detailed information about a specific OIDC provider
- [Create OIDC Provider](/api-reference/oidc-providers/crud/create-oidc-provider) - Create a new OIDC provider
- [Update OIDC Provider](/api-reference/oidc-providers/crud/update-oidc-provider) - Update an existing OIDC provider
- [Delete OIDC Provider](/api-reference/oidc-providers/crud/delete-oidc-provider) - Delete an OIDC provider
