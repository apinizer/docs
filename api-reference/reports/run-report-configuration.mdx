---
title: "Run Report Generator Report"
description: "Runs a saved Report Generator report of a project by name and returns its headers, rows and Total row as JSON, with the same result as Try it on the report screen."
---

## Endpoint

```
POST /apiops/projects/{projectName}/reports/report-configurations/{reportName}/run
```

The report runs with its saved settings, exactly as **Try it** on the report screen. Nothing is saved, mailed or triggered.

## Authentication

Requires a Personal API Access Token whose user holds **Analytics / Manage** permission in the project named in the path. A project the caller cannot see answers `404`.

A platform-scoped (administration) token has no project to read and is refused with `400 malformedRequest`.

### Header

```
Authorization: Bearer YOUR_TOKEN
Content-Type: application/json
```

## Request

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Name of the project that owns the report |
| reportName | string | Yes | Exact name of the report |

### Request Body

The body is optional.

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| limit | integer | No | 20 | Highest number of data rows returned. At most 200. The limit is lower when the record limit of the Reporting system settings is lower |

```json
{
  "limit": 50
}
```

### Notes

- Only a report of the project in the path is found. An unknown report, a report of another project and a global report (a report of the Administration project) answer `404`.
- The Total row is returned apart from the data rows and does not count against `limit`.

## Response

### Success Response (200 OK)

```json
{
  "reportName": "Daily proxy metrics",
  "reportType": "API_TRAFFIC_METRICS",
  "generatedAt": "2026-10-28T09:15:00Z",
  "status": "SUCCESS",
  "headers": ["API Proxy", "Success", "Blocked", "Error", "Total"],
  "rows": [["orders", "120", "2", "1", "123"]],
  "totalRow": ["Total", "120", "2", "1", "123"],
  "rowCount": 1,
  "truncated": false
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| reportName | string | Name of the report |
| reportType | string | Type of the report |
| generatedAt | string | Time of the run, ISO-8601 |
| status | string | `SUCCESS`, `NO_RECORDS` or `FAILURE` |
| errorMessage | string | Reason of the failure. Present only when `status` is `FAILURE` |
| headers | array | Column headers |
| rows | array | Data rows, each a list of strings |
| totalRow | array | Total row of a metric report. Absent for a report without a Total row |
| rowCount | integer | Number of data rows returned |
| truncated | boolean | `true` when the report has more rows than returned |

:::warning
A Logs report returns the columns it is configured with. These columns can include headers or bodies of requests and responses.
:::

## Error Responses

| Status | Description |
|--------|-------------|
| 400 | Platform-scoped token |
| 401 | Missing or invalid token |
| 404 | Unknown project, unknown report, report of another project or global report |
