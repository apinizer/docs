---
title: "Consumer Access Report"
description: "Lists, for each consumer, the API proxies and API proxy groups that the consumer may call, with the environments, the expiry of the grant and the disallowed endpoints. The report covers the projects that you may read."
---

## Endpoint

```
GET /apiops/reports/consumer-access
```

## Authentication

Requires a Personal API Access Token.

### Header

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | No | Only the consumers of this project. Use `admin` for the administration project |
| organizationCode | string | No | Only the consumers of the organization with this code |
| consumerKey | string | No | Only the consumer with this consumer key |
| search | string | No | Only the consumers whose username or full name contains this text. The match ignores case |
| page | integer | No | Zero-based page index. Default `0` |
| size | integer | No | Rows per page. Default `20`, capped at `200` |
| sort | string | No | `username` or `fullName`, followed by `,asc` or `,desc`. Default `username,asc` |

### Notes

- **Scope**: A System Administrator or a System Analyzer reads every project. A user with the project manager role reads the projects that the user belongs to. Any other user reads only the projects where the user holds the **Identity** permission at **View** or **Manage**.
- **Grant targets**: A grant whose API proxy or API proxy group is in a project that you may not read is not listed. `projectName` selects the consumers only. A grant on another project that you may read stays in the list, with its own `projectName`.
- **Expired grants** stay in the list, with their `expireTime`.
- **Sort**: Rows with the same sort value are ordered by `consumerKey`. Any other sort field answers `400 unsupportedSortField`, and `params` names the field and lists the supported ones.
- The rows of each consumer are the rows that [List Consumer Access](/api-reference/consumers/access/list-consumer-access) returns for it.

#### Row Fields

| Field | Type | Description |
|-------|------|-------------|
| projectName | string | Project of the consumer. `admin` for the administration project |
| consumerKey | string | Consumer key |
| username | string | Username of the consumer |
| fullName | string | Display name |
| email | string | Email address |
| enabled | boolean | Whether the consumer is enabled |
| organization | object | Organization of the consumer. Absent when the consumer has none |
| organization.code | string | Organization code |
| organization.nameDefault, organization.nameSecondary | string | Names of the organization in the default and in the secondary language |
| organization.parentOrganizationCode | string | Code of the parent organization, when it has one |
| apiProxies | array | API proxies that the consumer may call |
| apiProxies[].endpoints | array | Endpoints that the consumer may call. Each item has `name` (REST path or SOAP operation) and `httpMethod` |
| apiProxies[].reverseProxy | boolean | `true` for a Reverse Proxy. It forwards every path and method, so `endpoints` is not the full surface |
| apiProxyGroups | array | API proxy groups that the consumer may call |

Each grant row also has `name`, `type`, `projectName`, `expireTime`, `environments`, and `disallowedEndpoints` (API proxy) or `disallowedApiProxies` (API proxy group). The fields are the ones of [List Consumer Access](/api-reference/consumers/access/list-consumer-access). The report returns no secret value.

### Error Response (400 Bad Request)

```json
{
  "status": "FAILURE",
  "errorKey": "unsupportedSortField",
  "message": "error.unsupportedSortField",
  "params": {
    "field": "email",
    "supported": ["fullName", "username"]
  },
  "correlationId": "7f1c9e2a-8f43-4d2e-9a11-6b5d0c3e2f77"
}
```

### Error Response (401 Unauthorized)

`invalidToken` or `tokenExpired`. See [Common Contract](/api-reference/apiops-common-contract#error-keys).

### Error Response (403 Forbidden)

The user reads no project: the user is not a System Administrator or a System Analyzer, and holds no **Identity** permission in any project.

```json
{
  "status": "FAILURE",
  "errorKey": "permissionDenied",
  "message": "error.permissionDenied",
  "correlationId": "7f1c9e2a-8f43-4d2e-9a11-6b5d0c3e2f77"
}
```

### Error Response (404 Not Found)

`projectName` is unknown or outside the projects that you may read, or `organizationCode` is unknown. Both answer `resourceNotFound`, so the call does not reveal which project names exist.

## cURL Example

```bash
curl -X GET \
  "https://demo.apinizer.com/apiops/reports/consumer-access?projectName=Payments&organizationCode=FIN&sort=fullName,asc&size=50" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Permissions

- System Administrator or System Analyzer: every project.
- Any other user: the projects where the user holds **Identity** at **View** or **Manage**.
