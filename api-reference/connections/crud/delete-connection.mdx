---
title: "Delete Connection"
description: "Deletes an existing connection from a project. The connection is permanently removed and cannot be recovered."
---

## Endpoint

```
DELETE /apiops/projects/{projectName}/connections/{connectionName}/
```

## Authentication

Requires a Personal API Access Token.

### Header

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Headers

| Header | Value | Required |
|--------|-------|----------|
| Authorization | Bearer \{token\} | Yes |

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| connectionName | string | Yes | Connection name (must exist) |

### Query Parameters

None

### Request Body

This endpoint does not require a request body.

## Response

### Success Response (200 OK)

```json
{
  "status": "SUCCESS",
  "deploymentResult": {
    "success": true
  }
}
```

#### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| status | string | Response status: `SUCCESS` or `FAILURE` |
| deploymentResult | object | Deployment result (when connection was deployed to worker) |
| deploymentResult.success | boolean | Worker deployment success |

### Error Response (400 Bad Request)

```json
{
  "status": "FAILURE",
  "resultMessage": "Connection (name: my-email-connection) was not found!"
}
```

#### Common Causes

- Connection name does not exist
- Connection name is empty
- The connection is still in use (see below)

### Error Response (400 Bad Request) - connection in use

A connection that another record still uses is not deleted. The answer is `400` and `resultMessage` names the users:

```json
{
  "status": "FAILURE",
  "resultMessage": "The connection cannot be deleted because it is still used by: disk-alert (Alert, Project ops), weekly-report (Scheduled Report, Project ops) and 2 more. 1 more in other projects. See Used By on the detail page."
}
```

- The sentence names at most 5 records as `name (Type, Project P)`. `and N more` counts further records you may see.
- `N more in other projects.` and `N more you do not have permission to view.` count records that are not named.
- A system administrator sees every name. Any other user sees only the names of records in the project of the connection, on screens the user may view.
- The check covers Email, SNMP, Linux Script and database connection pools, and every other connection type of this page. These users count: alerts, scheduled reports, uptime monitors, anomaly detectors, quota alerts, promotion targets, database and LDAP authentication, SIEM, portal and general settings, environments, integration flows, DB-2-API and API proxy policies. An environment that uses the connection is named in the same sentence.
- If the usage cannot be read completely, the delete is refused as well. Retry the request.

### Error Response (401 Unauthorized)

```json
{
  "status": "FAILURE",
  "resultMessage": "Token is not valid!"
}
```


## cURL Example

```bash
curl -X DELETE \
  "https://demo.apinizer.com/apiops/projects/MyProject/connections/my-email-connection/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Full JSON Body Example

This endpoint does not require a request body.

## Permissions

- User must have **`CONNECTIONS` + `MANAGE`** permission in the project

## Notes and Warnings

- **Permanent Deletion**: Connection deletion is permanent and cannot be undone
- **Dependencies**: A connection that other records use is refused with `400`. Remove the connection from those records first
- **Case Sensitivity**: Connection names are case-insensitive
- **Deployment**: Connection is automatically removed from workers if it was deployed
- **References**: If other connections reference this connection, those references may break
