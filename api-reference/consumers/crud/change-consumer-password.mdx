---
title: "Change Consumer Password"
description: "Sets a new password for a consumer and redeploys it. On a consumer whose identity was carried over to an API client, this also rotates the secret of that client."
---

## Endpoint

```
POST /apiops/projects/{projectName}/consumers/{consumerKey}/actions/change-password
```

## Authentication

Requires a Personal API Access Token.

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| consumerKey | string | Yes | Consumer key, assigned by the installation. Returned as `consumerKey` by every consumer response |

### Request Body

```json
{
  "password": "NewSecurePassword123!"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| password | string | Yes | The new password. Stored encrypted and never returned. A blank value answers `400 malformedRequest` (`params.reason` = `required`) |

:::warning

A consumer that a live identity source manages (LDAP, OIDC, database or API sync) cannot be edited. The request answers `400 malformedRequest` with `params.reason` = `ldapManaged`. Change such a consumer in the identity source.

:::

## Response

`200 OK`.

The response is a [write response](/api-reference/apiops-common-contract#write-responses). `result` is the consumer. `runtimeDeployment.state` is `IN_SYNC` when every environment acknowledged the change, or `DEGRADED` when the change is stored but at least one environment did not acknowledge it. Do not retry a `DEGRADED` write; redeploy instead. `resourceVersion` is not returned.

## cURL Example

```bash
curl -X POST \
  "https://demo.apinizer.com/apiops/projects/MyProject/consumers/CONSUMER_KEY/actions/change-password" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "password": "NewSecurePassword123!" }'
```

## Permissions

- User must have **`IDENTITY` + `MANAGE`** permission in the project
- A project outside the scope of the caller answers `404 resourceNotFound`, never `403`
- The admin project has no consumers: a call on it answers `400 malformedRequest` (`params.reason` = `platformScopeNotSupported`)
