---
title: "List Consumers"
description: "Lists the consumers of a project, by username by default. You can filter by organization code, enabled flag and a username or full-name search, and sort by username, fullName or enabled."
---

## Endpoint

```
GET /apiops/projects/{projectName}/consumers
```

## Authentication

Requires a Personal API Access Token.

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| organizationCode | string | No | Only the consumers of this organization. An unknown code answers `404 resourceNotFound` |
| enabledOnly | boolean | No | `true` returns only enabled consumers |
| search | string | No | Case-insensitive contains-match on username and full name |
| page | integer | No | Zero-based page index. Default `0` |
| size | integer | No | Rows per page. Default `20`, capped at `200` |
| sort | string | No | `field,asc` or `field,desc`. Fields: `username`, `fullName`, `enabled`. Default `username,asc` |

## Response

`200 OK` with the [paged envelope](/api-reference/apiops-common-contract#pagination). Each item is a consumer:

| Field | Type | Description |
|-------|------|-------------|
| consumerKey | string | Immutable key of the consumer, assigned by the installation |
| username | string | Username of the consumer. Immutable |
| fullName | string | Display name |
| email | string | Email address |
| description | string | Description |
| enabled | boolean | Whether the consumer is enabled |
| organizationCode | string | Code of the organization of the consumer. Absent when the consumer belongs to none |
| expireDate | timestamp | Expiry of the consumer. Absent when the consumer does not expire |
| trafficLogDisabled | boolean | `true` when the traffic of the consumer is not written to the traffic-log connectors. Absent when never set |

No password, secret or token setting is ever returned.

## cURL Example

```bash
curl -X GET \
  "https://demo.apinizer.com/apiops/projects/MyProject/consumers?enabledOnly=true&sort=username,asc" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Permissions

- User must have **`IDENTITY` + `VIEW`** permission in the project
- A project outside the scope of the caller answers `404 resourceNotFound`, never `403`
- The admin project has no consumers: a call on it answers `400 malformedRequest` (`params.reason` = `platformScopeNotSupported`)
