## Endpoints

| Operation | Method | Endpoint | Description |
|-----------|--------|----------|-------------|
| [List](/api-reference/consumers/crud/list-consumers) | GET | `/consumers` | List the consumers of the project |
| [Get](/api-reference/consumers/crud/get-consumer) | GET | `/consumers/{consumerKey}` | Read one consumer |
| [Create](/api-reference/consumers/crud/create-consumer) | POST | `/consumers` | Create a consumer |
| [Update](/api-reference/consumers/crud/update-consumer) | PUT | `/consumers/{consumerKey}` | Update a consumer (JSON Merge Patch) |
| [Change Password](/api-reference/consumers/crud/change-consumer-password) | POST | `/consumers/{consumerKey}/actions/change-password` | Set a new password |
| [Delete](/api-reference/consumers/crud/delete-consumer) | DELETE | `/consumers/{consumerKey}` | Delete a consumer |
