## Overview

A consumer is the credential-based identity that calls your API proxies. This API is the write surface for consumers. It replaces the [Credentials API](/api-reference/credentials), which is deprecated and addresses the same records by username.

Every address is under `/apiops/projects/{projectName}` and follows the shared [Common Contract](/api-reference/apiops-common-contract): the stable error envelope, correlation IDs and bounded pagination.

## How the API behaves

- **Addressed by consumer key.** The installation assigns the `consumerKey` when you create the consumer. A create request that names a `consumerKey` is refused with `400 immutableField`. Use the `consumerKey` from the create response in every later path.
- **Create answers `201`** and a `Location` header with the address of the new consumer.
- **Update is a JSON Merge Patch.** A field that the body omits (or sends as `null`) keeps its stored value. Send an empty list or an empty string to clear a field. Send `"expireDate": null` to remove the expiry.
- **Some fields cannot change on an update.** `username` and `consumerKey` are immutable (`400 immutableField`). The password changes only with [Change Consumer Password](/api-reference/consumers/crud/change-consumer-password). The organization changes only with the [transfer action](/api-reference/consumers-and-applications#transfer-to-another-organization).
- **Identity-source consumers are read-only here.** A consumer that a live identity source manages (LDAP, OIDC, database or API sync) cannot be edited. The write answers `400 malformedRequest` with `params.reason` = `ldapManaged`. The same rule applies on the Manager screen. [Enable](/api-reference/consumers/crud/enable-consumer) and [Disable](/api-reference/consumers/crud/disable-consumer) are the exception: they are accepted on such a consumer.
- **Secret values are write-only.** No response returns a password or the value of a secret metadata entry.
- **Writes report the gateway push.** Every write stores the change, pushes it to the environments and answers with `runtimeDeployment`: `IN_SYNC` or `DEGRADED`. A `DEGRADED` write is stored. See [Write responses](/api-reference/apiops-common-contract#write-responses).

## Endpoints

### CRUD Operations

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/consumers` | [List Consumers](/api-reference/consumers/crud/list-consumers) |
| `GET` | `/consumers/{consumerKey}` | [Get Consumer](/api-reference/consumers/crud/get-consumer) |
| `POST` | `/consumers` | [Create Consumer](/api-reference/consumers/crud/create-consumer) |
| `PUT` | `/consumers/{consumerKey}` | [Update Consumer](/api-reference/consumers/crud/update-consumer) |
| `POST` | `/consumers/{consumerKey}/actions/change-password` | [Change Consumer Password](/api-reference/consumers/crud/change-consumer-password) |
| `POST` | `/consumers/{consumerKey}/actions/enable` | [Enable Consumer](/api-reference/consumers/crud/enable-consumer) |
| `POST` | `/consumers/{consumerKey}/actions/disable` | [Disable Consumer](/api-reference/consumers/crud/disable-consumer) |
| `POST` | `/consumers/{consumerKey}/actions/sync-match` | [Match Consumer to an Identity Source User](/api-reference/consumers/crud/sync-match-consumer) |
| `DELETE` | `/consumers/{consumerKey}` | [Delete Consumer](/api-reference/consumers/crud/delete-consumer) |
| `POST` | `/consumers/{consumerKey}/actions/transfer-organization` | [Transfer to another organization](/api-reference/consumers-and-applications#transfer-to-another-organization) |

### Secret material, JWK and token settings

Two read operations return the current state: [Get Consumer Token Settings](/api-reference/consumers/token-settings/get-consumer-token-settings) (`GET /consumers/{consumerKey}/token-settings`) and [Get Consumer Secret References](/api-reference/consumers/secrets/get-consumer-secrets) (`GET /consumers/{consumerKey}/secrets`). The second returns the name and scope of each reference, never the material.

Each reference below has a set operation (`PUT`, name in the path) and a remove operation (`DELETE`).

| Reference | Set | Remove |
|-----------|-----|--------|
| Secret key | [Set](/api-reference/consumers/secrets/set-consumer-secret-key) | [Remove](/api-reference/consumers/secrets/remove-consumer-secret-key) |
| Certificate | [Set](/api-reference/consumers/secrets/set-consumer-certificate) | [Remove](/api-reference/consumers/secrets/remove-consumer-certificate) |
| Public key | [Set](/api-reference/consumers/secrets/set-consumer-public-key) | [Remove](/api-reference/consumers/secrets/remove-consumer-public-key) |
| Private key | [Set](/api-reference/consumers/secrets/set-consumer-private-key) | [Remove](/api-reference/consumers/secrets/remove-consumer-private-key) |
| Keystore | [Set](/api-reference/consumers/secrets/set-consumer-keystore) | [Remove](/api-reference/consumers/secrets/remove-consumer-keystore) |
| Truststore | [Set](/api-reference/consumers/secrets/set-consumer-truststore) | [Remove](/api-reference/consumers/secrets/remove-consumer-truststore) |
| JWK for validation and signing | [Set](/api-reference/consumers/jwk-settings/set-consumer-jwk-validation) | [Remove](/api-reference/consumers/jwk-settings/remove-consumer-jwk-validation) |
| JWK for decryption and encryption | [Set](/api-reference/consumers/jwk-settings/set-consumer-jwk-encryption) | [Remove](/api-reference/consumers/jwk-settings/remove-consumer-jwk-encryption) |
| Token settings | [Set](/api-reference/consumers/token-settings/set-consumer-token-settings) | [Reset](/api-reference/consumers/token-settings/reset-consumer-token-settings) |

### Read-only sub-resources

The API clients and the limit assignments of a consumer are read on the [Consumers & Applications API](/api-reference/consumers-and-applications):

- `GET /consumers/{consumerKey}/api-clients`
- `GET /consumers/{consumerKey}/limit-assignments`

### Consumer roles

Roles live on a separate collection, `/consumer-roles`. See the [Consumer Roles API](/api-reference/consumer-roles).

### Consumer organizations

Organizations live on a separate collection, `/consumer-organizations`. See the [Consumer Organizations API](/api-reference/consumer-organizations).

## Permissions

| Operation | Required Permission |
|-----------|---------------------|
| List, Get, List Access, Get Token Settings, Get Secret References | `IDENTITY` + `VIEW` |
| Create, Update, Change Password, Enable, Disable, Match to an Identity Source User, Delete, Grant, Update and Revoke Access, secret material, JWK, token settings | `IDENTITY` + `MANAGE` |
