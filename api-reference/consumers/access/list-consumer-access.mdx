---
title: "List Consumer Access"
description: "Lists the API proxies and API proxy groups of the project that a consumer may call, by name."
---

## Endpoint

```
GET /apiops/projects/{projectName}/consumers/{consumerKey}/access
```

## Authentication

Requires a Personal API Access Token.

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| consumerKey | string | Yes | Consumer key, assigned by the installation. Returned as `consumerKey` by every consumer response |

## Response

`200 OK` with an array of access rows:

```json
[
  { "name": "MyAPI", "type": "API_PROXY" },
  { "name": "MyGroup", "type": "API_PROXY_GROUP", "expireTime": "2027-12-31T23:59:59.000Z" }
]
```

| Field | Type | Description |
|-------|------|-------------|
| name | string | Name of the API proxy or API proxy group |
| type | string | `API_PROXY` or `API_PROXY_GROUP` |
| expireTime | timestamp | Expiry of the grant, when set |

## Permissions

- User must have **`IDENTITY` + `VIEW`** permission in the project
- A project outside the scope of the caller answers `404 resourceNotFound`, never `403`
- The admin project has no consumers: a call on it answers `400 malformedRequest` (`params.reason` = `platformScopeNotSupported`)
