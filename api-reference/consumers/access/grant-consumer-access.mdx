---
title: "Grant Consumer Access"
description: "Grants a consumer access to every listed API proxy and API proxy group of the project. A target that is already granted is refused, never skipped silently."
---

## Endpoint

```
POST /apiops/projects/{projectName}/consumers/{consumerKey}/access
```

## Authentication

Requires a Personal API Access Token.

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| consumerKey | string | Yes | Consumer key, assigned by the installation. Returned as `consumerKey` by every consumer response |

### Request Body

```json
{
  "accessList": [
    { "name": "MyAPI", "type": "API_PROXY" },
    { "name": "MyGroup", "type": "API_PROXY_GROUP", "expireTime": "2027-12-31T23:59:59.000Z" }
  ]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| accessList | array | Yes | Targets to change. An empty or missing list answers `400 malformedRequest` (`params.reason` = `accessListRequired`) |
| accessList[].name | string | Yes | Name of an API proxy or API proxy group of the project |
| accessList[].type | string | Yes | `API_PROXY` or `API_PROXY_GROUP` |
| accessList[].expireTime | timestamp | No | Expiry of the grant. Used by grant |

An entry without `name` or `type` answers `400 malformedRequest` (`params.reason` = `nameAndTypeRequired`).

## Response

`200 OK` as a [write response](/api-reference/apiops-common-contract#write-responses). `result` is the access list of the consumer after the grant.

### Errors

| Status | Error key | Cause |
|--------|-----------|-------|
| 404 | resourceNotFound | A target is unknown in the project |
| 409 | lifecycleConflict | A target is already granted (`params.reason` = `accessAlreadyGranted`) |

:::warning

The targets are applied in order. A refusal leaves the targets before it granted. On a retry, send only the remaining targets.

:::

## cURL Example

```bash
curl -X POST \
  "https://demo.apinizer.com/apiops/projects/MyProject/consumers/CONSUMER_KEY/access" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "accessList": [ { "name": "MyAPI", "type": "API_PROXY" } ] }'
```

## Permissions

- User must have **`IDENTITY` + `MANAGE`** permission in the project
- A project outside the scope of the caller answers `404 resourceNotFound`, never `403`
- The admin project has no consumers: a call on it answers `400 malformedRequest` (`params.reason` = `platformScopeNotSupported`)
