---
title: "Credential Organizations API"
description: "The Credential Organizations API provides endpoints for managing organizational groupings of credentials. Organizations are identified by a stable code and can carry custom metadata that applies as defaults to credentials in the organization."
---

## Endpoints

### CRUD Operations

- [Create Credential Organization](/api-reference/credential-organizations/crud/create-credential-organization) - Create a new organization
- [Get Credential Organization](/api-reference/credential-organizations/crud/get-credential-organization) - Retrieve an organization by code
- [Update Credential Organization](/api-reference/credential-organizations/crud/update-credential-organization) - Update display names, parent, or metadata
- [Delete Credential Organization](/api-reference/credential-organizations/crud/delete-credential-organization) - Delete an organization

## Authentication

All endpoints require authentication using a Personal API Access Token.

## Permissions

### GET Operations

- User must have **`IDENTITY` + `VIEW`** permission in the project
- If the asset category does not exist, user must have **at least one permission** in the project

### POST/PUT/DELETE Operations

- User must have **`IDENTITY` + `MANAGE`** permission in the project

| Operation | Required Permission |
|-----------|---------------------|
| Get Credential Organization | `IDENTITY` + `VIEW` (or any permission if category doesn't exist) |
| Create/Update/Delete Credential Organization | `IDENTITY` + `MANAGE` |
