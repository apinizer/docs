## Endpoints

| Operation | Method | Endpoint | Description |
|-----------|--------|----------|-------------|
| [Create](/api-reference/credential-organizations/crud/create-credential-organization) | POST | `/credential-organizations/` | Create a new organization |
| [Get](/api-reference/credential-organizations/crud/get-credential-organization) | GET | `/credential-organizations/{code}` | Retrieve an organization by code |
| [Update](/api-reference/credential-organizations/crud/update-credential-organization) | PUT | `/credential-organizations/{code}` | Update names, parent, or metadata |
| [Delete](/api-reference/credential-organizations/crud/delete-credential-organization) | DELETE | `/credential-organizations/{code}` | Delete an organization |

Organizations are identified by a stable **`code`** (unique within the project). Custom metadata attached to an organization can serve as defaults for credentials assigned to that organization.
