---
title: "Create LLM Provider"
description: "Creates a new AI Gateway LLM provider in the specified project. This endpoint is an upsert: if a provider with the same name already exists, it is updated instead. The request body must include the polymorphic discriminator \"_class\": \"llm\"."
---

## Endpoint

```
POST /apiops/projects/{projectName}/llm-providers/{providerName}/
```

## Authentication

Requires a Personal API Access Token.

### Header

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Headers

| Header | Value | Required |
|--------|-------|----------|
| Authorization | Bearer \{token\} | Yes |
| Content-Type | application/json | Yes |

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| providerName | string | Yes | LLM provider name (must match the `name` field in the body) |

### Query Parameters

None

### Request Body

The body is a polymorphic `ConnectionConfigLlm` object. It **must** include `"_class": "llm"` — without this discriminator, deserialization fails.

#### Full JSON Body Example

```json
{
  "_class": "llm",
  "name": "deepseek-primary",
  "description": "DeepSeek production provider",
  "enabled": true,
  "providerType": "DEEPSEEK",
  "endpoint": "https://api.deepseek.com/v1",
  "apiVersion": "v1",
  "authScheme": "BEARER",
  "authHeaderName": "Authorization",
  "credentialSource": "GATEWAY",
  "apiKeyLocation": "HEADER",
  "apiKeyPrefix": null,
  "allowClientOverride": false,
  "apiKey": "sk-your-deepseek-api-key",
  "coldStartRetryEnabled": false,
  "onlyListedModels": false,
  "deploymentType": "CLOUD",
  "supportedModels": [
    {
      "modelId": "deepseek-chat",
      "displayName": "DeepSeek Chat",
      "contextWindow": 64000,
      "maxOutputTokens": 8192,
      "pricePerMillionInput": 0.27,
      "pricePerMillionOutput": 1.10,
      "capabilities": ["chat", "function_calling"],
      "modality": "TEXT",
      "enabled": true,
      "aclEnabled": false,
      "aclEntries": []
    }
  ],
  "metadata": [
    {
      "key": "team",
      "value": "platform",
      "secret": false
    }
  ]
}
```

#### Request Body Fields

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| _class | string | Yes | - | Polymorphic discriminator — must be `"llm"` |
| name | string | Yes | - | Provider name; must match `providerName` in the path (case-insensitive) |
| description | string | No | - | Free-text description |
| enabled | boolean | No | true | Whether the provider is active |
| providerType | string | No | - | Provider type enum constant (`OPENAI`, `ANTHROPIC`, `AZURE_OPENAI`, `BEDROCK`, `VERTEX`, `COHERE`, `MISTRAL`, `DEEPSEEK`, `GROQ`, `MOONSHOT`, `ZHIPU`, `QWEN_DASHSCOPE`, `XAI`, `GOOGLE_AI_STUDIO`, `TOGETHER`, `FIREWORKS`, `CEREBRAS`, `HUGGINGFACE`, `OPENROUTER`, `PERPLEXITY`, `NVIDIA_NIM`, `VLLM`, `OLLAMA`, `CUSTOM_OPENAI_COMPAT`, `VOYAGE`, `TYPESAFE`, `TEI`, `OTHER`) |
| endpoint | string | No | provider default | Base API URL; auto-filled from `providerType` when blank. Required for `TEI` (no default endpoint); `TYPESAFE` defaults to `https://api.typesafe.ai/v1` |
| apiVersion | string | No | provider default | Provider API version; auto-filled from `providerType` when blank |
| organizationId | string | No | - | Organization identifier (OpenAI `org-...`) |
| authScheme | string | No | provider default | Auth scheme enum constant (`BEARER`, `API_KEY_HEADER`, `BASIC`, `AWS_SIGV4`, `OAUTH2`, `NONE`, `CUSTOM`); auto-filled from `providerType` when null |
| authHeaderName | string | No | provider default | Credential header name; auto-filled from `providerType` when blank |
| apiKey | string | No | - | Primary auth secret (Bearer token, api-key). Encrypted at rest; never returned |
| apiSecret | string | No | - | Secondary auth secret (e.g. AWS SigV4 secretKey). Encrypted at rest; never returned |
| region | string | No | - | Region (e.g. Bedrock AWS region) |
| serviceAccountJson | string | No | - | GCP Vertex service-account JSON blob. Encrypted at rest; never returned |
| supportedModels | array | No | - | The models of the provider (see fields below) |
| coldStartRetryEnabled | boolean | No | - | Retry on 503 for self-hosted providers (vLLM/Ollama) |
| onlyListedModels | boolean | No | false | When `true`, the gateway refuses a model ID that is not in `supportedModels` (HTTP 403). `true` with an empty `supportedModels` list is rejected with 400. |
| deploymentType | string | No | auto | Deployment type enum constant (`CLOUD`, `ON_PREM`); auto-filled from `providerType` when null |
| metadata | array | No | - | Custom key/value metadata entries (see fields below) |

:::note `endpoint` and `apiVersion` runtime semantics

`endpoint` takes the **base address only** (e.g. `https://api.deepseek.com/v1`) — the request path
(`/chat/completions`, `/embeddings`, `/audio/transcriptions`, `/audio/speech`, `/images/generations`,
`/responses`) is appended automatically based on the request type. Putting a path in `endpoint`
produces a broken URL at request time; to set a custom path, use a
`providerType: OTHER` connection with its own path fields. A query string embedded in
`endpoint` is not lost, but it is relocated to the end of the resolved address, after the appended path.

`apiVersion` only reaches the request URL for `AZURE_OPENAI` connections, where it is added as an
`api-version` query parameter (skipped if one is already present). For `ANTHROPIC` it is sent as the
`anthropic-version` header instead and never touches the URL. Bedrock and Vertex build their address
entirely in provider-specific code, so `apiVersion` has no effect on either.

See [Query Strings and API Versioning in the Final URL](/en/ai-gateway/llm-providers#query-strings-and-api-versioning)
for the full behavior.

:::

:::caution Path snapshots are server-managed

`wireProtocol` and the six `default*Path` fields are the provider type's own, unless you set them on
the connection. They are **not writable** through this endpoint — values sent in the body are ignored,
and values omitted are preserved from the stored record rather than cleared. To use other paths,
create a connection with `providerType: OTHER`.

Paths support Apinizer variable resolution (`${env.name}`, `#{contextVar}`), resolved at request time
against the effective URL `endpoint` + path.

:::


#### Supported Model Fields

Each `supportedModels` row is one model of the provider.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| modelId | string | Yes | Model identifier (e.g. `deepseek-chat`) |
| displayName | string | No | Human-readable model name |
| contextWindow | integer | No | Maximum context window in tokens |
| maxOutputTokens | integer | No | Maximum output tokens |
| pricePerMillionInput | number | No | USD per 1M input tokens |
| pricePerMillionOutput | number | No | USD per 1M output tokens |
| pricePerMillionCached | number | No | USD per 1M cached input tokens |
| pricePerMillionCacheWrite | number | No | USD per 1M cache-write tokens (flat rate). A matching row in `cacheWritePricesByTtl` overrides this for its TTL |
| cacheWritePricesByTtl | array | No | Cache-write price per TTL — see [Cache-Write Price Fields](/api-reference/llm-providers/create-llm-provider#cache-write-price-cachewritepricesbyttl-fields) |
| contextTierPrices | array | No | Long-context price tiers — see [Context-Tier Price Fields](/api-reference/llm-providers/create-llm-provider#context-tier-price-contexttierprices-fields) |
| serviceTierPrices | array | No | Provider service-tier price multipliers — see [Service-Tier Price Fields](/api-reference/llm-providers/create-llm-provider#service-tier-price-servicetierprices-fields) |
| pricePerImage | number | No | USD per generated image |
| pricePerAudioMinute | number | No | USD per minute of audio (STT) |
| pricePerCharacterTts | number | No | USD per input character (TTS) |
| capabilities | array[string] | No | Capability tags, normalized on save — see [Capabilities Normalization](/api-reference/llm-providers/create-llm-provider#capabilities-normalization) |
| modality | string | No | Modality enum constant (`TEXT`, `VISION`, `AUDIO`, `EMBEDDING`, `RERANK`, `MULTIMODAL`, `IMAGE`) |
| enabled | boolean | No | `false` makes the gateway refuse the model with 403 and leave it out of `GET /v1/models` |
| aclEnabled | boolean | No | `true` limits the callers of the model to the subjects in `aclEntries` |
| aclEntries | array | No | Consumers, applications and organizations allowed to call the model — see [Model Access Control Fields](/api-reference/llm-providers/create-llm-provider#model-access-control-aclentries-fields) |

#### Cache-Write Price (`cacheWritePricesByTtl`) Fields

One row per cache TTL the provider bills separately for (e.g. Anthropic prices a 5-minute cache
write at 1.25× input and a 1-hour cache write at 2× input). A row overrides
`pricePerMillionCacheWrite` for usage that reports that TTL.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| ttl | string | Yes | Short TTL label as the provider reports it — typically `"5m"` or `"1h"` |
| pricePerMillion | number | Yes | USD per 1M cache-write tokens at this TTL |

```json
"cacheWritePricesByTtl": [
  { "ttl": "5m", "pricePerMillion": 3.75 },
  { "ttl": "1h", "pricePerMillion": 6.00 }
]
```

#### Context-Tier Price (`contextTierPrices`) Fields

Long-context pricing: above `aboveTokens` prompt tokens, the **whole request** is priced at
`inputFactor` × the input price and `outputFactor` × the output price. When several tiers match,
the one with the highest `aboveTokens` threshold wins.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| aboveTokens | integer | Yes | Prompt-token threshold (input + cached + cache-write). The tier applies strictly **above** this value |
| inputFactor | number | Yes | Multiplier applied to the input price for the whole request |
| outputFactor | number | Yes | Multiplier applied to the output price for the whole request |

```json
"contextTierPrices": [
  { "aboveTokens": 200000, "inputFactor": 2.0, "outputFactor": 1.5 }
]
```

#### Service-Tier Price (`serviceTierPrices`) Fields

The gateway applies the row whose `tier` matches the `service_tier` value the provider echoed in
the response usage (e.g. OpenAI's `flex` / `priority`, or a request routed through a Batch API).

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| tier | string | Yes | Service tier enum constant: `BATCH`, `PRIORITY`, `FLEX` or `CUSTOM` |
| name | string | No | Provider-reported tier value to match, used only when `tier` is `CUSTOM` (e.g. `"scale"`); ignored for the fixed tiers |
| inputFactor | number | Yes | Multiplier applied to the input price when the provider echoes this tier |
| outputFactor | number | Yes | Multiplier applied to the output price when the provider echoes this tier |

```json
"serviceTierPrices": [
  { "tier": "BATCH", "name": null, "inputFactor": 0.5, "outputFactor": 0.5 },
  { "tier": "PRIORITY", "name": null, "inputFactor": 2.0, "outputFactor": 2.0 }
]
```

#### Model Access Control (`aclEntries`) Fields

One row per consumer, application or organization that may call the model. The rows apply only when
`aclEnabled` is `true`. Whoever may edit the provider may edit the access control of its models.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| subjectType | string | Yes | Kind of the subject: consumer, application or organization |
| subjectId | string | Yes | Identifier of the subject |
| subjectName | string | No | Name of the subject |
| organizationId | string | No | Identifier of the organization of the subject |
| organizationName | string | No | Name of the organization of the subject |

```json
"aclEnabled": true,
"aclEntries": [
  { "subjectType": "ORGANIZATION", "subjectId": "64f0c0ffee", "subjectName": "Payments", "organizationId": null, "organizationName": null }
]
```

#### Capabilities Normalization

`capabilities` is normalized on every save. The stored value never contains a legacy spelling.

**Known keys** (the values `capabilities` normalizes to): `function_calling`, `vision`,
`prompt_caching`, `reasoning`, `structured_output`, `streaming`, `web_search`.

**Aliases collapsed to a known key**: `tools`, `tool_use`, `tool_calling`, `function-calling` →
`function_calling`; `image_input`, `multimodal_input` → `vision`; `caching` → `prompt_caching`;
`json_mode`, `json_schema`, `response_schema` → `structured_output`; `search` → `web_search`.

**Dropped as modality noise** (already implied by the `modality` field, so it carries no extra
information): `chat`, `completion`, `text`, `embedding`, `embeddings`, `code`.

**Unknown values** are lower-cased, converted to `snake_case`, and kept as a custom tag.

For example, a request body sending `"capabilities": ["chat", "tool_use", "json_mode"]` is stored
as `["function_calling", "structured_output"]` — `chat` is dropped and both remaining values
collapse to their canonical key.

:::note Prices are optional
A model without a price counts as 0 in cost reports. A USD limit does not meter such a model.
:::

### Notes

- `_class` must be `"llm"` or the request fails to deserialize
- `name` must match `providerName` in the path (case-insensitive), otherwise a `400 Bad Request` is returned
- Fields left blank (`endpoint`, `apiVersion`, `authScheme`, `authHeaderName`, `deploymentType`) are auto-filled from the selected `providerType`

## Permissions

- User must have **`AI_DEVELOPMENT` + `MANAGE`** permission in the project

## Notes and Warnings

- **Upsert Semantics**:
  - If a provider with the same `name` already exists, it is updated (its internal ID is reused)
  - Otherwise a new provider is created
- **Polymorphic Discriminator**:
  - `"_class": "llm"` is mandatory in the body
- **Secret Fields (INV-06)**:
  - `apiKey`, `apiSecret` and `serviceAccountJson` are encrypted before persistence and never returned in read responses
- **Enum Serialization**:
  - Enum values (`providerType`, `authScheme`, `deploymentType`, model `modality`) must be sent as the enum constant name (e.g. `DEEPSEEK`, `BEARER`, `CLOUD`, `TEXT`), not lowercase
- **Automatic Defaults**:
  - Blank endpoint/apiVersion/authScheme/authHeaderName/deploymentType are auto-filled from the `providerType` default
- **Deploy on Save**:
  - The provider is encrypted and pushed to the AI Gateway workers as part of the save
