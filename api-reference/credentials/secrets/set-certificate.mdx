## Endpoint

```
PUT /apiops/projects/{projectName}/credentials/{username}/certificate/{certificateName}/
```

## Authentication

Requires a Personal API Access Token.

### Header

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Headers

| Header | Value | Required |
|--------|-------|----------|
| Authorization | Bearer \{token\} | Yes |

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| username | string | Yes | Username of the consumer |
| certificateName | string | Yes | Name of the certificate to assign |

### Notes

- Certificate must exist in the project or in the admin project
- Consumer must exist
- Only one certificate can be assigned to a consumer at a time
- Assigning a new certificate replaces the existing one if present

## cURL Example

```bash
curl -X PUT \
  "https://demo.apinizer.com/apiops/projects/MyProject/credentials/api-user/certificate/my-certificate/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Notes and Warnings

- **Certificate Requirements**:
  - Certificate must exist in the project or admin project
  - Certificate name is case-sensitive

- **Consumer Requirements**:
  - Consumer must exist
  - Consumer must be in the same project or accessible from the project

- **Replacement Behavior**:
  - Assigning a new certificate replaces any existing certificate
  - Previous certificate assignment is automatically removed

- **Automatic Deployment**:
  - Consumer is automatically deployed to all environments after certificate assignment
  - Deployment results are returned in the response

## Permissions

- User must have **`IDENTITY` + `MANAGE`** permission in the project
- For automatic deployment, user must also have **`IDENTITY` + `DEPLOY_UNDEPLOY`** permission
