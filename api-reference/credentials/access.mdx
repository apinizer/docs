## Endpoints

- [Get Granted Access List](/api-reference/credentials/access/get-granted-access-list) - Get list of users/organizations with access to a consumer
- [Grant Access](/api-reference/credentials/access/grant-access) - Grant access to a consumer to users or organizations
- [Revoke Access](/api-reference/credentials/access/revoke-access) - Revoke access to a consumer from users or organizations
