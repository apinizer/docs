title: "Mock APIs API"
description: "The Mock APIs API provides endpoints for listing, reading, and saving the Mock API definitions of a project. You can use them to move a Mock API to another project or another Apinizer installation."
---

## Endpoints

### CRUD Operations

- [List Mock APIs](/api-reference/mock-apis/crud/list-mock-apis) - List all Mock APIs of a project
- [Get Mock API](/api-reference/mock-apis/crud/get-mock-api) - Get the full definition of a Mock API
- [Create or Update Mock API](/api-reference/mock-apis/crud/save-mock-api) - Save a Mock API definition by name

## Authentication

All endpoints require authentication using a Personal API Access Token.

## Permissions

Read operations require **`API_CREATOR` + `VIEW`**. The write operation requires **`API_CREATOR` + `MANAGE`** permission in the project.

| Operation | Required Permission |
|-----------|---------------------|
| List / Get Mock API | `API_CREATOR` + `VIEW` |
| Create or Update Mock API | `API_CREATOR` + `MANAGE` |
