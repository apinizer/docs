---
title: "Delete Consumer Organization"
description: "Deletes a consumer organization. An organization that still has child organizations, consumers, applications or portal accounts answers 409 dependencyConflict."
---

## Endpoint

```
DELETE /apiops/projects/{projectName}/consumer-organizations/{code}
```

## Authentication

Requires a Personal API Access Token.

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| projectName | string | Yes | Project name |
| code | string | Yes | Code of the organization |

## Response

`204 No Content`, without a body.

### Errors

| Status | Error key | Cause |
|--------|-----------|-------|
| 400 | malformedRequest | An identity source manages the organization |
| 404 | resourceNotFound | The code is unknown |
| 409 | dependencyConflict | The organization still has child organizations, consumers, applications or portal accounts. `params.reason` names the blocker |
| 409 | lifecycleConflict | Another delete holds the barrier (`params.reason` = `deleteInProgress`) |

## cURL Example

```bash
curl -X DELETE \
  "https://demo.apinizer.com/apiops/projects/MyProject/consumer-organizations/acme-partners" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Permissions

- User must have **`IDENTITY` + `MANAGE`** permission in the project
- A project outside the scope of the caller answers `404 resourceNotFound`, never `403`
- The admin project has no consumer organizations: a call on it answers `400 malformedRequest` (`params.reason` = `platformScopeNotSupported`)
