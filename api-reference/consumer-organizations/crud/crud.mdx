| [Update](/api-reference/consumer-organizations/crud/update-consumer-organization) | PUT | `/consumer-organizations/{code}` | Update an organization |
| [Delete](/api-reference/consumer-organizations/crud/delete-consumer-organization) | DELETE | `/consumer-organizations/{code}` | Delete an organization |
