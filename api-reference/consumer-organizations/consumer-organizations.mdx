---
title: "Consumer Organizations API"
description: "The Consumer Organizations API manages the organizational groupings of consumers in a project. An organization is addressed by its code and can carry custom metadata."
---

## Overview

This API replaces the [Credential Organizations API](/api-reference/credential-organizations), which is deprecated. It uses the same write logic. Organizations are addressed by `code`, under `/apiops/projects/{projectName}/consumer-organizations`, and are not a sub-path of `/consumers`.

## Endpoints

| Operation | Method | Endpoint | Description |
|-----------|--------|----------|-------------|
| [List](/api-reference/consumer-organizations/crud/list-consumer-organizations) | GET | `/consumer-organizations` | List the organizations |
| [Get](/api-reference/consumer-organizations/crud/get-consumer-organization) | GET | `/consumer-organizations/{code}` | Read one organization |
| [Create](/api-reference/consumer-organizations/crud/create-consumer-organization) | POST | `/consumer-organizations` | Create an organization |
| [Update](/api-reference/consumer-organizations/crud/update-consumer-organization) | PUT | `/consumer-organizations/{code}` | Update an organization |
| [Delete](/api-reference/consumer-organizations/crud/delete-consumer-organization) | DELETE | `/consumer-organizations/{code}` | Delete an organization |
| [Suspend](/api-reference/consumer-organizations/actions#suspend-and-resume) | POST | `/consumer-organizations/{code}/actions/suspend` | Disable the organization's credentials; reversible |
| [Resume](/api-reference/consumer-organizations/actions#suspend-and-resume) | POST | `/consumer-organizations/{code}/actions/resume` | Re-enable the credentials the suspend disabled |
| [Revoke credentials](/api-reference/consumer-organizations/actions#revoke-credentials) | POST | `/consumer-organizations/{code}/actions/revoke-credentials` | Permanently revoke every credential; one-way |

## Permissions

| Operation | Required Permission |
|-----------|---------------------|
| List, Get | `IDENTITY` + `VIEW` |
| Create, Update, Delete, Suspend, Resume, Revoke credentials | `IDENTITY` + `MANAGE` |

A project outside the scope of the caller answers `404 resourceNotFound`. The admin project has no consumer organizations: a CRUD call on it answers `400 malformedRequest` (`params.reason` = `platformScopeNotSupported`). The three [actions](/api-reference/consumer-organizations/actions) are the exception: they are also accepted on the admin project's path for a System Administrator, Portal Business or Portal Manager, who pass for any organization. A caller who has only the project's Identity permission passes for an organization that holds `INTERNAL` applications only; an organization that holds a portal application answers that caller `403 permissionDenied`.
