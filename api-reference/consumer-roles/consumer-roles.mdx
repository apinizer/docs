description: "The Consumer Roles API manages the roles that you give to consumers. A role is addressed by its name in the project and can answer to one OAuth scope name."

## Overview

A consumer role is a name that you assign to consumers and applications and that you use in the authorization settings of API proxies. Roles are under `/apiops/projects/{projectName}/consumer-roles`. The names of this API are the names that `roleNameList` of a consumer takes and that `roleNames` of a consumer returns. See the [Consumers API](/api-reference/consumers).

A role name must be unique across the project and the admin project. The comparison ignores case. A name that another role holds answers `409 duplicateName`.

A role name in the `roleNameList` of a consumer resolves in the project of the consumer first, then in the admin project.

## Endpoints

| Operation | Method | Endpoint | Description |
|-----------|--------|----------|-------------|
| [List](/api-reference/consumer-roles/crud/list-consumer-roles) | GET | `/consumer-roles` | List the roles of the project |
| [Get](/api-reference/consumer-roles/crud/get-consumer-role) | GET | `/consumer-roles/{roleName}` | Read one role |
| [Create](/api-reference/consumer-roles/crud/create-consumer-role) | POST | `/consumer-roles` | Create a role |
| [Update](/api-reference/consumer-roles/crud/update-consumer-role) | PUT | `/consumer-roles/{roleName}` | Update or rename a role |
| [Delete](/api-reference/consumer-roles/crud/delete-consumer-role) | DELETE | `/consumer-roles/{roleName}` | Delete a role |

## Permissions

| Operation | Required Permission |
|-----------|---------------------|
| List, Get | `IDENTITY` + `VIEW` |
| Create, Update, Delete | `IDENTITY` + `MANAGE` |

A project outside the scope of the caller answers `404 resourceNotFound`. The admin project is served too: `/apiops/projects/admin/consumer-roles` manages the roles of the admin project.
