---
title: "List MCP Tools"
description: "Returns the statically discovered tool catalog for an AI Gateway MCP connection — the tools/list result last persisted by Discover / Reparse (or by first-deploy auto-discovery). Read-only; an empty list means discovery has not run yet."
---

## Endpoint

```
GET /apiops/projects/{projectName}/mcp-connections/{connectionName}/tools/
```

## Authentication

Requires a Personal API Access Token.

### Header

```
Authorization: Bearer YOUR_TOKEN
```

## Request

### Headers

| Header | Value | Required |
|--------|-------|----------|
| Authorization | Bearer \{token\} | Yes |

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|--------------|
| projectName | string | Yes | Project name |
| connectionName | string | Yes | MCP connection name |

### Query Parameters

None

## Response

### Success Response (200 OK)

```json
{
  "status": "SUCCESS",
  "resultList": [
    {
      "name": "list_issues",
      "description": "List issues in a GitHub repository",
      "inputSchema": "{\"type\":\"object\",\"properties\":{\"repo\":{\"type\":\"string\"}},\"required\":[\"repo\"]}",
      "type": "tool",
      "connectionId": "github-mcp",
      "cachedAt": "2026-07-25T09:13:20Z",
      "ttlRemainingSeconds": null
    }
  ],
  "resultCount": 1
}
```

#### Response Fields

| Field | Type | Description |
|-------|------|--------------|
| status | string | Response status: `SUCCESS` or `FAILURE` |
| resultList | array | List of discovered tool entries |
| resultCount | integer | Number of tools returned |

#### Tool Object Fields

| Field | Type | Description |
|-------|------|--------------|
| name | string | Tool name as declared by the MCP server |
| description | string | Human-readable tool description from the server's capabilities response |
| inputSchema | string | Stringified JSON Schema for the tool's input parameters |
| type | string | Capability category; always `"tool"` on this endpoint (resources/prompts are not yet exposed) |
| connectionId | string | The MCP connection's **name** (not its internal ID) — the APIops surface is name-based, this field carries the name even though it is shared with the ID-based classic Tool Registry resource |
| cachedAt | string | ISO-8601 timestamp of the last successful discovery (`toolsParsedAt` on the connection) |
| ttlRemainingSeconds | integer | Always `null` on this endpoint — the static, persisted tool model has no TTL; tools remain until the next manual [Discover / Reparse](/api-reference/mcp-connections/parse-mcp-tools) |

### Empty Result

If `tools/list` has never been run for this connection (no first-deploy auto-discovery, no manual parse), `resultList` is an empty array:

```json
{
  "status": "SUCCESS",
  "resultList": [],
  "resultCount": 0
}
```

### EnumStatus

- `SUCCESS` - Operation successful
- `FAILURE` - Operation failed

### Error Response (400 Bad Request)

```json
{
  "status": "FAILURE",
  "resultMessage": "MCP connection (name: github-mcp) was not found!"
}
```

### Error Response (401 Unauthorized)

```json
{
  "status": "FAILURE",
  "resultMessage": "Token is not valid!"
}
```

## cURL Example

```bash
curl -X GET \
  "https://demo.apinizer.com/apiops/projects/MyProject/mcp-connections/github-mcp/tools/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Notes and Warnings

- **Read-Only, Static Snapshot**: This endpoint reads the `discoveredTools` field persisted on the connection entity — it does not call the MCP server live. Use [Test MCP Connection](/api-reference/mcp-connections/test-mcp-connection) for a live probe, or [Discover / Reparse Tools](/api-reference/mcp-connections/parse-mcp-tools) to refresh this catalog.
- **Empty Means Not Discovered Yet**: An empty `resultList` is the normal state for a connection that was created but has never completed a successful deploy or manual parse — it is not an error.
- **No TTL**: Unlike the live capability cache used at runtime by the gateway, this static catalog does not expire; it is only replaced by the next successful discovery.
- **Permission**: Requires `AI_DEVELOPMENT` + `VIEW` in the project.
