Audit records are kept for changes made to an API Proxy, showing which user made which change and when.

:::info

The **Audit Records** tab of earlier versions has been removed. Audit records are now available in the panel opened with the **Audit and Rollback** option in the actions menu at the top right of the API Proxy page.

:::

## Viewing Audit Records

The **Audit and Rollback** option appears in the actions menu for users who have permission to view audit records. The panel that opens lists the audit records of the API Proxy with the following columns:

| Column | Description |
|--------|-------------|
| **Operation Type** | The type of operation; the date of the operation is shown below it |
| **Object Name** | The name of the object the operation was performed on |
| **Correlation ID** | The correlation ID of the operation |
| **Principal · Source** | The user who performed the operation and the source of the operation |
| **User Agent** | The browser information of the client that performed the operation |

Clicking the eye icon of a record opens its details. The details contain the **Changed fields** table and the **JSON Diff** and **Before & After** sections.

The same records can also be viewed for all assets on the [Audit Records](/en/admin/audit-compliance/audit-records) screen.

## Rollback

The rollback action of a record restores the API Proxy to the snapshot in that record.

1. Click the rollback icon (**Rollback**) of the record you want to restore.
2. In the **Confirm rollback** window, type the requested value (the asset's name) into the input field.
3. Click the **Rollback** button.

:::info

A rollback does not delete existing records; it writes a new audit record. The history therefore only grows forward.

:::
