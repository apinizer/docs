---
title: Business Rule Application Based on Variable Content Using Custom Variable Map
description: "Implement business rules by adding values to the customVariableMap via script, then trigger throttling or other policies based on that variable content."
---

In this scenario, a Mock API will be created on Apinizer. In the request to be made, the value **stop=true** will be added to the **customVariableMap** variable using script.

In the next stage, a **Business Rule** policy will be added and the value in **customVariableMap** will be checked. If this value is **stop=true**, **the request will be prevented from going to the backend**

Let's add policies through Add policy.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/add-policy-menu.png" alt="Adding to All section" width="1000" />

We add **Script** and **Business Rule** as policies.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/policy-picker.png" alt="Script and Business Rule" width="1000" />

In the **Script** policy, by selecting the **Groovy** language, stop=true will be assigned to the customVariableMap value.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/script-groovy-custom-variable-map.png" alt="Script Groovy" width="1000" />

Let's select the **stop** action we determined in the Business Rule policy.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/business-rule-actions-add.png" alt="Stop action" width="1000" />

Select **Custom Variable** from the **Conditions** field, write **stop** in the name field, and save.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/stop-action-select-variable.png" alt="Select variable" width="1000" />

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/variable-add-custom-variable.png" alt="Custom Variable stop" width="1000" />

With the rule you added below, if the value in **customVariableMap** is **true**, the request will not be forwarded to the backend.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/stop-condition-equals-true.png" alt="stop equals true" width="1000" />

When the test is performed from the console below, a response message indicating that the request was stopped is returned.

<img src="/images/tutorials/api-proxy-senaryolari/custom-variable-map-business-rule/test-endpoint-blocked.png" alt="Test console" width="1000" />
