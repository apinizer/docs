---
title: Using JsonPath With Groovy
description: "Reading fields from a JSON message with the Jayway JsonPath library in a Groovy script; examples for the $, ., *, and @ operators"
---

When specific fields need to be read from a JSON message, Apinizer's supported [Jayway JsonPath](/en/concepts/supported-technologies/supported-libraries) library can be used in a Groovy script. Import the `com.jayway.jsonpath.JsonPath` class and run JsonPath expressions with the `JsonPath.read` method. JsonPath can be used on JSON body variables on both the request and response pipelines.

```groovy
import com.jayway.jsonpath.JsonPath

def orderId = JsonPath.read(requestBodyTextFromClient, '$.orderResponse.orderId')
requestHeaderMapToTargetAPI.put("orderId", orderId)
```

## Sample Message

The JSON message used in the examples below:

```json
{
  "orderResponse": {
    "orderId": "ORD-0000001",
    "orderType": "SAMPLE_ORDER_TYPE",
    "status": "COMPLETED",
    "customer": {
      "customerNumber": "CUST-0000001",
      "region": "SAMPLE-REGION"
    },
    "items": [
      {
        "productCode": "PRD-0000001",
        "quantity": 10,
        "active": true
      },
      {
        "productCode": "PRD-0000002",
        "quantity": 5,
        "active": false
      }
    ]
  }
}
```

## 1) `$` — Root Element

- JsonPath expressions start with `$`.
- `$` represents the root of the JSON document.

```groovy
import com.jayway.jsonpath.JsonPath

def orderResponse = JsonPath.read(requestBodyTextFromClient, '$.orderResponse')

requestHeaderMapToTargetAPI.put("orderStatus", orderResponse.status)
// Output: COMPLETED
```

## 2) `.` — Child Element Access

- The dot operator is used to access nested fields from the root.

```groovy
import com.jayway.jsonpath.JsonPath

def orderId = JsonPath.read(responseBodyTextFromTargetAPI, '$.orderResponse.orderId')

responseHeaderMapToClient.put("orderId", orderId)
// Output: ORD-0000001
```

## 3) `*` — Wildcard

- Used to select all matching elements in an array or object.

```groovy
import com.jayway.jsonpath.JsonPath

def productCodes = JsonPath.read(requestBodyTextFromClient, '$.orderResponse.items[*].productCode')

customVariableMap.put("productCodes", productCodes)
// Output: [PRD-0000001, PRD-0000002]
```

## 4) `@` — Current Node

- Represents the array element being evaluated in filter expressions (`[?(...)]`).

```groovy
import com.jayway.jsonpath.JsonPath

def activeProductCode = JsonPath.read(responseBodyTextFromTargetAPI, '$.orderResponse.items[?(@.active == true)].productCode')

customVariableMap.put("activeProductCode", activeProductCode)
// Output: [PRD-0000001]
```

## 5) Using Read Values as Custom Variables

Read values can be added to `customVariableMap` for use in other policies:

```groovy
import com.jayway.jsonpath.JsonPath

def requestOrderId = JsonPath.read(requestBodyTextFromClient, '$.orderResponse.orderId')
def responseOrderId = JsonPath.read(responseBodyTextFromTargetAPI, '$.orderResponse.orderId')

customVariableMap.put("requestOrderId", requestOrderId)
customVariableMap.put("responseOrderId", responseOrderId)

// Output:
// requestOrderId = ORD-0000001
// responseOrderId = ORD-0000001
```
