## Version 2027.01.0

:::warning Before you upgrade

- **A record that other records use can no longer be deleted.** The refusal names the records that use it; APIops delete follows the same rule.
- **DB-2-API, Script-2-API, Mock API, task flow run logs, Quota Alerts and `${NAME}` variables work inside one project.** An API proxy routes only to a definition of its own project, and a variable of another project stays as typed.
- **Text criteria "is equal to" and "not equal" now compare the whole value and ignore letter case.** Saved reports and anomaly detectors that use them can return different results.
- **A connector added to an environment after the upgrade does not write logs until you turn it on.** Turn on **Active for this environment** in the traffic log settings.
- **Existing AI Token Usage Percentage and AI Daily Cost Threshold (USD) alarms switch to Execute once for same violation series.** You can change the **Execution Mode** of each alarm.

:::
