<Steps>
  <Step title="Add an LLM Provider Connection">
    Connect Apinizer to at least one LLM provider — cloud (OpenAI, Anthropic, Azure, Vertex, Bedrock) or self-hosted (vLLM, Ollama, Hugging Face TGI). The connection stores the provider's credentials encrypted, so your application never handles the real key.

    See [LLM Providers and Models](/en/ai-gateway/llm-providers) for the full setup steps.
  </Step>

  <Step title="Point Your OpenAI SDK at Apinizer">
    Configure the OpenAI SDK (or any OpenAI-compatible client) with your gateway's `base_url` and your Apinizer credential key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        api_key="your-apinizer-credential-key",
        base_url="https://your-apinizer-gateway.com/api/ai/v1"
    )
    ```

    No other client-side changes are needed — the SDK talks to Apinizer exactly as it would talk to OpenAI directly.

    Your LLM Gateway's **Routing** tab has an **Endpoints** panel that lets you copy the gateway address per environment and try it quickly through the Test Console via the **Test** button next to it — see [Routing and Failover](/en/ai-gateway/routing-and-failover#endpoints-panel) for details.
  </Step>

  <Step title="Send Your First (Streaming) Chat Completion">
    ```python
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": "Hello, Apinizer!"}],
        stream=True
    )

    for chunk in response:
        if chunk.choices[0].delta.content:
            print(chunk.choices[0].delta.content, end="", flush=True)
    ```

    The response streams back chunk-by-chunk as it arrives from the provider — the same shape you'd get calling the provider directly, regardless of which provider actually served the request.

    A new LLM Gateway follows the `stream` value your client sends. A new LLM Gateway has no policies: guardrails, semantic cache and token limits apply only after you add them. If the LLM Gateway was created earlier and its **Client "stream" field** is **Overwrite with the proxy setting**, the **Streaming (SSE)** switch on the **Routing** tab decides, and a gateway with the switch off returns a single response even for `stream=True`. See [Client "stream" Field](/en/ai-gateway/routing-and-failover#client-stream-field).
  </Step>
</Steps>
