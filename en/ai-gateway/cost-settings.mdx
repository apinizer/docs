Costs are calculated and reported in **USD**, priced per model from the prices in the model's LLM provider.
:::

## Per-Model Pricing

Every model of an [LLM provider](/en/ai-gateway/llm-providers#model-prices) can have an input and output price, expressed per 1M tokens:

```
gpt-4o
  Input:  $0.005 per 1M tokens
  Output: $0.015 per 1M tokens

gpt-4-turbo
  Input:  $0.01 per 1M tokens
  Output: $0.03 per 1M tokens
```

Pricing changes apply going forward — historical usage keeps the price that was in effect when it was recorded.

In the model drawer, the prices appear as **Input $/1M**, **Output $/1M** and **Cached $/1M**. Prices are optional. A model with no price shows a **no price** badge in the provider's model list.

<Steps>
  <Step title="Open the LLM Provider">
    Go to **AI Gateway** → **Models** and open the provider that serves the model. Pricing lives in the model's drawer, under **Cost management**.
  </Step>

  <Step title="Open the Model">
    The **Models** section lists the models of the provider. Click the pencil icon of a row to open the model drawer.
  </Step>

  <Step title="Update Price">
    Edit the input and output price fields. A model with no price configured counts as 0 in cost reports.
  </Step>

  <Step title="Save">
    Click **Save Model**, then **Save and Deploy** on the provider. New requests use the updated price; already-recorded usage is not recalculated.
  </Step>
</Steps>

## Cost Reconciliation

Every request's cost is reconciled from three token counts, priced independently:

<CardGroup cols={1}>
  <Card title="Input Tokens" icon="arrow-right-to-line">
    Tokens sent to the model as the prompt.
  </Card>
  <Card title="Output Tokens" icon="arrow-left-to-line">
    Tokens generated by the model in its response.
  </Card>
  <Card title="Cached Tokens" icon="database">
    Prompt tokens the *provider* served from its own prompt/context cache instead of reprocessing them, usually billed at a lower rate than standard input tokens.
  </Card>
</CardGroup>

:::note
Cached tokens are a **provider-side** mechanism (OpenAI prompt caching, Anthropic prompt caching, etc.) — not Apinizer's own [semantic cache](/en/ai-gateway/semantic-cache), which avoids calling the model at all for a similar prior request. A request can use provider-side caching and still be a full, billable call to the model.
:::

Because each is priced separately, your cost reports reflect exactly what was consumed rather than a single blended rate.

## Prices and USD Limits {#prices-and-usd-limits}

The same prices also drive **USD limits** in [Limit Plans](/en/ai-gateway/limit-plans#usd-limits-need-model-prices), so the amount charged against a USD limit and the cost shown in reports are the same figure:

- Each turn of a request is priced by the model that actually served it. When a request fails over to another model, or is routed to a cheaper model, the cost follows the model that answered.
- A request served by a model with no price costs **0** in both places. The model is exempt from USD limits, and its usage appears in reports at zero cost, until you set a price. Check the **no price** badge in the provider's model list.
- A request whose price resolves to 0 (for example, a zero-rate service tier) also counts 0 toward the USD limit.

## Cost in Reports

Once pricing is configured, cost figures appear throughout [Reports and Analytics](/en/ai-gateway/reports):

- This month's cost and the cumulative cost chart on the **Cost & Consumers** tab
- Cost breakdown by model, project, team, and deployment type, and the **Total cost** card on the **Overview** tab
- Exported reports with cost columns

Reports show costs in USD, with four decimals.

## Permissions

Prices are edited together with the LLM provider, so changing them requires the permission to manage AI development. A provider shared from the Administration catalog is edited from the Administration menu. Other roles continue to see usage and cost breakdowns in reports, without the ability to change pricing.
