## Deleting a Record That Is in Use

Apinizer refuses to delete a connection while another record still uses it. The same rule applies to LDAP connections, certificates, key stores, keys, IP groups, and knowledge bases.

The error message names the records that use the item:

- Up to 5 records are listed, each with its type. In the Admin view, the project name is also shown.
- When more records use the item, the message adds "and N more".
- Records in other projects are counted but not named, unless you are an admin. The message reads "N more in other projects".
- Records on screens that you may not view are counted but not named. The message reads "N more you do not have permission to view".
- For connections, certificates, key stores, IP groups, and knowledge bases, the message ends with "See Used By on the detail page." These items have the Used By panel. Other items, such as keys, LLM providers, vector databases, OIDC providers, limit plans, API plans, and roles, have no panel and no such ending.

Remove or change each use first, then delete the item again. Items that are deleted together with their parent, such as the JWKs of a certificate, follow their own deletion options and are not affected by this rule.

### Used By Panel

The detail page of the following items has a **Used By** panel below the item details:

- All connection types in this section, including the OTLP connection
- Certificates
- Key stores
- IP groups
- Knowledge bases

The panel is calculated when you open the page. It lists the API proxies, policies, connections, integrations, DB-2-APIs, alerts, monitors, reports, consumers, applications, authentication and settings records that refer to the item.

- The table has the columns **Type**, **Name**, **Used In**, and, in the Admin view, **Project**. Click a name to open the record.
- Use the **Type** filter and the name search to narrow the list. Click the Excel button to export the list.
- The table shows 10 rows per page.
- The header shows **All projects** in the Admin view and **This project** in a project.
- In a project, the list shows only the records of that project. References elsewhere appear as "N more in other projects".
- When nothing uses the item, the panel shows **Not used**.
