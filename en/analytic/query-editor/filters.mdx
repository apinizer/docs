:::info

**Project menu:** **Analytic → Query Editor → Filters** (`/custom-query-filter`)  
**Administration mode:** **Analytic → Query Editor → Filters** (`/admin/custom-query-filter`)  
Create a filter from **Create** on the list; save from the edit screen with **Save and Deploy**. Saved filters show an **Audit and Rollback** tab.

:::

## Filter Creation

On the **General** tab you define name, description, proxy list, date range, operation result type, and sort order. If the proxy table is empty, the filter applies to all proxies.

## Configuration Fields

| Field | Description |
| --- | --- |
| **Name** | Unique name of the filter. |
| **Description** | Optional description. |
| **Proxies** | API Proxies the filter applies to. An empty table or **All Proxies** row means every proxy. Use **Add** to pick proxies. |
| **Date Range** | Time window for the filter (for example the last 30 minutes). |
| **Operation Result Type** | **Success**, **Blocked**, **Error** — multiple selections allowed. |
| **Sort Order** | Log fields and direction (ascending/descending) for the result table. Add with **Create New Order**. |

## Filter Criteria

  <Card title="Result Type Filtering" icon="filter">
    Narrows to successful, blocked, or error requests

  <Card title="Sorting" icon="sort">
    Defines how the query result is ordered

:::info

If no proxy is selected, the filter applies to **all** API Proxies. Inline test filters on the query edit screen apply only to that session; create a filter here or use **Select Filter** for a persistent definition.

:::
