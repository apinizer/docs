:::info

There is no separate **Queries** list now. A saved Query is a **Filter**. Open it from **Analytic → Filters**.

:::

On upgrade, each saved Query became a Filter with its conditions, and each earlier Filter became a Filter too. Reports, anomaly detectors and API Proxy trace keep working with the Filter in the place of the Query. See [Filters](/en/analytic/query-editor/filters) for the Filter list, the Filter page, the conditions, the Keyword criterion and the **Used in** tab.
