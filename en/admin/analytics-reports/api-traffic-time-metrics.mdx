This screen is the **API Traffic Metrics** sub-report found under the **Traffic** tab of the **Analytics** > **Reports** > **Metrics** page in the **Admin** menu.

:::info

The same report is also available in the **Project** menu; the only difference between the two views is scope. When accessed from the Admin menu, the report covers all projects and additionally offers a project selection filter; when accessed from the Project menu, it covers only the currently active project.

:::

For column descriptions, filtering options, and metric definitions, see the canonical page: [API Traffic and Time Metrics](/en/analytic/analytics-reports/api-traffic-and-time-metrics).
