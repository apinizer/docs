## Accessing Your Profile

You can open the profile menu with the avatar button at the top right of the screen. From this menu you can:

* Go to the **My Profile** page
* Go to the **Change Password** page
* Change the interface language (English / Türkçe) — the selected language is applied instantly and is marked with a checkmark in the menu
* Sign out of the platform

## Profile Information

The profile card at the top of the page contains your personal information. After making changes, you can save them with the **Save** button at the top right of the page.

| Field | Description |
| --- | --- |
| **Username** | The name you use to sign in. It is displayed under your avatar and cannot be changed. |
| **Full Name** | Your first and last name as shown across the platform. |
| **Email** | Your e-mail address used for notifications. |
| **Preferred Language** | Your interface language preference. The selection changes the interface language immediately and is stored as your preference when you save. |
| **Default Project** | The project that is selected automatically when you sign in. |
| **Roles** | Your system-wide roles. This area is read-only; roles are assigned by an administrator. For details, see the [Users](/en/admin/user-access-management/users) page. |

## Personal API Access Tokens

Personal API access tokens let you access the Apinizer Management API on your own behalf; requests made with a token are executed with your user's permissions.

The token list shows the name, creation date, expiration status, last used time and the masked value of each token. You can reveal a token with the eye icon, copy it with the copy icon, and narrow the list with the **Active / Expired / All** filter.

### Generating a Token

<Steps>
    <Step title="Start token creation">
        Click the <strong>Generate new token</strong> button on the Personal API Access Tokens tab.
    </Step>
    <Step title="Define name and lifetime">
        Enter a descriptive token name and choose a lifetime: 30, 60 or 90 days, a custom date, or no expiration.
    </Step>
    <Step title="Copy the created token">
        Click <strong>Generate token</strong>. The created token is displayed on the screen and can be copied with a single click. You can also view or copy the token later from the token list.
    </Step>
</Steps>

:::warning

Tokens created without an expiration date never expire. For better security, prefer a limited lifetime and revoke tokens you no longer use.

:::

### Revoking a Token

You can revoke a token with the **Revoke** button on the token row. When you confirm the operation, applications using that token lose their access immediately; this action cannot be undone.

## Memberships

The Memberships tab is a read-only view of which projects you can access and which teams you belong to. Memberships and roles are managed by administrators from the [Users](/en/admin/user-access-management/users), [Teams](/en/admin/user-access-management/teams) and [Project Members](/en/admin/project-management/project-members) pages.

### Project Memberships

Lists the projects you can access, either directly or through a team. For each project you can see:

* **Membership type**: **Direct** if you were added to the project as an individual member; otherwise the name of the team through which you gained access
* **Roles**: the roles that are effective for you in that project, including the roles inherited from your teams

### Teams

Lists the teams you belong to, together with the number of members in each team and the number of projects the team is added to. Teams are added to projects as members, so joining a team grants you access to that team's projects with the team's roles.
