---
title: "Project Members"
description: "Authorize selected projects by assigning roles to users or teams created in Apinizer"
---

Through the Members screen, authorization can be made for selected projects by assigning roles to users or teams created in Apinizer.

A separate role can be defined for each project for a user or team.

When a team is added as a member to a project, there is no need to select a role. Since the roles of users in the team are defined when adding the team, the roles of users within the team are valid.

## Adding Team

To add members from a team to the active project, select the team from the list in the **Select Users and/or Teams** field, then click the **Add** button.

![Adding Team](/images/admin/project-management/image2021-12-3_10-42-14.png)

## Adding User

To add a user to the active project, select the user from the list in the **Select Users and/or Teams** field, then click the **Add** button.

![Adding User](/images/admin/project-management/image2021-12-3_10-43-22.png)

To update the role of the added user, select from the **role** list.

![Role Update](/images/admin/project-management/image2021-12-3_10-45-20.png)

## Viewing Team Details

To see the users and roles within the added team, click the **Team Details** button.

![Team Details](/images/admin/project-management/image2021-12-3_10-46-34.png)

In the opened window, you can see the users in the team and the roles of these users within the relevant team.

![Team Details Window](/images/admin/project-management/image2021-12-3_10-47-11.png)

## Removing Member

To remove the added team, click the **Delete Member** button, then confirm the operation in the window that appears.

![Removing Member](/images/admin/project-management/image2021-12-3_10-49-17.png)

## Project Access

The **Project Access** tab shows who is a member of which project. It is read-only. Only system administrators see the tab.

Open the **Project** page under **Administration**. The page has two tabs: **Projects** and **Project Access**. Click **Project Access**.

The table has these columns:

| Column | Description |
|---|---|
| **User** | The user name. Click it to open the user page. A member of a directory (LDAP) who has no user record in Apinizer yet shows the name without a link. |
| **System Role** | The system roles of the user. |
| **Project** | The project. Click it to open the project page. |
| **Role(s)** | The roles of the user in the project. |
| **Source** | **Direct** when you added the user to the project. The team name when the user is a member through a team. |

The table has one row for each user, project and source. A user who is a member of a project directly and through a team has two rows.

Use the filters above the table to narrow the list:

| Filter | Description |
|---|---|
| **Search by user** | Shows the users whose name contains the text. |
| **All projects** | Select one or more projects. |
| **All roles** | Select one role. |
| **All sources** | Select **Direct** or a team name. |

Click **Excel** to export the filtered list. The file has these columns: **User**, **System Role**, **Project**, **Role(s)** and **Source**. It holds no password or token.
