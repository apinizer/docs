:::info

Secrets Management enables management of certificates, keystores, private keys, and JWKS configurations used for security and encryption in the Apinizer platform. This module provides all the tools needed to create, manage security components used in policies and connections, and perform export/import operations.

:::

:::warning

Operations in the Secrets Management menu can only be performed by **Admin** user.

:::

## Single-Page View

The Secrets Management lists are gathered on a **single page with tabs**: **Certificates**, **Truststore**, **Keys**, **Key Stores**, **JSON Web Keypair Sets**, and **Keystore Studio**. The sidebar menu opens this page directly; each tab keeps its own filters, and the **Import** / **Create** buttons sit on the right side of the filter row of the related tab.

- **Overview cards** at the top show the total count per type together with a one-line status (for example `2 expired · 1 expiring soon`). Clicking a card switches to that tab.
- **Expiry status** is colour coded everywhere: green means valid, amber means it expires within 30 days, red means expired. Tab count pills also turn red when the tab contains expired or erroneous items.
- Related records are grouped **per gateway environment** inside each row; certificate and key store entries show alias, subject and a `Valid : from - until` badge.
- The **Truststore** tab is read **live from the selected gateway environment** — its content is not stored in Apinizer. Select an environment to fetch the currently trusted certificates; this tab has no Import or Create action.
- The **How to read** button at the top right opens a panel that explains each tab and the status colours.

Row clicks keep navigating to the existing detail pages; create and edit screens are unchanged.

## Module Core Components

The Secrets Management module provides centralized management of all components used for security and encryption in the Apinizer platform. With this module:

- Security certificates and keystores are managed
- Encryption keys and JWKS configurations are created
- Configurations are transferred between environments
