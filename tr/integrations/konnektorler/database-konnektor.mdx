Konfigürasyon alanları:

<CardGroup cols={2}>
  <Card title="Tip" icon="database">
    **Alan:** Tip 
    
    Veritabanı tipi seçilir.
  </Card>
  
  <Card title="Bağlantı Havuzu Tanımı" icon="plug">
    **Alan:** Bağlantı Havuzu Tanımı (Connection Pool Definition)
    
    Seçilen veritabanı türüne göre veritabanı bağlantısına ait tanım havuzdan seçilir. Bağlantı oluşturmak hakkında detaylı bilgi için [tıklayınız](/tr/integrations/baglanti-yonetimi/database)
  </Card>
  
  <Card title="Operasyon" icon="gear">
    **Alan:** Operasyon (Operation)
    
    Operasyon tipi seçilir.
  </Card>
  
  <Card title="Sorgu Zaman Aşımı" icon="clock">
    **Alan:** Sorgu Zaman Aşımı (sn) (Query Timeout (sec))
    
    Sorgunun çalışma süresine ait aşım süresi bilgisi girilir.
  </Card>
  
  <Card title="SQL" icon="code">
    **Alan:** SQL
    
    Eylem içinde çalıştırılacak sorgu yazılır.
    
    :::info

SQL alanında değişkenler kullanılabilir.

:::
  </Card>
</CardGroup>

:::info

**Operasyon** alanında sunulan seçenekler konnektörün kullanıldığı yere göre değişir. Bir **ortam, SIEM ve Log Yönlendirme veya Portal Login Log** alıcısı olarak kullanıldığında — bkz. [Log Konnektörü Eklenmesi](/tr/admin/server-management/gateway-ortamlarina-konnektor-eklenmesi#veritabani-alicisinda-operasyon-alani) — veritabanı tipinden bağımsız olarak yalnızca **Insert-Update-Delete** sunulur. Bir **Job**, **Alert** veya **Task Flow Routing** eyleminde ise seçilen veritabanı tipine göre Select, Insert-Update-Delete ve Stored Procedure seçenekleri kullanılabilir olmaya devam eder.

:::

:::tip

Bu konnektörü API trafik veya diğer Apinizer loglarını veritabanına yazmak için kullanıyorsanız, hedef tabloların şema ve DDL tanımları için [Apinizer Logları için Tablo Oluşturma Komutları](/tr/operations/yonetici-kilavuzlari/apinizer-log-tablolari-olusturma-komutlari) sayfasına bakabilirsiniz.

:::
