## Sürüm 2027.01.0

<span style={{ display: 'inline-block', backgroundColor: '#e65a2a', color: '#ffffff', padding: '0.25rem 0.75rem', borderRadius: '9999px', fontSize: '0.875rem', fontWeight: '500' }}>HATA DÜZELTMELERİ</span>

- ### URL ve Dosyadan İçe Aktarma ile Bağlantı Testleri İçin Yetki Gerekir
URL veya dosyadan spesifikasyon içe aktarma, Test Console'da URL'den içe aktarma, URL'den sertifika okuma ve Promotion instance bağlantı testi artık kullandıkları ekranın yetkisini ister. Bu yetkisi olmayan istek HTTP 403 alır. [Bkz.](/tr/develop/api-proxy-olusturma/api-proxy-olusturma) APNZ-7205

- ### Manager ve API Portal Girişi Beni Hatırla Değerini Yok Sayar
Manager ve API Portal girişi artık her token'a normal token geçerlilik süresini (`token-validity-in-seconds`) verir. `/api/authenticate` adresine `rememberMe: true` gönderen istemci bu süreyi alır ve hata almaz. Yükseltmeden önce verilen token'lar özgün bitiş süresini korur, en çok 30 gün. Yenileme bu süreyi uzatmaz ve kısaltmaz. `token-validity-in-seconds-for-remember-me` yapılandırma anahtarı hâlâ kabul edilir ve yok sayılır; eski yapılandırmalar açılmaya devam eder. APNZ-7204

- ### XML'den JSON'a Dönüşümde Dizi Yolları Düzeltildi
`root#liste#aciklama` gibi bir dizi yolu, yolun son elemanını artık tekrar eden her üst elemanın altında ve her derinlikte JSON dizisine dönüştürür. Önceden üst eleman iki veya daha çok kez tekrar ettiğinde eleman tekil değer olarak kalıyordu. Bu düzeltme REST to SOAP yanıt dönüşümünü, XML Dönüştürme politikasını, Redaction'ı, İş Kuralı politikalarını ve XML dönüşüm test aracını kapsar. [Bkz.](/tr/develop/politikalar/xml-donusturme) APNZ-7171

- ### Portal Test Ekranı ve MCP Token Aracı Çalışmayacak Token İsteklerini Reddeder
Bazı token politikaları token'ı uygulama credential'ına değil, yalnızca API'nin kendi istemcisine verir. Bu durum kendi anahtarlarını yöneten OAuth2 politikası için geçerlidir. Anahtarlarını portalın yayımlamadığı JWT politikası için de geçerlidir. Bu API'lerde portal test ekranı artık **Authorize** düğmesini devre dışı bırakır ve bir ipucu gösterir. MCP aracı `get_token` isteği reddeder. `get_api_auth_info` portalın token alamadığını belirtir. Portal ağ geçidine hiçbir istek göndermez. [Bkz.](/tr/api-portal/api-urunu) APNZ-6092


- ### API Portal Angular 22 Sürümüne Yükseltildi, CVE-2026-88059 Kapatıldı
API Portal artık Angular 22.2.3 üzerinde çalışır. Bu yükseltme, bir güvenlik taramasının API Portal için bildirdiği CVE-2026-88059 zafiyetini kapatır. Düzeltme Angular 22.1.1 ve sonrasındaki sürümlerdedir. API Portal sunucu tarafı render kullanmaz; bu nedenle sunucu tarafı render önbellek sorunu yükseltmeden önce de istismar edilemezdi. APNZ-6932
