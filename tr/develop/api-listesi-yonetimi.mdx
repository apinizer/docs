### Liste Sütunları

| Sütun | İçerik |
|-------|--------|
| **İstemci Rotası** | İstemci rotasının göreli yolları. İlk iki yol görünür, kalanlar araç ipucu olan bir `+N` bağlantısı olarak görünür. Host'lar ve metotlar altta küçük yazıyla görünür. Liste boşsa **Tüm host'lar** veya **Tüm metotlar** yazar. |
| **URL** | Her ortam için erişim adresi. Adresin yanındaki simge ve etiket ortamın TLS düzeyini gösterir: HTTP, HTTPS veya mTLS. |
| **Oluşturulma** | Oluşturulma tarihi ve API Proxy'yi oluşturan kullanıcı. Oluşturulma tarihine göre sıralamak için sütun başlığına tıklayın. |

### Göster Menüsü

Sütun eklemek için listenin üstündeki **Göster** düğmesini kullanın. Tüm seçenekler varsayılan olarak kapalıdır. Seçiminiz bu liste için tarayıcınızda saklanır.

| Seçenek | Sütun | İçerik |
|---------|-------|--------|
| **Route adresini göster** | **Route Adresi** | Her yönlendirme adresi için bir satır. DB-2-API proxy'sinde, metotların kullandığı bağlantı havuzlarının adları adreslerden sonra gelir. |
| **Route koşulunu göster** | **Route Koşulu** | Her yönlendirme adresinin koşulu, adresle aynı satırda. Yalnız **Route adresini göster** açıkken kullanılabilir. |
| **Politikaları göster** | **Politikalar** | Aktif kimlik doğrulama politikasının adı ve diğer politikaların sayısı. Aktif kimlik doğrulama politikası yoksa hücre **Kimlik doğrulama politikası yok** yazar. Her politikayı tipi, kaynağı (global politika, API Proxy, endpoint veya proxy grubu), fazı ve durumuyla görmek için hücrenin üzerine gelin. |
| **Trafiği göster (son 24 saat)** | **Ort. Yanıt Süresi** ve **Son Hata** | Son 24 saate ait değerler, trafik logundan okunur. Yalnız analitik görüntüleme yetkiniz varsa kullanılabilir. Trafik logu okunamazsa bir hata mesajı ve **Tekrar dene** düğmesi görünür. |

**Route Adresi** sütununda, proxy'nin birden fazla adresi veya ağırlıklı bir adresi varsa adresin ardında tipini gösteren bir etiket görünür: `[PRIMARY]`, `[CANARY]`, `[MIRROR]` veya `[FAILOVER_ONLY]`. 1'den büyük ağırlık `w=3` biçiminde görünür. Tek ve ağırlıksız bir primary adresi olan proxy yalnız adresi gösterir. 20 satırdan uzun bir liste `... (+N more)` ile biter.

LLM Gateway listesinde **Route Adresi** sütunu LLM sağlayıcısını ve modeli gösterir, örneğin `Sağlayıcı (model) [PRIMARY]`. Koşullu route'lar `[CONDITIONAL: route adı]`, failover kayıtları `[FAILOVER #1]`, `[FAILOVER #2]` biçiminde görünür. Anlama göre eşleşen koşullu bir route, örnek cümlelerini **Route Koşulu** sütununda gösterir.

:::info

LLM, MCP ve A2A Gateway listelerinde **Trafiği göster (son 24 saat)** seçeneği yoktur.

:::

### API Proxy Arama ve Filtreleme


  <Accordion title="Temel Filtreleme" icon="filter" defaultOpen>
    | Filtre | Açıklama |
    |--------|----------|
    | **İsim Arama** | API Proxy adına göre arama |

    | **Durum Filtresi** | Deployment durumuna göre filtreleme |

### Gelişmiş Filtreleme

Daha detaylı aramalar yapabilmek için **Gelişmiş Filtreleme** özelliğini kullanın. Liste üzerinde bulunan filtre alanlarının hemen yanındaki ilgili ikona tıklayarak gelişmiş filtreleme seçeneklerine erişebilirsiniz.

**Gelişmiş Filtreleme Kriterleri:**

| Kriter | Açıklama |
|--------|----------|
| **API Proxy Adı** | Belirli bir adı içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **API Proxy Açıklaması** | Belirli bir açıklamayı içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **API Tipi** | Protokol tipine göre filtreleme yapar. Birden fazla seçim yapabilirsiniz. Seçenekler: REST, SOAP, gRPC, WebSocket |
| **API Proxy Tipi** | Oluşturulurken seçilen tipe göre filtreleme yapar. Seçenekler: Swagger, WSDL, Open API/Swagger 3.0.x, WADL, Fake API, Reverse Proxy, Mirror API, No-Spec API, DB-2-API, Script-2-API, Mock API, Websocket, gRPC, gRPC Proto |
| **Kullanım Şekli** | Kullanım şekline göre filtreleme yapar. Seçenekler: Hepsi, Üretici, Tüketici, Üretici ve Tüketici |
| **Paylaşım Tipi** | API Proxy'nin paylaşım tipine göre filtreleme yapar. |
| **Kategori** | Kategorilere göre filtreleme yapar. |
| **API Proxy Adresi** | Belirli bir adresi içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **Metot/Uç Nokta Adı** | Belirli bir metot veya uç nokta adını içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **Metot/Uç Nokta Açıklaması** | Belirli bir metot veya uç nokta açıklamasını içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **Parametre Adı** | Belirli bir parametre adını içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **Parametre Açıklaması** | Belirli bir parametre açıklamasını içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **Router Adresi** | Belirli bir yönlendirme adresini içeren API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **Yükleme Durumu** | Yükleme durumuna göre filtreleme yapar. Seçenekler: Hepsi, Yüklenmiş, Yüklenmemiş |
| **Ortam** | Ortam bilgisine göre filtreleme yapar. |
| **Trace Modu** | İzleme moduna göre filtreleme yapar. Seçenekler: Aktif, Pasif |
| **Uygulama Log Durumu** | Uygulama log durumuna göre filtreleme yapar. Seçenekler: Aktif, Pasif |
| **Oluşturulma başlangıcı / Oluşturulma bitişi** | Oluşturulma tarihine göre filtreler. Her iki gün de dahildir. |
| **Oluşturan** | Girilen metni adında içeren bir kullanıcının oluşturduğu API Proxy kayıtlarını getirir. Büyük/küçük harf duyarlılığı yoktur. |
| **TLS** | API Proxy'nin yüklendiği ortamın TLS düzeyine göre filtreler. Seçenekler: HTTP, HTTPS, mTLS. Yalnız yüklenmiş API Proxy'ler eşleşir. |
| **Kimlik Doğrulama** | Seçenekler: Kimlik doğrulama politikası var, Kimlik doğrulama politikası yok. Yalnız aktif kimlik doğrulama politikaları sayılır. Kontrol; API Proxy'nin, endpoint'lerinin ve proxy gruplarının politikalarını kapsar. |
| **Politika Tipi** | Seçilen politika tiplerini kullanan API Proxy kayıtlarını getirir. |

### Sıralama

API Proxy listesi bir tablo olarak görünür. Şu şekilde sıralayabilirsiniz:

- **Sıralama**: **Ad** veya **Oluşturulma** sütun başlığına tıklayın.

### Excel'e Aktarma

Listeyi dışa aktarmak için sayfanın üstündeki Excel simgesine tıklayın. Dosya, geçerli filtrelerin tüm sonucunu içerir. **Oluşturulma** ve **Oluşturan** sütunları dosyada bulunur. **Route adresini göster**, **Route koşulunu göster** veya **Politikaları göster** seçeneğini açtığınızda dosyaya **Route Adresi**, **Route Koşulu** ve **Politikalar** sütunları da eklenir.

### API Proxy Grup Bilgisi

API Proxy listesinde, her bir API Proxy'nin ait olduğu API Proxy grupları görüntülenir. Bir API Proxy birden fazla gruba ait olabilir ve grup bilgileri liste görünümünde gösterilir.

:::info

API Proxy grupları hakkında detaylı bilgi için [API Proxy Grupları](/tr/develop/api-proxy-group-olusturma) sayfasına bakabilirsiniz.

:::

### Etiket Ekleme

<Steps>
  <Step title="Proxy Seç">
    Listeden bir API Proxy seçin
  </Step>
  <Step title="Overview Sekmesi">
    **Overview** sekmesine gidin
  </Step>
  <Step title="Etiketler Bölümü">
    **Etiketler** bölümünü bulun
  </Step>
  <Step title="Etiket Ekle">

  </Step>

### Etiket Tabanlı Filtreleme


  <Accordion title="Filtreleme Yöntemleri" icon="filter">
    - Etiket bulutunda bir etikete tıklayarak o etikete sahip proxy'leri filtreleyin
    - Daha spesifik filtreleme için birden fazla etiketi birleştirin
    - Belirli etiket kombinasyonlarına sahip proxy'leri bulmak için etiket araması kullanın
  </Accordion>


### Etiketleme En İyi Uygulamaları

:::warning

**Dikkat Edilmesi Gerekenler:**
- **Tutarlı İsimlendirme**: Bir etiketleme kuralı oluşturun ve buna bağlı kalın
- **Etiket Sayısı**: Proxy başına 3-5 etiket kullanın
- **Hiyerarşik Etiketler**: Nokta notasyonu kullanın (örn: `payment.credit-card`)
- **Dokümantasyon**: Ekibiniz için bir etiket sözlüğü tutun

:::


### Liste Üzerinden Yapılabilecek İşlemler

API Proxy listesinde, her bir API Proxy için aşağıdaki işlemler gerçekleştirilebilir:

<CardGroup cols={2}>
  <Card title="Export" icon="file-export">
    API Proxy'yi yedekleme veya migrasyon için export edebilirsiniz. Export işlemi JSON formatında dosya oluşturur.
  </Card>
  <Card title="Sil" icon="trash">
    API Proxy'yi listeden silebilirsiniz. Silme işlemi öncesinde onay istenir.
  </Card>
  <Card title="Duplicate" icon="copy">
    Mevcut API Proxy'nin bir kopyasını oluşturabilirsiniz. Kopyalama işlemi tüm konfigürasyonları içerir.
  </Card>
  <Card title="Reparse" icon="refresh">
    API Proxy tipine göre yeniden ayrıştırma (reparse) işlemi yapabilirsiniz. Bu işlem, API Proxy'nin spec dosyasını yeniden okur ve günceller. Onay adımı, erişimi olan consumer'lar için yeni endpoint'leri engelli tutabilir. Bkz. [Erişim Kontrolü](/tr/admin/identity-management/erisim-kontrolu).
  </Card>
</CardGroup>

:::info

Bu işlemler tek tek API Proxy'ler üzerinde gerçekleştirilir. Toplu işlem desteği bulunmamaktadır.

:::
