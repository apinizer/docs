## Script-2-API Listesi

Ana menüde **Geliştirme → API Oluşturucu → Script-2-API** (*Development → API Creator → Script-2-API*) öğesini seçin. Liste tek bir kartta açılır. Sayfa Mock API listesiyle aynı düzendedir.

Kartın üst bölümünde bir arama kutusu ve aramayı temizleyen bir düğme bulunur. Listeyi süzmek için arama kutusuna bir ad yazın.

| Sütun | Açıklama |
|-------|----------|
| **Ad** (Name) | Script-2-API'nin adı. Adın altında açıklaması görünür. Düzenleyiciyi açmak için ada tıklayın. |
| **Uç Noktalar** (Endpoints) | Script-2-API'deki uç nokta sayısı. |
| **Diller** (Languages) | Uç noktaların script dilleri. Örneğin: **JS · GROOVY**. |

Her satırın sonunda bir **⋮** menüsü bulunur. Menüde şu seçenekler yer alır:

| Seçenek | Ne yapar |
|---------|----------|
| **Düzenleyiciyi aç** (Open editor) | Script-2-API'yi düzenleyicide açar. |
| **Çoğalt** (Duplicate) | Script-2-API'nin kopyasını oluşturur. Açılan pencerede kopya için bir ad girin. |
| **Dışa Aktar** (Export) | Dışa/İçe Aktarma Sihirbazı'nı bu Script-2-API için açar. |
| **Sil** (Delete) | Script-2-API'yi siler. Ayrıntılar için [Script-2-API Silme](#script-2-api-silme) bölümüne bakın. |

Sayfanın sağ üstünde iki düğme bulunur:

- **Veriyi Aktar** (*Import*): Dışa/İçe Aktarma Sihirbazı'nı API Creator tipiyle açar. **Dışa Aktar** ile aldığınız bir dosyayı içe aktarır. Ayrıntılar için [Export Import](/tr/admin/secrets-management/export-import) sayfasına bakın.
- **+ Yeni** (*Create*): **Script API Oluştur** penceresini açar. Ayrıntılar için [Yeni Script-2-API Oluşturma](#yeni-script-2-api-olusturma) bölümüne bakın.

## Yeni Script-2-API Oluşturma {#yeni-script-2-api-olusturma}

<Steps>
  <Step title="Menüden Script-2-API Sayfasına Gidin">
    Ana menüde **Geliştirme → API Oluşturucu → Script-2-API** öğesini seçin.
    
    <img src="/images/develop/api-proxy-olusturma/script-api-olusturma-ekrani.png" alt="Script-2-API Oluşturma Ekranı" width="1000" />
  </Step>
  
  <Step title="Yeni API Oluşturun">
    Sağ üstteki **+ Yeni** düğmesine tıklayın. **Script API Oluştur** penceresi açılır.
  </Step>
  
  <Step title="API Bilgilerini Doldurun">
    API'nin adını ve açıklamasını girin. **İlk uç nokta** bölümünde ilk uç noktayı tanımlayın. Sonra **Yeni** düğmesine tıklayın. Apinizer Script-2-API'yi bu uç nokta ve bir başlangıç script'iyle kaydeder. Sonra düzenleyiciyi açar.
    
    <img src="/images/develop/api-proxy-olusturma/script2api-new.png" alt="API Bilgilerini Doldurma" width="1000" />
  </Step>
  
  <Step title="Uç Nokta Ekleyin">
    Başka bir uç nokta eklemek için düzenleyicide **API Uç Noktaları** başlığının yanındaki **+** düğmesine tıklayın. Script-2-API'de hiç uç nokta yoksa orta bölümdeki **Ekle** düğmesine de tıklayabilirsiniz.
    
    <img src="/images/develop/api-proxy-olusturma/script2api-neww.png" alt="Uç Nokta Ekleme" width="1000" />
  </Step>
</Steps>

**Script API Oluştur** penceresinde şu alanlar bulunur:

| Alan | Açıklama |
|------|----------|
| **Ad** (Name) | Zorunlu. Script-2-API'nin adı. Apinizer adın benzersiz olup olmadığını denetler. |
| **Açıklama** (Description) | Script-2-API'nin kısa açıklaması. |
| **HTTP Metot** (HTTP Method) | İlk uç noktanın metodu. |
| **Yol** (Path) | İlk uç noktanın yolu. Yol "/" ile başlamalıdır. |
| **Dil** (Language) | İlk uç noktanın script dili: **JavaScript** veya **Groovy**. |

Başlangıç script'i kısa bir JSON iletisi döndürür. Script'i değiştirmek için düzenleyicide **Yapılandır** düğmesine tıklayın.

## Script-2-API Düzenleyicisi

**Script API Oluştur** penceresinde **Yeni** düğmesine tıkladığınızda düzenleyici açılır. Düzenleyiciyi listedeki **Düzenleyiciyi aç** seçeneğiyle de açabilirsiniz. Düzenleyicide bir sol sütun, bir orta bölüm ve üstte bir düğme çubuğu bulunur.

:::info

Veri değiştiren her panel ve pencere kendi **Kaydet** düğmesini taşır. **Kaydet** değişikliği hemen saklar.

:::

### Sol Sütun

- Script-2-API'nin adı ve açıklaması üstte yer alır. Özet satırı uç nokta ve API Proxy sayısını gösterir.
- Kalem düğmesi **Ad ve açıklamayı düzenle** penceresini açar. Adı ve açıklamayı değiştirin. Sonra **Kaydet** düğmesine tıklayın. Apinizer değişikliği hemen saklar.
- **API Uç Noktaları** uç noktaları listeler. **+** düğmesi yeni uç nokta ekler.
- Her uç nokta kartında metot, yol, dil rozeti (**GROOVY** veya **JS**) ve açıklama görünür.
- Uç noktanın tam yolunu ve açıklamasını görmek için imleci kartın üzerinde tutun.
- Uç noktayı seçmek için karta tıklayın. Seçili kart vurgulanır.

### Orta Bölüm

Orta bölümün üstünde seçili uç noktanın metodu, yolu, dili ve açıklaması görünür. Sağda uç noktanın işlemleri bu sırayla yer alır:

| Düğme | Ne yapar |
|-------|----------|
| **Dene** (Try it) | Bu uç nokta için **Dene** panelini açar. Ayrıntılar için [Script-2-API'yi Deneme](#script-2-apiyi-deneme) bölümüne bakın. Script-2-API'nin API Proxy'si yoksa düğme devre dışıdır. Nedenini görmek için imleci düğmenin üzerinde tutun. |
| **Yapılandır** (Configure) | Uç noktanın **Yapılandırma** panelini açar. Ayrıntılar için [Uç Nokta Oluşturma](#uc-nokta-olusturma) bölümüne bakın. |

**Yapılandır** düğmesini ve **Salt okunur · düzenlemek için Yapılandır'ı kullanın** notunu yalnız API Creator'ı yönetebilen kullanıcılar görür.

Başlığın altında uç noktanın script'i yer alır. Kod görünümünde satır numaraları bulunur. Görünüm sayfayı doldurur. Script salt okunurdur. Script'i değiştirmek için **Yapılandır** düğmesine tıklayın.

### Üstteki Düğmeler

Düzenleyicinin üstündeki düğme çubuğunda şu düğmeler bulunur. Düğmeler soldan sağa bu sırayla dizilir.

| Düğme | Ne yapar |
|-------|----------|
| **Geri** (Back) | Script-2-API listesine döner. |
| **Dışa Aktar** (Export) | Dışa/İçe Aktarma Sihirbazı'nı bu Script-2-API için açar. |
| **Spec'leri göster** (Show Specs) | Script-2-API'nin OpenAPI tanımını bir pencerede gösterir. Pencerede **Open API Yaml** ve **Open API JSON** sekmeleri bulunur. Tanımı kopyalayabilir veya indirebilirsiniz. |
| **Geçmiş** (History) | **Denetim ve Geri Yükleme** başlıklı yan paneli açar. Ayrıntılar için [Varlık Yaşam Döngüsü](/tr/concepts/temel-kavramlar/varlik-yasam-dongusu) sayfasına bakın. |
| **Proxyleri Yönet** (Manage API Proxies) | Script-2-API'den oluşturulan API Proxy'leri ve yükleme durumlarını gösterir. Ayrıntılar için [Yükle (Deploy)/Yeniden Yükle (Redeploy)](#yukle-yeniden-yukle) bölümüne bakın. |
| **API Proxy Oluştur** (Create API Proxy) | **API Proxy Oluştur** penceresini açar. Ayrıntılar için [Script-2-API'den API Proxy Oluşturma](#script-2-apiden-api-proxy-olusturma) bölümüne bakın. |

Yeni bir uç noktada panelin başlığı **Yeni uç nokta** olur. Yeni uç nokta bir başlangıç script'iyle gelir. Var olan bir uç noktada başlık metodu ve yolu gösterir.

**Kod parçaları** satırı düzenleyicinin üstündedir. Hazır kodu imlecin bulunduğu yere eklemek için bir kod parçasına tıklayın. Eklenen kod seçili dile uyar. Kod parçaları şunlardır: **Başlık oku**, **Sorgu parametresi oku**, **JSON döndür** ve **Hata döndür**.

**Değişkenler** bandı, **Kod parçaları** satırı ile araç çubuğu arasında yer alır. Script-2-API backend'i çağırmadığı için bantta iki şerit bulunur. Bir çipe tıklayın. Apinizer değişkenin adını imlecin bulunduğu yere ekler. Bant şu bölümlerden oluşur:

| Bölüm | İçerik |
|-------|--------|
| **İstemci → Gateway** (okunur) | `requestHeaderMapFromClient`, `requestBodyTextFromClient`, `requestUrlParamMapFromClient`, `requestFormUrlEncodedListFromClient`, `requestFormDataListFromClient` |
| **Gateway → İstemci** (yanıtta yazılır) | `responseHeaderMapToClient`, `responseBodyTextToClient`, `statusCodeToClient`, `responseErrorMessageToClient` |
| **Ortak** (Shared) | `customVariableMap`, `environmentVariableMap`, `credentialMap`, `cache`, `stopFlowAsSuccess` |
| **Bağlam** (Context) | Arama kutulu bir liste. Değerler şu gruplarda yer alır: Request, Response, Metadata, Date/Time, Error ve Credential. Eklemek istediğiniz bağlam değerini seçin. Apinizer değeri imlecin bulunduğu yere ekler. |

Her çipin bir de **▾** bölümü vardır. **▾** bölümüne tıklayın. Açılan menü, değişkenin tipine uygun hazır kodu ve **Adını kopyala** seçeneğini sunar. Map tipindeki bir değişken için kod işlemleri şunlardır: **Değer oku**, **Anahtar var mı kontrol et** ve **Tümünü dolaş**. Yazılabilir bir Map ayrıca **Değer yaz** ve **Anahtarı sil** işlemlerini sunar. Gövde değişkenleri ayrıca **JSON olarak oku** işlemini sunar.

Mavi çip kenarlığı, değişkenin yazılabilir olduğunu gösterir. Kesikli kenarlık, değişkenin ekranda yeni olduğunu gösterir. **Tümünde ara** düğmesine tıklayın. Yan panelin **Değişkenler** sekmesi açılır. **Gizle** düğmesi bandı daraltır. **Göster** düğmesi bandı yeniden açar.

Panelin altında şu düğmeler bulunur:

- **Uç noktayı sil** onay aldıktan sonra uç noktayı siler. Bu düğme yeni bir uç noktada görünmez.
- **İptal** paneli kapatır ve değişikliklerinizi atar. Uç nokta yeniyse Apinizer uç noktayı oluşturmaz.
- **Kaydet** tanımı ve script'i birlikte saklar.

**Kaydet** düğmesi ve Ctrl+S (macOS'ta Cmd+S) önce script'i kontrol eder. Script hata içeriyorsa **Script hata içeriyor** penceresi sorar: **Script'te N hata var. Script çalışma anında hata verebilir. Yine de kaydedilsin mi?** Uç noktayı hatalarla kaydetmek için **Yine de kaydet** düğmesine tıklayın. Hataları düzeltmek için **Geri dön** düğmesine tıklayın. Kontrol, kaydetme işlemini hiçbir zaman engellemez.

### Script Düzenleyicisi {#script-duzenleyicisi}

**Yapılandırma** panelindeki script düzenleyicisi, Script politikasının düzenleyicisidir. Kodun üstünde **Değişkenler** bandı, bir araç çubuğu ve durum metni bulunur. Kodun altında bir sorun listesi yer alır. Yan panel kodun yanında açılır. Araç çubuğu ve sorun listesi şu öğeleri içerir:

- Motor etiketi, seçili dilin çalışma motorunu gösterir: **Groovy 3.0.25** veya **JavaScript (GraalJS)**.
- **Öner**, kod tamamlamayı açar. Kısayollar: Ctrl+Space, Alt+Space ve Ctrl+.
- **Kontrol et**, script'i Worker'da çalışma motoruyla derler. **Kontrol et** hiçbir şeyi çalıştırmaz. Projenin yayınlanmış bir ortamını gerektirir. Projede yayınlanmış ortam yoksa yalnızca editör kontrolleri çalışır.
- **Kontrol et** düğmesinin yanındaki durum metni sonucu gösterir. Örnekler: **Hatasız derlendi (N ms).** veya **Derleme hatası var.**
- **Dene**, **Script'i Test Etme** penceresini açar. Script boşsa düğme devre dışıdır. Ayrıntılar için [Script'i Test Etme](#scripti-test-etme) bölümüne bakın.
- **Katalog ve sınıflar**, yan paneli açar. **Paneli gizle**, paneli kapatır. Yan panel kapalı başlar. Böylece düzenleyici genişliğini korur.
- Sorun listesi **Sorun yok** yazar. Aksi halde hata ve uyarı sayısını gösterir. Her satır konumu gösterir. Örnek: **Satır 3:5**. İmleci o satıra götürmek için bir satıra tıklayın.

Düzenleyici, siz yazarken uyarı verir. Örneğin salt-okunur bir değişkene değer atamasını, `println` veya `console.log` çağrısını ve Groovy'de `"${ad}"` ifadesini işaretler. Script bu ifadeyle ortam değişkenini çözmez. `environmentVariableMap.get("ad")` kullanın.

Java sınıfları yalnızca Groovy script'lerinde kullanılabilir. Worker'daki JavaScript script'leri Java sınıfı yükleyemez; `Java.type` kullanılamaz.

Yan panelde üç sekme bulunur:

- **Değişkenler**: Değişkeni adıyla arayın. Adı kopyalamak için bir satıra tıklayın. Adı veya hazır kodu eklemek için ⋮ menüsünü kullanın.
- **Katalog**: Hazır kodları listeler. Kodu eklemek için **İmlece ekle** düğmesine tıklayın. Kodu kopyalamak için **Kopyala** düğmesine tıklayın. Script-2-API'de **Katalog** yalnız dört öğe gösterir: **İstek başlığını oku**, **Sorgu parametresini oku**, **JSON yanıt döndür** ve **Hata yanıtı döndür**. Script politikasının proxy akışı öğeleri burada görünmez. Bu öğeler backend değişkenlerini kullanır. Script-2-API backend'i çağırmaz.
- **Sınıflar**: Sınıfı adıyla arayın. Bir sınıf eklediğinizde import satırı da eklenir. Bu sekme yalnız Groovy için kullanılabilir.

**Değişkenler** bandı, araç çubuğu ve kontroller Script politikasındaki gibi çalışır. Bir fark vardır. Bu ekranda bir çipe tıklamak veya **Bağlam** kutusundan değer seçmek, adı veya değeri imlecin bulunduğu yere ekler. Script politikasında bu işlemler kopyalar. Kod tamamlama öğelerinin, editör kontrollerinin ve derleme kontrolü mesajlarının tam listesi için Script politikası sayfasındaki [Script Gövdesi ve Değişken Yönetimi](/tr/develop/politikalar/script#adım-6-script-gövdesi-ve-değişken-yönetimi) bölümüne bakın.

Ayrıntılar için [Flow Variables](/tr/develop/politikalar/script#flow-variables-akış-değişkenleri), [Ortam Değişkenlerine Erişim](/tr/develop/politikalar/script#ortam-değişkenlerine-erişim), [Credential Bilgilerine Erişim](/tr/develop/politikalar/script#credential-bilgilerine-erişim) ve [Cache Erişimi](/tr/develop/politikalar/script#cache-erişimi) bölümlerine bakın.

## Script'i Test Etme {#scripti-test-etme}

**Script'i Test Etme** penceresi, **Yapılandırma** panelindeki script'i örnek veriyle çalıştırır. Script'i kaydetmediyseniz de çalıştırır. Pencere API Proxy gerektirmez. Apinizer hiçbir şeyi kaydetmez ve backend'i çağırmaz.

<Steps>
  <Step title="Pencereyi Açın">
    Bir uç noktada **Yapılandır** düğmesine tıklayın veya yeni uç nokta için **+** düğmesine tıklayın. Script düzenleyicisinin araç çubuğundaki **Dene** düğmesine tıklayın. Bu düğme, uç noktanın başlığındaki **Dene** düğmesi değildir. **Script'i Test Etme** penceresi açılır. Başlığın yanındaki rozet script'in dilini gösterir.
  </Step>

  <Step title="Hattı Kontrol Edin">
    **Script'iniz nerede çalışıyor?** başlığının altında **İstek** veya **Yanıt** seçilidir. Pencere, script'inizdeki değişkenlerin çalıştığı hattı seçer. İstemciye yanıt yazan bir script **Yanıt** hattında çalışır. Hattı değiştirebilirsiniz.
  </Step>

  <Step title="Ortamı Seçin">
    **Ortam** listesinden bir ortam seçin. Ortam seçmeden script'i çalıştıramazsınız.
  </Step>

  <Step title="Test Verisini Girin">
    **1 Test verisi** bölümünde örnek veriyi girin. Yalnız script'inizin okuduğu değerleri doldurun. Diğer değerler boş kalabilir.
  </Step>

  <Step title="Test Bağlamını Ayarlayın (İsteğe Bağlı)">
    Script'iniz istemciyi veya HTTP metodunu okuyorsa kartların altındaki **Test bağlamı** kutusunu kullanın. **Credential (doğrulanan istemci)** listesinden bir credential seçin. Pencere `credential_*` değerlerini ve `credentialMap` değişkenini doğrulanmış bir çağrıdaki gibi doldurur. Varsayılan değer **Credential yok** seçeneğidir. **HTTP metodu** listesinden bir metot seçin. Pencere `request_httpMethod` değerini doldurur. Varsayılan değer POST'tur.
  </Step>

  <Step title="Script'i Çalıştırın">
    **Script'i Çalıştır** düğmesine tıklayın veya Ctrl+Enter tuşlarına basın (macOS'ta Cmd+Enter). Ortam seçmeden ve script yazmadan düğme devre dışı kalır. Sonuç **3 Sonuç** bölümünde görünür.

    Pencere çalıştırmadan önce editör kontrollerini ve derleme kontrolünü çalıştırır. Script hata içeriyorsa **Script hata içeriyor** penceresi sorar: **Script'te N hata var. Yine de çalıştırılsın mı?** Script'i çalıştırmak için **Yine de çalıştır** düğmesine tıklayın. Hataları düzeltmek için **Geri dön** düğmesine tıklayın.
  </Step>
</Steps>

Pencerede üç sütun bulunur:

| Sütun | Açıklama |
|-------|----------|
| **1 Test verisi** | Bir bilgi mesajı, script'inizin okuduğu ve hâlâ boş olan verileri listeler. Bu verileri eklemek için mesajdaki bir düğmeye tıklayın. Mesajın altında kartlarda örnek mesajlar yer alır: **From Client**, **To Backend**, **From Backend** ve **To Client**. Pencere, script'inizin kullandığı mesajları ve alanları gösterir. Alanlar şunlardır: **Başlıklar**, **Parametreler**, **Request URL Path**, **Gövde**, **Hata Mesajı** ve **Durum Kodu**. **script okur** ve **script değiştirir** rozetleri script'inizin kullandığı alanları işaretler. Karta başka bir alan eklemek için **Alan ekle:** satırındaki alana tıklayın. Doldurmadığınız bir alanı gizlemek için **Gizle** düğmesine tıklayın. **Test bağlamı** kutusu sütunun sonundadır. |
| **2 Script** | Kod tamamlama, editör kontrolleri, derleme kontrolü (**Kontrol et**) ve sorun listesi olan bir kod düzenleyicisinde script. Ayrıntılar için [Script Düzenleyicisi](#script-duzenleyicisi) bölümüne bakın. Script'i değiştirip yeniden çalıştırın. Pencereyi kapattığınızda değişiklikleriniz **Yapılandırma** paneline aktarılır. Script boşsa pencere **Script boş. Test etmek için bir script yazın.** uyarısını gösterir. Düzenleyicinin altında **Değişkenler** paneli bulunur. Bir değişkenin adını kopyalamak için değişkene tıklayın. Script'inizde geçen değişkenler vurgulanır. Her değişken grubunun rozeti seçili hattaki erişimi gösterir: **Yalnızca okunur**, **Okunur ve değiştirilir** veya **Burada kullanılamaz**. |
| **3 Sonuç** | Son çalıştırmanın sonucu. Ayrıntılar aşağıdaki tabloda yer alır. |

Sonuçta şu bölümler bulunur:

| Bölüm | Açıklama |
|-------|----------|
| Sonuç durumu | **Başarılı** veya **Başarısız**, milisaniye cinsinden çalışma süresi ve değişiklik sayısı. **Değişiklik yok** yazıyorsa script hiçbir şeyi değiştirmemiştir. İlk çalıştırmadan önce sütun **Henüz sonuç yok** mesajını ve bir ipucu gösterir. |
| Değişiklikler | Başlık **Backend API'ye giden istek** veya **Client'a giden yanıt** olur. Tablolar sonucu **To Backend** veya **To Client** test verisiyle karşılaştırır. Her satırda bir rozet bulunur: **eklendi**, **değişti**, **silindi** veya **değişmedi**. Değişmeyen satırları görmek için **Değişmeyen N satırı göster** düğmesine tıklayın. |
| **Gövde** | Script gövdeyi değiştirdiyse yeni gövde **değişti** rozetiyle görünür. Eski gövdeyi görmek için **Script öncesi gövdeyi göster** düğmesine tıklayın. |
| Backend URL ve durum kodu | Değer varsa sonuç **Özelleştirilmiş Backend URL** ve **Durum Kodu** satırlarını gösterir. |

| Akışın kesilmesi | Script bir hata mesajı ayarlarsa sonuçta **Akış burada durur. Client bu hatayı alır.** iletisi ve durum kodu görünür. `stopFlowAsSuccess` true ise sonuçta **Akış burada SUCCESS sonucuyla durur. Client bu mesajı alır.** iletisi görünür. |

:::info

Script'i Test Etme penceresi script'i gateway ile aynı motorlarda çalıştırır: Groovy ve JavaScript (GraalJS). JavaScript script'leri Java sınıfı yükleyemez; `Java.type` kullanılamaz. Java sınıfları yalnızca Groovy script'lerinde kullanılabilir.

:::note

Script'i Test Etme penceresi gizli değerleri `******` olarak maskeler. Bu, credential'ın parolası, credential'ın diğer gizli alanları ve gizli ortam değişkenleri için geçerlidir. Script'i Test Etme yalnızca test projesinin ve yönetici projesinin anahtar nesnelerini (sertifika, anahtar, keystore ve JWK) alır. Sertifikalar ve açık anahtarlar gerçek değerleriyle gelir. Özel anahtarlar, gizli anahtarlar, keystore'lar ve JWK'ler yalnızca adıyla bulunur; değerleri null olur. Yalnız projenin credential'ları kullanılabilir. Derleme kontrolü ve Dene, API Creator veya Genel Ayarlar için MANAGE yetkisi olan kullanıcılara açıktır. Cache yazmaları gerçek cache'e değil, geçici bir test cache'ine gider.

## Script-2-API'yi Deneme {#script-2-apiyi-deneme}

Uç noktanın başlığındaki **Dene** düğmesi **Dene** panelini açar. Bu panel **Script'i Test Etme** penceresinden farklıdır. **Yapılandırma** panelindeki script düzenleyicisinin araç çubuğunda da bir **Dene** düğmesi bulunur. Bu düğme **Script'i Test Etme** penceresini açar.

- **Script'i Test Etme** penceresi, **Yapılandırma** panelindeki script'i çalıştırır. Script'in kaydedilmiş olması gerekmez. Pencere API Proxy gerektirmez.
- **Dene** paneli, kaydedilmiş script'e bir API Proxy üzerinden gerçek bir istek gönderir.

:::note

**Dene** paneli isteği Test Konsolu'nun istek gönderme hizmetiyle gönderir. Bu nedenle **Test** kategorisinde **Çalıştır** yetkisine sahip olmanız gerekir. Yetkiler için [Yetkilendirme Matrisi](/tr/admin/user-access-management/yetkilendirme-matrisi) sayfasına bakın.

:::

:::info

**Dene** paneli Script-2-API'ye yönlenen bir API Proxy gerektirir. Script-2-API'nin API Proxy'si yoksa **Dene** düğmesi devre dışıdır. Önce bir API Proxy oluşturun. Ayrıntılar için [Script-2-API'den API Proxy Oluşturma](#script-2-apiden-api-proxy-olusturma) bölümüne bakın.

:::

**Dene** paneli Mock API'deki panelle aynıdır. Panelin tüm bölümleri için [Mock API'yi Deneme](/tr/develop/api-proxy-olusturma/api-creator-mock-api-olusturma#mock-apiyi-deneme) bölümüne bakın.

<Steps>
  <Step title="Paneli Açın">
    Düzenleyicinin sol sütununda bir uç nokta seçin. Uç noktanın başlığındaki **Dene** düğmesine tıklayın. Sağdan **Dene** paneli açılır.
  </Step>

  <Step title="API Proxy ve Ortamı Seçin">
    **API Proxy** ve **Ortam** listeleri aynı satırdadır. Panel ilk API Proxy'yi ve bu API Proxy'nin ilk ortamını seçer. Başka bir API Proxy kullanmak için **API Proxy** listesinden seçim yapın. Sonra **Ortam** listesinden ortamı seçin. **Ortam** listesi yalnız API Proxy'nin yüklü olduğu ortamları gösterir.
  </Step>

  <Step title="İsteği Hazırlayın">
    **İstek** bölümü metodu ve tam istek adresini gösterir. İsteği **Parametreler**, **Başlıklar** ve **Gövde** sekmelerinde değiştirin.

    - Her yol parametresi için bir değer girin. Yoldaki her parametre için bir alan görünür.
    - Sorgu parametresi eklemek için **Parametreler** sekmesinde **+ Ekle** düğmesine tıklayın.
    - Başlık eklemek için **Başlıklar** sekmesinde **+ Başlık** düğmesine tıklayın. Sekme `Accept: application/json` başlığıyla başlar.
    - İstek gövdesini **Gövde** sekmesine yazın. Bu sekme gövde taşıyan metotlarda görünür. Örneğin POST, PUT ve PATCH. Bu metotlarda panel `Content-Type: application/json` başlığını da ekler.
  </Step>

  <Step title="İsteği Gönderin">
    Adres satırının sonundaki **Gönder** düğmesine tıklayın. **Yanıt** bölümü durum kodunu, yanıt süresini, boyutu, yanıt gövdesini ve yanıt başlıklarını gösterir.
  </Step>
</Steps>

İstek kartında **cURL kopyala** ve **Sıfırla** düğmeleri de bulunur. Yüklenmemiş bir API Proxy **Yüklenmedi** rozetiyle görünür. Panel Script-2-API için hiç API Proxy bulamazsa **Bu API için henüz API Proxy yok** başlığını ve **API Proxy Oluştur** düğmesini gösterir.

## Script-2-API'den API Proxy Oluşturma {#script-2-apiden-api-proxy-olusturma}

:::info

Script-2-API'den API Proxy oluşturmak için en az bir uç nokta olmalıdır. Uç nokta yoksa **API Proxy Oluştur** düğmesi devre dışıdır.

:::

Script-2-API'yi API Proxy olarak erişime açmak için düzenleyicinin üstündeki **API Proxy Oluştur** düğmesine tıklayın.

<img src="/images/develop/api-proxy-olusturma/script-api-proxy-olustur-butonu.png" alt="Proxy Oluştur Butonu" width="1000" />

**API Proxy Oluştur** penceresi açılır.

<img src="/images/develop/api-proxy-olusturma/script-api-proxy-olusturma-ekrani.png" alt="API Proxy Oluşturma Ekranı" width="1000" />

Pencere Script-2-API'nin adından bir ad ve göreli yol önerir. Gerekirse bunları değiştirin. Pencerede şu alanlar bulunur:

| Alan | Açıklama |
|------|----------|
| **Proxy adı** (Proxy name) | Zorunlu. Apinizer adın benzersiz olup olmadığını denetler. |
| **Göreli Yollar** (Relative Paths) | İstemcinin API Proxy'ye eriştiği yollar. Projede göreli yol öneki varsa önek yolların başında görünür. Her yol "/" ile başlamalıdır. Yol eklemek için **+ Yol ekle** düğmesine tıklayın. |
| **Metotlar** (Methods) | Listeden bir veya birkaç metot seçin: GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS veya QUERY. Hiçbirini seçmezseniz Apinizer tüm metotları yönlendirir. |
| **Host'lar** (Hosts) | **+ Host ekle** düğmesiyle host ekleyin. |
| **Başlıklar** (Headers) | **+ Başlık ekle** düğmesiyle istek başlığı ekleyin. Her başlık için ad ve değer girin. |
| **Kategori Listesi** (Category List) | Kategori adını yazın ve Enter tuşuna basın. |
| **Yüklenecek ortamlar** (Deploy to) | API Proxy'nin yükleneceği ortamları işaretleyin. Her ortamın erişim adresi yanında görünür. |
| **Gateway URL** | API Proxy'nin gateway adresinin önizlemesi. |

**Göreli Yollar**, **Metotlar**, **Host'lar** ve **Başlıklar** alanları **İstemci Rotası** (*Client Route*) bölümünü oluşturur. En az bir yol, metot, host veya başlık tanımlayın. Ayrıntılar için [Client Route Ayarları](/tr/develop/api-proxy-olusturma/client-route-ayarlari) sayfasına bakın.

İlk ortam varsayılan olarak işaretli gelir. API Proxy'yi şimdi yüklemek istemiyorsanız işareti kaldırın.

**Oluştur ve yükle** (*Create and deploy*) düğmesine tıklayın. Apinizer API Proxy'yi oluşturur ve işaretli ortamlara yükler. Hiçbir ortam işaretlemezseniz Apinizer yalnız API Proxy'yi oluşturur. API Proxy oluşturmadan pencereyi kapatmak için **İptal** düğmesine tıklayın.

Bu adımdan sonra yapılabilecekler API Proxy dokümanı ile aynıdır. Ayrıntılar için [API Proxy Oluşturma](/tr/develop/api-proxy-olusturma) sayfasına bakın.

:::note

Bir Script-2-API için birden fazla API Proxy oluşturabilirsiniz.

:::
