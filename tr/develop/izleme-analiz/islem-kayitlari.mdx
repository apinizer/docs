API Proxy üzerinde yapılan değişiklikler için hangi kullanıcının, ne zaman, hangi değişikliği yaptığını gösteren denetim kayıtları tutulur.

:::info

Eski sürümlerdeki **İşlem Kayıtları** sekmesi kaldırılmıştır. Denetim kayıtlarına artık API Proxy sayfasının sağ üst köşesindeki işlemler menüsünde yer alan **Denetim ve Geri Yükleme** seçeneğiyle açılan panelden ulaşılır.

:::

## Denetim Kayıtlarını Görüntüleme

**Denetim ve Geri Yükleme** seçeneği, işlemler menüsünde denetim kayıtlarını görüntüleme yetkisi olan kullanıcılar için görünür. Açılan panel, API Proxy'ye ait denetim kayıtlarını aşağıdaki sütunlarla listeler:

| Sütun | Açıklama |
|-------|----------|
| **Operasyon Tipi** | Yapılan işlemin tipi; altında işlemin tarihi gösterilir |
| **Nesne Adı** | İşlemin yapıldığı nesnenin adı |
| **Korelasyon ID** | İşlemin korelasyon kimliği |
| **Kullanıcı · Kaynak** | İşlemi yapan kullanıcı ve işlemin kaynağı |
| **Tarayıcı Bilgisi** | İşlemin yapıldığı istemcinin tarayıcı bilgisi |

Bir kaydın göz simgesine tıklandığında kaydın detayı açılır. Detayda **Değişen alanlar** tablosu ile **JSON Diff** ve **Öncesi & Sonrası** bölümleri yer alır.

Aynı kayıtlar, tüm varlıklar için [Denetim Kayıtları](/tr/admin/audit-compliance/denetim-kayitlari) ekranında da görüntülenebilir.

## Geri Yükleme

Bir kaydın geri yükleme işlemi, API Proxy'yi o kayıttaki anlık görüntüye geri döndürür.

1. Geri yüklemek istediğiniz kaydın geri yükleme simgesine (**Geri Yükle**) tıklayın.
2. **Geri yüklemeyi onayla** penceresinde, istenen değeri (varlığın adı) giriş alanına yazın.
3. **Geri Yükle** butonuna tıklayın.

:::info

Geri yükleme, mevcut kayıtları silmez; yeni bir denetim kaydı oluşturur. Bu nedenle geçmiş yalnızca ileri yönde büyür.

:::
