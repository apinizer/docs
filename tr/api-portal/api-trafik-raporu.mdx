**Ne İşe Yarar?**

* Seçilen dönemde portal abonelik trafiğini ürün × kurum × uygulama kırılımında özetler
* Başarı, blok ve hata adetlerini yan yana koyarak hangi aboneliklerin sorunlu olduğunu gösterir
* Min/max/ortalama yanıt süreleriyle yavaş tüketicileri ayırt etmenizi sağlar
* Canlı trafik ekranına girmeden dönemsel performans karşılaştırması ve raporlama yapmanızı kolaylaştırır

**Kimler Kullanır?**

* **Portal Yöneticileri:** Dönemsel abonelik performansını raporlamak için
* **Ürün Sahipleri:** Kendi API ürünlerinin hangi kurumlarda nasıl kullanıldığını görmek için
* **Destek Ekipleri:** Şikâyet gelen kurum/uygulama çiftini hızlı doğrulamak için

## Ekrana Erişim ve Yetkiler

* Admin panelinde **Portal → Raporlar → API Traffic Report** yolunu izleyin
* Yetkili roller (Portal Manager, Admin, Portal Business) raporu görüntüleyebilir

## Filtreleme

| Filtre | Açıklama |
|--------|----------|
| **API Product** | Tek veya birden çok ürün; boş = tümü |
| **Organization** | Tek veya birden çok kurum; boş = tümü |
| **Tarih aralığı** | Analytic date-range seçici (varsayılan yaklaşık 30 gün) |
| **Search / Clear** | Sorguyu çalıştırır / filtreleri temizler |

:::note
Standalone API Traffic Report sayfasında **App** filtresi yoktur. App filtresi organizasyon overview içindeki traffic panelinde yer alır.
:::

## Rapor Nasıl Okunur?

Her satır bir **API Product · Organization · App** kombinasyonudur.

### Bilgi grubu

| Sütun | Açıklama |
|-------|----------|
| **API Product** | Trafiği ölçülen API ürünü |
| **Organization** | Tüketici kurum |
| **App** | Abone uygulama |

### Trafik metrikleri (adet)

| Sütun | Açıklama |
|-------|----------|
| **Successful** | Başarılı istek sayısı |
| **Blocked** | Kota / rate limit vb. nedeniyle bloklanan istekler |
| **Error** | Hatalı istekler |
| **Total** | Toplam istek |

### Toplam süreler (ms)

| Sütun | Açıklama |
|-------|----------|
| **Min.** | En düşük yanıt süresi |
| **Max.** | En yüksek yanıt süresi |
| **Avg.** | Ortalama yanıt süresi |

**Yorumlama ipuçları:**

* **Blocked** yüksek, Successful düşükse kota veya rate limit baskısı aranır → [Kota / Plan Kullanımı](/tr/api-portal/api-kota-plan-kullanimi)
* **Error** yüksekse ürün, plan veya istemci entegrasyonu incelenir
* **Avg / Max** uç değerleri ayırt eder; tek yavaş uygulama ortalamayı bozuyor olabilir

## Kullanım Senaryoları

* Son 30 günde belirli bir ürünün hangi kurumlarda en çok bloklandığını görüp plan limitlerini gözden geçirirsiniz
* Destek kaydı açan kurumun ortalama süresini diğer kurumlarla karşılaştırırsınız
* Yeni yayınlanan ürünün ilk haftadaki başarı oranını izlersiniz
