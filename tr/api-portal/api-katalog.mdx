**Ne İşe Yarar?**

* Portalda yayınlanacak / yayınlanan API’lerin ürün paketleme durumunu tek listede gösterir
* Hangi proxy’lerin henüz hiçbir API Product’a alınmadığını görünür kılar
* Portal proje kapsamı dışındaki varlıkları ayırt ederek yanlış kapsamda yayın riskini azaltır
* Ürün vitrinine çıkmadan önce envanter ve paketleme kontrolü yapmanızı sağlar

**Kimler Kullanır?**

* **Portal Yöneticileri:** Yayın öncesi paketleme tamamlığını kontrol etmek için
* **API / Ürün Sahipleri:** Kendi proxy’lerinin hangi ürünlerde yer aldığını görmek için
* **Platform Ekipleri:** Kapsam dışı kalan veya unutulmuş API’leri temizlemek için

## Ekrana Erişim ve Yetkiler

* Admin panelinde **Portal → API Catalog** yolunu izleyin
* Liste, aktif portalın scoped-projects kapsamındaki projelerden beslenir

:::

## Filtreleme

| Filtre | Açıklama |
|--------|----------|
| **All Projects** | Projeyi daraltır; temizlenebilir |
| **Packaging Status** | **All** · **Packaged** · **Not Packaged** |
| Arama | Ada veya yola göre ara |
| Clear | Filtreleri temizler |

Sayfalama: 10 / 15 / 25 / 50

## Liste Nasıl Okunur?

Her satır bir **API Proxy** veya **Proxy Group** varlığıdır.

| Sütun | Açıklama |
|-------|----------|
| **Name** | Varlık adı (sıralanabilir) |
| **Type** | **Proxy** veya **Proxy Group** |
| **Base Path** | Temel yol |
| **Operations** | Operasyon sayısı |
| **Project** | Ait olduğu proje (sıralanabilir) |
| **Packaged In Products** | Bağlı olduğu API Product’lar (badge + popover) |
| **Status** | Paketleme / kapsam durumu |

### Durum rozetleri

| Rozet | Anlamı |
|-------|--------|
| **Packaged** | En az bir API Product’a bağlı |
| **Not Packaged** | Henüz hiçbir ürüne alınmamış |
| **Out of Scope** | Aktif portalın proje kapsamı dışında |

## Kullanım Senaryoları

* Yeni portal yayınından önce Not Packaged kalan kritik proxy’leri ürünlere eklersiniz
* Bir proxy’nin yanlışlıkla birden fazla üründe olup olmadığını Packaged In Products üzerinden kontrol edersiniz
* Out of Scope kayıtları görüp portal scoped-projects listesini gözden geçirirsiniz
