:::info

Apinizer'da bir kullanıcının yetkisi olmadığı bir projeye erişmesi hatta aynı proje içinde yetkisi dahilinde olmayan bir eylemi gerçekleştirmesi mümkün değildir. Kullanıcıların herhangi bir projede işlem yapabilmesi için rol/rollerinin olması gerekmektedir.

Sistem ilk kurulduğunda yedi API rolü (Project Owner, API Developer, API Manager, API Creator, API Security, API Analytics, API Tester) ve dört AI rolü (AI Admin, AI Developer, AI Analytics, AI Finance) hazır gelmektedir. Kullanıcıları ya da takımları yetkilendirmek için varsayılan (default) roller kullanılabileceği gibi yeni roller de tanımlanabilir.

:::

Bu roller ve rollerin yetkileri aşağıda detaylı olarak açıklanmıştır:

## Varsayılan Roller ve Yetkileri

Aşağıdaki yetkiler yeni kurulumda oluşturulan varsayılan değerlerdir. Her rolün kategori ve aksiyon bazında tam yetki listesi için [Rol Yetki Detayları](./rol-yetki-detaylari) sayfasına bakınız.

| Rol | Açıklama | Ana Yetkiler (Yönet) |
|-----|----------|--------------|
| **Project Owner** | Projede tüm yetkilere sahip rol. Silinemez. Önceden tanımlı roller arasında **Veri Yaşam Döngüsü** (yasal saklama ve veri yaşam döngüsü temizleme) ve **Promotion** yetkisini taşıyan tek roldür; bu yetkilerin başka rollere açıkça verilmesi gerekir. | Tüm kategorilerde tüm aksiyonlar |
| **API Developer** | API Proxy'leri yönetme, deploy etme ve entegrasyon işlemleri yapabilen rol. | API Yönetimi (Dağıt/Kaldır dahil), API Oluşturucu, API Entegratör, Global Ayarlar, Bağlantılar, Kimlik ve Erişim Kontrolü, Gizli Anahtarlar ve Sertifikalar, İzleme, Analitik ve Raporlar, Proje Yönetimi |
| **API Manager** | API'leri yönetme, analiz ve izleme yapabilen rol. | API Yönetimi (Dağıt/Kaldır dahil), İzleme, Analitik ve Raporlar, Proje Yönetimi |
| **API Creator** | DB to API, Script to API, Mock API gibi API oluşturma işlemleri yapabilen rol. | API Oluşturucu, Proje Yönetimi |
| **API Security** | Kimlik yönetimi, tüketici, certificate ve bağlantı güvenliği yöneten rol. | Kimlik ve Erişim Kontrolü, Gizli Anahtarlar ve Sertifikalar, Bağlantılar, Proje Yönetimi |
| **API Analytics** | Analiz ve raporlama işlemleri yapabilen rol. | Analitik ve Raporlar, Proje Yönetimi |
| **API Tester** | Test işlemleri yapabilen rol. | Test, Proje Yönetimi |
| **AI Admin** | AI geliştirme, AI bütçe/kota ve AI analitik üzerinde tam yetkiye sahip rol. | AI Geliştirme (Dağıt/Kaldır dahil), AI Bütçe/Kota |
| **AI Developer** | AI varlıklarını yöneten, taşıyan ve yükleyen rol. | AI Geliştirme (Dağıt/Kaldır dahil) |
| **AI Analytics** | AI geliştirme, AI bütçe/kota ve AI analitiği salt okunur izleyen rol. | — (yalnızca Görüntüle) |
| **AI Finance** | Yalnızca AI bütçe/maliyet ve AI analitiği görüntüleyen rol. | — (yalnızca Görüntüle) |

:::note

Sistem rolleri silinemez.

:::

:::info

Yeni bir proje açıldığında, projeyi oluşturan kullanıcı ve **Proje Yöneticisi** yetkisine sahip tüm kullanıcılar projeye otomatik olarak **Project Owner** rolüyle eklenir.

:::

Bir kullanıcının ya da takımın varsayılan rollerdeki yetkilerden daha fazlasına ya da yetkilerin daha azına sahip olması isteniyorsa, tamamen buna göre özelleştirilebilecek yeni bir rol oluşturulabilir.

## Yeni Bir Rol Oluşturma

Rol oluşturma ayarlarını içeren görsele aşağıda yer verilmiştir:

  src="/images/yonetici/roller.png"

/>

Rol oluşturma konfigürasyonu için kullanılan alanlar aşağıdaki tabloda görülmektedir.

| Alan                         | Açıklama                                                                                                                    |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Ad**               | Oluşturulan rol için rol adı bilgisidir.                                                                                    |
| **Açıklama**  | Oluşturulan rol ile ilgili yönetimi kolaylaştırmak için açıklama yazılabilir.                                               |
| **Yetki** _(Authorities)_    | Oluşturulan rolün sahip olacağı yetkilerin seçildiği alandır. Yetkiler, kategori ve aksiyon bazında ilgili checkbox seçilerek eklenir. **Tümünü Seç** / **Tümünü Temizle** butonları ve **Şablon Yükle** menüsü (API Geliştirici, API Yöneticisi, API Oluşturucu, Güvenlik Yöneticisi, Analitik Uzmanı, Test Uzmanı, Görüntüleyici) ile yetkiler toplu olarak seçilebilir. |

:::warning

Silinen roller, sistem tarafından projelerden ve takımlardan da silinir.

:::
