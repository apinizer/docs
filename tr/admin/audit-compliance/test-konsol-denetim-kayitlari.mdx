:::info

**Yönetim → Denetim & Uyumluluk → Test Konsol Denetim Kayıtları** yolunu izleyerek bu ekrana erişebilirsiniz.

:::

Test Konsol Denetim Kayıtları ekranı, Yönetim Konsolu'ndaki Test Konsolu (Quick Test) aracıyla yapılan her API çağrısını kaydeder — çağrıyı yapan kullanıcı, hedef API Proxy ve metot, çağrının sonucu ve çağrının geldiği istemci adresiyle birlikte.

## Kolonlar

| Kolon | Açıklama |
|---|---|
| **Tarih** | Test çağrısının yapıldığı zaman damgası. |
| **Kullanıcı Adı** | Çağrıyı Test Konsolu üzerinden başlatan kullanıcı. |
| **Apinizer Correlation ID** | Çağrının denetim/log kayıtlarıyla eşleştirilmesini sağlayan korelasyon kimliği. |
| **URL** | Çağrının yapıldığı tam adres. |
| **Proje** | Test edilen API Proxy'nin ait olduğu proje. |
| **API Proxy** | Test edilen API Proxy'nin adı. |
| **Metot/Endpoint** | Test edilen API metodu/endpoint'i. |
| **İstemci IP** | Çağrıyı Test Konsolu üzerinden başlatan kullanıcının IP adresi. |
| **Durum** | Çağrının döndürdüğü durum kodu. |

:::note

**İstemci IP** kolonu bu sürümle eklenmiştir; bu tarihten önce oluşturulmuş kayıtlarda boş görünür.

:::

## Filtreleme

Sayfanın üst tarafında bulunan filtre bölümünden aşağıdaki kriterlerle sonuçları daraltabilirsiniz: tarih aralığı, istemci IP, Correlation ID, kullanıcı (birden çok seçilebilir), proje (birden çok seçilebilir), API Proxy (birden çok seçilebilir) ve API metodu. **Tarih Aralığı** alanları takvimden seçilebileceği gibi doğrudan klavyeden de girilebilir ve her iki alan saat bilgisi de taşır. Takvimden bir gün seçtiğinizde saat 00:00 olarak gelir; saati 00:00 olan sınır gün olarak yorumlanır: bitiş tarihi o günü son kaydına kadar kapsar, gece yarısında kesilmez. Aralığı belirli bir ana daraltmak isterseniz ilgili alana saat girin. Temizle butonu ile filtre içerikleri sıfırlanabilir.

:::warning

Test Konsolu'nu çalıştıran kullanıcının IP bilgisinin doğru alınabilmesi için kurumun kullandığı yük dengeleyici veya güvenlik duvarı tarafından X-Forwarded-For başlığı ile gerçek IP'sinin iletilmesi gereklidir.

:::
