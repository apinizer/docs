## Kaydedilen İşlemler

Ekran, kimlik bilgilerine tanınan API Proxy ve API Proxy Grubu erişim izinlerinde gerçekleşen her **verme** (Grant) ve **kaldırma** (Revoke) olayını kayıt altına alır. Her kayıtta üç bilgi birlikte gösterilir:

- **Kaynak Tipi**: İznin hangi akıştan geldiğini belirtir. Tabloda **ACL** veya **PORTAL** değeri olarak görüntülenir. **ACL**, izni Kimlik ekranlarından manuel olarak veya bir sözleşme üzerinden verilen/kaldırılan tüm işlemleri kapsar; **PORTAL**, API Portal üzerinden ürün aboneliği yoluyla oluşan işlemleri kapsar.
- **Operasyon Tipi**: **Grant** (izin verildi) veya **Revoke** (izin kaldırıldı).
- **Sebep Tipi**: İşlemi tetikleyen olayı belirtir.

Bir sözleşme (Sözleşmeler ekranı) üzerinden kimlik bilgisine API Proxy veya API Proxy Grubu erişimi verildiğinde, bu işlem de bu ekranda **Grant** kaydı olarak görünür; Kaynak Tipi, Kimlik ekranından yapılan manuel verme işlemleriyle aynı şekilde **ACL** olarak işaretlenir. Kayıt, iznin sözleşme üzerinden mi yoksa manuel mi verildiğini ayrıca belirtmez.

### Sebep Tipleri

| Sebep Tipi | Açıklama |
|---|---|
| **API Proxy Grubu Silindi** | Kimlik bilgisine erişim izni tanımlı bir API Proxy Grubu silindiğinde, ilgili izin kaldırılır. |
| **API Proxy Grubu İzni** | Kimlik ekranından veya bir sözleşme üzerinden bir API Proxy Grubu izni verildiğinde ya da kaldırıldığında oluşur. |
| **API Proxy Grubu İzninin Süresi Doldu** | Bir API Proxy Grubu izninin son kullanma tarihi geçtiğinde izin otomatik olarak kaldırılır. |
| **API Proxy Grubu Eklendi** | Kimlik bilgisine zaten izin verilmiş bir API Proxy Grubuna yeni bir API Proxy eklendiğinde, kimlik bilgisi bu yeni API Proxy'ye de erişim kazanır. |
| **API Proxy Grubu Kaldırıldı** | Bir API Proxy Grubundan bir API Proxy çıkarıldığında, kimlik bilgisinin o API Proxy'ye erişimi kaldırılır. |
| **API Proxy Silindi** | Kimlik bilgisine erişim izni tanımlı bir API Proxy silindiğinde, ilgili izin kaldırılır. |
| **API Proxy İzni** | Kimlik ekranından veya bir sözleşme üzerinden bir API Proxy izni verildiğinde ya da kaldırıldığında oluşur. |
| **API Proxy İzninin Süresi Doldu** | Bir API Proxy izninin son kullanma tarihi geçtiğinde izin otomatik olarak kaldırılır. |
| **API Proxy Yöntemi Eklendi** | Kimlik bilgisine zaten izin verilmiş bir API Proxy'ye yeni bir metot eklendiğinde, kimlik bilgisi bu metoda da erişim kazanır. |
| **API Proxy Yöntemi Kaldırıldı** | Bir API Proxy'den bir metot çıkarıldığında, kimlik bilgisinin o metoda erişimi kaldırılır. |
| **Portal Abone Olundu** | API Portal üzerinden bir ürüne abone olunduğunda, ürüne bağlı API Proxy'lere erişim verilir. |
| **Portal Abonelikten Çıkıldı** | API Portal üzerinden bir ürün aboneliği sonlandırıldığında, ürüne bağlı erişim kaldırılır. |
| **Portal Ürünü Silindi** | Bir API Portal ürünü silindiğinde, ürüne bağlı erişimler kaldırılır. |
| **Kimlik Bilgileri Etkinleştirildi** | Devre dışı bırakılmış bir kimlik bilgisi yeniden etkinleştirildiğinde, sahip olduğu tüm izinler yeniden geçerli hale gelir. |
| **Kimlik Bilgileri Devre Dışı Bırakıldı** | Bir kimlik bilgisi devre dışı bırakıldığında, sahip olduğu tüm izinler geçici olarak kaldırılır. |
| **Kimlik Bilgileri Silindi** | Bir kimlik bilgisi silindiğinde, sahip olduğu tüm izinler kalıcı olarak kaldırılır. |

## Filtreleme

Sayfanın üst tarafında bulunan filtre alanlarından kriterler belirleyerek sonuçları tabloda görüntüleyebilirsiniz. Silme butonu ile filtre içerikleri temizlenebilir.

| Alan | Açıklama |
|---|---|
| **Başlangıç tarihi / Bitiş tarihi** | Kayıtları operasyon tarihine göre aralık bazında filtreler. |
| **Operasyon Tipi** | Kayıtları **Grant** veya **Revoke** değerine göre filtreler. |
| **Kimlik Bilgisi Kullanıcı Adı** | Girilen değeri içeren kimlik bilgisi kullanıcı adına sahip kayıtları getirir. |
| **Kimlik Bilgisi E-postası** | Girilen değeri içeren kimlik bilgisi e-postasına sahip kayıtları getirir. |
| **Kimlik Bilgisi Kurum Adı** | Girilen değeri içeren kurum adına sahip kayıtları getirir. |
| **Proje(ler)** | Seçilen proje(ler)e ait API Proxy'lerle ilişkili kayıtları getirir. |
| **API Proxy(ler)** | Seçilen API Proxy(ler)le ilişkili kayıtları getirir. |
| **API Proxy Metot Adı** | Girilen değeri içeren API Proxy metot adına sahip kayıtları getirir. |
| **Yönlendirme Adresi** | Girilen değeri içeren yönlendirme adresine sahip kayıtları getirir. |

## Tablo Kolonları

| Kolon | Açıklama |
|---|---|
| **Operasyon Tarihi** | İşlemin gerçekleştiği tarih ve saat. |
| **Kaynak Tipi** | İznin kaynağı — **ACL** veya **PORTAL**. |
| **Operasyon Tipi** | **Grant** veya **Revoke**. |
| **Sebep Tipi** | İşlemi tetikleyen olay (yukarıdaki tabloya bakınız). |
| **Kimlik Bilgisi Kullanıcı Adı** | İzin sahibi kimlik bilgisinin kullanıcı adı. |
| **Kimlik Bilgisi E-posta** | İzin sahibi kimlik bilgisinin e-posta adresi. |
| **Kimlik Bilgisi Kurum Adı** | Kimlik bilgisinin bağlı olduğu kurum (varsa). |
| **API Proxy Adı** | İzinle ilişkili API Proxy'nin adı. |
| **API Proxy Metot** | İzinle ilişkili API Proxy metodunun adı (metot bazlı izinlerde). |
| **Yönlendirme Adresi** | İlişkili API Proxy metodunun yönlendirme adresi. |
| **Ürün Adı** | Kaynak Tipi **PORTAL** olan kayıtlarda, aboneliğe konu olan API Portal ürününün adı. |

## Excel'e Aktarma

Sayfanın üst kısmındaki Excel simgesiyle, o an uygulanan filtre kriterlerine göre listelenen tüm kayıtlar bir Excel dosyası olarak dışa aktarılabilir.

## ACL Raporundan Farkı

[ACL Raporu](/tr/admin/identity-management/acl-raporu) ekranı, kimlik bilgilerinin **o anki** API Proxy erişim durumunu gösteren bir anlık görüntüdür. ACL Denetim Kayıtları ekranı ise bu erişimlerin zaman içinde nasıl oluştuğunu ve kaldırıldığını gösteren bir **olay geçmişidir** — hangi iznin ne zaman, hangi sebeple verildiğini veya kaldırıldığını içerir.
