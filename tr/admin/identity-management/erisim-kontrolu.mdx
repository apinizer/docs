:::info

Erişim Kontrolü, tüketicilerin API Proxy'lere ve API Proxy Gruplarına erişim izinlerini; bu izinlere bağlı geçerlilik tarihi, ortam bazlı erişim ve izin verilmeyen metot/proxy ayarlarını **tek bir ekrandan** yönetmenizi sağlar. Bu sayfa, Kimlik Yönetimi altındaki Erişim Kontrolü ile ilgili sayfaları bir arada listeler.

:::

## Görünüm Modları

Erişim Kontrolü ekranı, aynı erişim ilişkisine üç farklı bakış açısıyla bakmanızı sağlayan üç moda sahiptir:

- **API Proxy modu**: Soldaki listeden bir API Proxy seçilir; sağda o API Proxy'e erişim izni verilmiş tüketiciler ile API Proxy'nin metot/endpoint bazlı erişim kısıtları yönetilir.
- **Proxy Grubu modu**: Aynı mantık bir API Proxy Grubu ve grup üyesi API Proxy'ler için uygulanır.
- **Tüketici modu**: Soldaki listeden bir tüketici seçilir; sağda bu tüketicinin erişim izni olduğu tüm API Proxy ve API Proxy Gruplarının listesi görüntülenir ve yönetilir (ters yönden bakış).

Seçilen tüketici/API Proxy/Proxy Grubu ilişkisi için geçerlilik tarihi, her ortamdaki erişim ve izin verilmeyen metot/proxy tanımları yapılandırılabilir. Kota ve daraltma burada ayarlanmaz; bunları [Limit Planları](/tr/ai-gateway/limit-planlari) menüsünde tanımlayın. Değişiklikler **Kaydet & Yayınla** ile etkinleştirilir.

Alan bazında detaylı konfigürasyon açıklamaları için [API Proxy ACL](/tr/admin/identity-management/api-proxy-acl) ve [API Proxy Grup ACL](/tr/admin/identity-management/api-proxy-grup-acl) sayfalarını inceleyebilirsiniz.

:::warning

Tüketici erişim izni, API proxy'e erişim için tek başına yeterli değildir. Tüketicideki ve erişim iznindeki ayarların geçerli olması için API Proxy üzerinde kimlik doğrulama politikalarından birisi eklenmiş olmalı ve bu politikada kimlik doğrulama şekli olarak **Security Manager** seçeneği seçili olmalıdır.

:::

## Büyük Kimlik Listeleri

API Proxy ve Proxy Grubu modunda **Kimlikler** sekmesi, atanmış kimlikleri sayfa sayfa gösterir. Varsayılan sayfa boyutu 50'dir. 25, 50 veya 100 seçebilirsiniz. 50 veya daha az kimlik içeren liste tek sayfada görünür.

- Listeyi daraltmak için **Tümü**, **Tüketiciler** ve **Uygulamalar** filtrelerini kullanın. Filtrelerdeki sayılar ile "gösterilen / toplam" metni yalnız geçerli sayfayı değil, atanmış tüm kimlikleri kapsar.
- Bir kimliği ada, kullanıcı adına veya kurum adına göre bulmak için **Kimlik ara...** kutusunu kullanın. Arama büyük/küçük harfe duyarsızdır ve metnin herhangi bir parçasıyla eşleşir.
- **Kimlik Ekle** ile eklediğiniz kimlikler, **Kaydet & Yayınla**'ya tıklayana kadar ilk sayfanın en üstünde görünür.
- Sayfalar arasında gezerken yaptığınız düzenlemeler korunur. Kaydetme sürerken yaptığınız bir düzenleme kaydedilmemiş değişiklik olarak kalır; kaydetme bittiğinde kaybolmaz.
- **Kaydet & Yayınla** yalnız değişen ve eklenen satırları kaydeder. Gateway, API Proxy'nin veya Proxy Grubunun erişim listesinin tamamını almaya devam eder.
- **Endpoint'ler** sekmesinde her endpoint için izinli ve engelli sayıları tüm kimlikleri kapsar. Bir endpoint'e tıkladığınızda açılan panel de sayfalıdır.

## Tüm Kimlikleri Kaldırma

Seçili API Proxy veya Proxy Grubuna erişimi olan tüm kimliklerin erişimini tek seferde kaldırmak için kimlikler araç çubuğundaki **Tümünü sil** düğmesine tıklayın. Değişiklik gateway'lerden de kaldırılır. Onay penceresi kimlik sayısını ve API adını gösterir. Bu işlem geri alınamaz.

Tüm kimlikler tek işlemle kaldırılır. İşlem sürerken pencere "N kimliğin erişimi kaldırılıyor. Bu pencereyi kapatmayın." mesajını gösterir ve kapatılamaz. Kaldırılan her erişim yine denetim loguna yazılır.

:::note

Kaydedilmemiş değişiklik varken **Tümünü sil** düğmesi devre dışıdır. Önce değişiklikleri kaydedin veya iptal edin. Bu düğmeyi yalnız kimlikleri yönetebilen kullanıcılar kullanabilir.

:::

## Kaydetme Hataları

Siz sayfayı yükledikten sonra başka bir kullanıcı bir erişim kuralını kaldırmış olabilir. Bu durumda **Kaydet & Yayınla** isteği reddeder; böylece kaldırılan erişim yeniden verilmez. Sayfayı yenileyip tekrar deneyin.

- "İstekteki bir erişim kuralı bu arada silinmiş. Sayfayı yenileyip tekrar deneyin."
- "İstekteki bir erişim kuralı başka bir API'ye ait. Sayfayı yenileyip tekrar deneyin."
