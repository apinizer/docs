## Dump İşlemi

Aşağıdaki komut ile Elasticsearch'teki data stream, `--searchBody` alanındaki sorguya göre filtrelenir ve `/tmp/es_backup` klasörüne dump edilir.

:::note

`--searchBody` parametresi ile belirli API Proxy ID'lerine göre filtreleme yapılır. Komuttaki `<INDEX_KEY>`, `<API_PROXY_ID>`, `<USERNAME>`, `<PASSWORD>`, `<ELASTIC_IP>` ve `<ELASTIC_PORT>` değerlerini kendi ortamınıza göre değiştirmeniz gerekir.

:::

```bash
multielasticdump --direction=dump \
  --match='apinizer-log-apiproxy-<INDEX_KEY>' \
  --matchType=datastream \
  --input=https://<USERNAME>:<PASSWORD>@<ELASTIC_IP>:<ELASTIC_PORT> \
  --ignoreType='mapping,settings,template' \
  --output=/tmp/es_backup \
  --searchBody="{\"query\": {\"match\": { \"api\": \"<API_PROXY_ID>\" }}}" \
  --overwrite \
  --ignoreChildError=true \
  --ignoreMapping=true \
  --ignoreSettings=true \
  --ignoreTemplate=true \
  --ignoreAlias=true
```

:::warning

Dump alınırken `self-signed certificate in certificate chain` hatası alınırsa, komutun en başına `NODE_TLS_REJECT_UNAUTHORIZED=0` eklenerek dump alınabilir:

```bash
NODE_TLS_REJECT_UNAUTHORIZED=0 multielasticdump --direction=dump \
  --match='apinizer-log-apiproxy-<INDEX_KEY>' \
  --matchType=datastream \
  --input=https://<USERNAME>:<PASSWORD>@<ELASTIC_IP>:<ELASTIC_PORT> \
  --ignoreType='mapping,settings,template' \
  --output=/tmp/es_backup \
  --searchBody="{\"query\": {\"match\": { \"api\": \"<API_PROXY_ID>\" }}}" \
  --overwrite \
  --ignoreChildError=true \
  --ignoreMapping=true \
  --ignoreSettings=true \
  --ignoreTemplate=true \
  --ignoreAlias=true
```

:::

## Kurulum

### CentOS/RHEL

```bash
yum install npm
npm install elasticdump
npm install --no-bin-links elasticdump
```

### Ubuntu

```bash
apt update
apt install npm
npm install elasticdump
npm install --no-bin-links elasticdump
```
