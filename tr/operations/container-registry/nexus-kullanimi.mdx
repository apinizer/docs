Kurumunuz Nexus üzerinde docker-proxy repository tanımladıysa, Kubernetes worker node'larında registry mirror yapılandırması yapılır ve Apinizer deployment dosyalarındaki imaj path'leri Nexus adresine göre güncellenir.

:::info

Bu sayfadaki `<NEXUS_HOST>` placeholder'ını kurumunuzun registry adresiyle değiştirin. Path segmenti (`docker-proxy` vb.) kurumunuzun Nexus yapılandırmasına göre değişebilir.

:::

## Node Yapılandırması

Yapılandırmayı **cluster'daki tüm worker node'larda** uygulayın. Node'larınızda kullanılan container runtime'a göre ilgili sekmeyi seçin.

<Tabs>
  <TabItem value="containerd" label="Containerd">
    Modern Kubernetes kurulumlarında containerd kullanılır. Root kullanıcıya geçip yapılandırma dosyasını açın:

    ```bash
    sudo su
    vi /etc/containerd/config.toml
    ```

    `[plugins."io.containerd.grpc.v1.cri".registry]` bölümüne mirror tanımını ekleyin:

    ```toml
    [plugins."io.containerd.grpc.v1.cri".registry.mirrors."<NEXUS_HOST>"]
      endpoint = ["https://<NEXUS_HOST>"]
    ```

    **Örnek:**

    ```toml
    [plugins."io.containerd.grpc.v1.cri".registry.mirrors."repo.apinizer.com"]
      endpoint = ["https://repo.apinizer.com"]
    ```

    Değişikliği uygulamak için containerd servisini yeniden başlatın:

    ```bash
    systemctl restart containerd
    systemctl status containerd
    ```
  </TabItem>
  <TabItem value="docker" label="Docker">
    Docker runtime kullanan node'larda `/etc/docker/daemon.json` dosyasını düzenleyin:

    ```bash
    sudo su
    vi /etc/docker/daemon.json
    ```

    ```json
    {
      "data-root": "/docker-data",
      "insecure-registries": ["<NEXUS_HOST>"],
      "registry-mirrors": ["https://<NEXUS_HOST>"],
      "exec-opts": ["native.cgroupdriver=systemd"],
      "log-driver": "json-file",
      "log-opts": {
        "max-size": "100m"
      },
      "storage-driver": "overlay2"
    }
    ```

    **Örnek (registry alanları):**

    ```json
    {
      "insecure-registries": ["repo.apinizer.com"],
      "registry-mirrors": ["https://repo.apinizer.com"]
    }
    ```

    Değişikliği uygulamak için Docker servisini yeniden başlatın:

    ```bash
    systemctl daemon-reload
    systemctl restart docker
    docker info
    ```
  </TabItem>
</Tabs>

## Kubernetes Deployment Yapılandırması

Deployment, StatefulSet veya Helm values dosyalarında `image` alanını Nexus path yapınıza göre güncelleyin:

```yaml
image: <NEXUS_HOST>/docker-proxy/apinizercloud/apimanager:<APINIZER_VERSION>
```

**Örnek:**

```yaml
image: repo.apinizer.com/docker-proxy/apinizercloud/apimanager:2026.01.1
```

Diğer bileşenler (`worker`, `cache`, `integration`, `apiportal`) için aynı path kalıbı kullanılır.
