Kurumunuz Harbor registry kullanıyorsa, Kubernetes worker node'larında registry mirror yapılandırması yapılır ve Apinizer deployment dosyalarındaki imaj path'leri Harbor adresine göre güncellenir. Registry host ve proje path'ini kurumunuzdan almanız gerekir.

:::info

Bu sayfadaki `<HARBOR_HOST>` ve `<HARBOR_PROJECT>` placeholder'larını kurumunuzun Harbor adresi ve proje adıyla değiştirin.

:::

## Node Yapılandırması

Yapılandırmayı **cluster'daki tüm worker node'larda** uygulayın. Node'larınızda kullanılan container runtime'a göre ilgili sekmeyi seçin.

<Tabs>
  <TabItem value="containerd" label="Containerd">
    Modern Kubernetes kurulumlarında containerd kullanılır. Root kullanıcıya geçip yapılandırma dosyasını açın:

    ```bash
    sudo su
    vi /etc/containerd/config.toml
    ```

    `[plugins."io.containerd.grpc.v1.cri".registry]` bölümüne mirror tanımını ekleyin:

    ```toml
    [plugins."io.containerd.grpc.v1.cri".registry.mirrors."<HARBOR_HOST>"]
      endpoint = ["https://<HARBOR_HOST>"]
    ```

    **Örnek:**

    ```toml
    [plugins."io.containerd.grpc.v1.cri".registry.mirrors."harbor.apinizer.com"]
      endpoint = ["https://harbor.apinizer.com"]
    ```

    Harbor kurumsal bir CA sertifikası kullanıyorsa, sertifikayı node'a kopyalayıp TLS tanımını da ekleyin:

    ```toml
    [plugins."io.containerd.grpc.v1.cri".registry.configs."<HARBOR_HOST>".tls]
      ca_file = "/etc/containerd/certs.d/<HARBOR_HOST>/ca.crt"
    ```

    Değişikliği uygulamak için containerd servisini yeniden başlatın:

    ```bash
    systemctl restart containerd
    systemctl status containerd
    ```
  </TabItem>
  <TabItem value="docker" label="Docker">
    Docker runtime kullanan node'larda `/etc/docker/daemon.json` dosyasını düzenleyin:

    ```bash
    sudo su
    vi /etc/docker/daemon.json
    ```

    Harbor HTTPS kullanıyorsa ve kurumsal CA sertifikası gerekiyorsa sertifikayı sisteme ekleyin. HTTP veya self-signed ortamlarda `insecure-registries` kullanılabilir:

    ```json
    {
      "insecure-registries": ["<HARBOR_HOST>"]
    }
    ```

    **Örnek:**

    ```json
    {
      "insecure-registries": ["harbor.apinizer.com"]
    }
    ```

    Değişikliği uygulamak için Docker servisini yeniden başlatın:

    ```bash
    systemctl daemon-reload
    systemctl restart docker
    docker info
    ```
  </TabItem>
</Tabs>

## Kubernetes Deployment Yapılandırması

Deployment, StatefulSet veya Helm values dosyalarında `image` alanını Harbor path yapınıza göre güncelleyin:

```yaml
image: <HARBOR_HOST>/<HARBOR_PROJECT>/apinizercloud/apimanager:<APINIZER_VERSION>
```

**Örnek:**

```yaml
image: harbor.apinizer.com/apinizer/apinizercloud/apimanager:<APINIZER_VERSION>
```

Diğer bileşenler (`worker`, `cache`, `integration`, `apiportal`) için aynı path kalıbı kullanılır.
