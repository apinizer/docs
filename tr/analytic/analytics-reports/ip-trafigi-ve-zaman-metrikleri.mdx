:::info

Bir API Proxy birden fazla ortama yüklenebildiği için metrikleri de yüklendiği ortama göre değerlendirmek gerekir. Bu sebeple tüm analitik ekranlarında öncelikle ortam bilgisi seçilerek metrikler filtrelenir.

:::

:::warning

Elasticsearch entegrasyonu yapılandırılmamış ortamlar için metrik verileri görüntülenemez. Bu durumda ekranda uyarı mesajı gösterilir.

:::

## Metrikler Sayfası

Bu rapor **Metrikler** sayfasının **Clients** sekmesinde **IP Traffic Metrics** alt-raporu olarak yer alır (dokümantasyonda **IP Trafiği & Zaman Metrikleri**). Ekrana **Administration > Reports > Metrics** veya proje menüsünden **Analytic > Reports > Metrics** ile ulaşabilirsiniz; **Clients** sekmesinde **IP Traffic Metrics** düğmesini seçin.

Tablo IP bazlı üç seviyeli ağaç yapısındadır: IP satırı genişletilerek o IP'nin kullandığı API Proxy'ler ve altında metot/endpoint kırılımı görülebilir.

## Filtreleme

Metrikler sayfasının üst filtre satırı tüm sekmeler ve alt-raporlar için ortaktır:

| Seçenek | Açıklama |
|---------|----------|
| **Ortam** | Metrikleri görmek istediğiniz ortamı (environment) seçebilirsiniz |
| **Proje** | (Yalnızca Administration) Birden fazla proje seçerek metrikleri filtreleyebilirsiniz |
| **Tarih Aralığı** | Metriklerin hesaplanacağı zaman aralığı (varsayılan: son 1 saat) |
| **Yenile** | O an görüntülenen alt-raporu anında yeniden sorgular |
| **Excel Export** | Paylaşılan filtre satırındaki dışa aktarma; o an açık alt-raporun listesini indirir |

### Rapora özel filtreler

Alt-rapor satırında yalnızca **IP Traffic Metrics** seçiliyken görünür:

| Seçenek | Açıklama |
|---------|----------|
| **IP Address** | Belirli bir IP adresiyle sınırlar |
| **Proxy** | Belirli API Proxy'lerle sınırlar |

Alt-rapor satırında **Choose Your Refresh Time** (varsayılan: Manual) ve yenileme düğmesi bulunur.

## Tablo Sütun Açıklamaları

Tablo IP adresi bazında ağaç (tree) yapısındadır: her satırın solundaki ok simgesiyle bir alt seviye açılır/kapanır.

- **1. seviye (kök satır):** Trafik üreten bir **IP adresi**.
- **2. seviye:** O IP adresinin istek gönderdiği bir **API Proxy**.
- **3. seviye (en alt):** O API Proxy altında IP'nin istek attığı bir **uç nokta (method/endpoint)**.

Sütunlar altı grup altında toplanır.

### Bilgi

| Sütun | Açıklama |
|-------|----------|
| **IP Address** | Kök satırda istemci IP adresi; alt seviyede API Proxy adı veya metot/endpoint yolu |
| **Project** | (Yalnızca Administration) API Proxy satırında proje adı; IP kök satırında boş |

### Trafik Metrikleri (adet)

O satırdaki node'a (IP / API Proxy / uç nokta) ait, seçilen ortam ve tarih aralığındaki isteklerin sonuç durumuna göre sayısı:

| Sütun | Açıklama |
|-------|----------|
| **Successful** | Başarılı sonuçlanan istek sayısı |
| **Blocked** | Politikalar tarafından (ör. güvenlik, rate limiting) bloklanan istek sayısı |
| **Error** | Hata ile sonuçlanan istek sayısı |
| **Total** | Successful + Blocked + Error toplamı |

### Request Pipeline Time (ms)

İsteğin, gateway'e ulaştıktan sonra backend'e yönlendirilmeden önce üzerinden geçtiği istek (request) politikalarının işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Avg.** | Bu bölgede ölçülen ortalama süre (ms) |

### Routing Time (ms)

İsteğin backend'e gönderilip yanıtın geri alınmasına kadar geçen süre (backend gidiş-dönüş süresi):

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Avg.** | Bu bölgede ölçülen ortalama süre (ms) |

### Response Pipeline Time (ms)

Backend'den dönen yanıtın, istemciye iletilmeden önce üzerinden geçtiği yanıt (response) politikalarının işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Avg.** | Bu bölgede ölçülen ortalama süre (ms) |

### Total Time (ms)

Request Pipeline + Routing + Response Pipeline sürelerinin toplamı; isteğin gateway'e ulaşmasından yanıtın istemciye dönmesine kadar geçen toplam süre:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu node için ölçülen en kısa toplam süre (ms) |
| **Max.** | Bu node için ölçülen en uzun toplam süre (ms) |
| **Avg.** | Bu node için ölçülen ortalama toplam süre (ms) |
