Bu rapor, **Analitik > Raporlar > Metrikler** ekranının **Uç Noktalar** sekmesinde **Uç Nokta Trafik Metrikleri** alt-raporu olarak sunulur.

[Ağ Geçidi Trafiği & Zaman Metrikleri](/tr/analytic/analytics-reports/api-trafigi-ve-zaman-metrikleri) raporu kayıtları **API Proxy** bazında gruplarken, bu rapor aynı trafik ve süre metriklerini **Proje / API Proxy / Metot-Uç Nokta** kırılımında gösterir. Böylece "hangi API Proxy yavaş" sorusu yerine, **bir API Proxy'nin hangi metodu/uç noktası** daha fazla trafik alıyor veya daha yavaş yanıt veriyor sorusuna cevap bulabilirsiniz.

:::info

Bir API Proxy birden fazla ortama yüklenebildiği için metrikleri de yüklendiği ortama göre değerlendirmek gerekir. Bu sebeple tüm analitik ekranlarında öncelikle ortam bilgisi seçilerek metrikler filtrelenir.

:::

:::warning

Elasticsearch entegrasyonu yapılandırılmamış ortamlar için metrik verileri görüntülenemez. Bu durumda ekranda uyarı mesajı gösterilir.

:::

## Filtreleme

Metrikler ekranındaki filtre satırı, sekme/alt-rapor değişse dahi tüm alt-raporlar için ortaktır; her sekmeye geçildiğinde o an ekranda görünen rapor bu filtrelerle yeniden sorgulanır.

| Seçenek | Açıklama |
|---------|----------|
| **Ortam** | Metriklerin hesaplanacağı ortamı (environment) seçersiniz. Rapor, seçilen ortamın Elasticsearch verisi üzerinden sorgulanır |
| **Proje** | (Yalnızca Yönetim menüsünde) Birden fazla projeyi seçerek metrikleri projeler bazında filtreleyebilirsiniz |
| **Tarih Aralığı** | Metriklerin hesaplanacağı zaman aralığını belirlersiniz. Varsayılan değer **son 1 saat**tir |
| **Yenile** | O an ekranda görünen raporu (bu durumda Uç Nokta Trafik Metrikleri'ni) seçili filtrelerle yeniden sorgular |

Alt-rapor sekmesinin yanındaki Excel simgesi, o an ekranda görünen raporu dışa aktarır.

## Tablo Sütun Açıklamaları

### Bilgi

| Sütun | Açıklama |
|-------|----------|
| **Proje** | Kaydın ait olduğu projenin adı (yalnızca Yönetim menüsünde görünür) |
| **Proxy Adı** | İlgili API Proxy'nin adı |
| **Metot Adı** | HTTP metodu ve uç nokta yolunun birleşimi (örn. `GET /pet/findByStatus`) |

### Trafik Metrikleri (adet)

Seçilen tarih aralığında, ilgili metoda/uç noktaya gelen isteklerin sayısal dökümü:

| Sütun | Açıklama |
|-------|----------|
| **Başarılı** | Başarılı (2xx) yanıt kodu ile sonuçlanan istek sayısı |
| **Bloklanmış** | Güvenlik politikaları, rate limiting/quota gibi nedenlerle engellenen istek sayısı |
| **Hatalı** | Hata (4xx, 5xx) yanıt kodu ile sonuçlanan istek sayısı |
| **Toplam** | Toplam istek sayısı (Başarılı + Bloklanmış + Hatalı) |

### İstek Hattı Süreleri (ms)

İsteğin Apinizer'a ulaşmasından backend'e yönlendirilmesine kadar geçen sürede, istek tarafı politikalarının (auth, dönüşüm, doğrulama vb.) işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu süre için gözlemlenen en küçük değer |
| **Max.** | Bu süre için gözlemlenen en büyük değer |
| **Ort.** | Bu sürenin ortalama değeri |

### Routing Süreleri (ms)

İsteğin backend'e gönderilip yanıtın backend'den alınmasına kadar geçen süre (backend çağrı/ağ süresi):

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu süre için gözlemlenen en küçük değer |
| **Max.** | Bu süre için gözlemlenen en büyük değer |
| **Ort.** | Bu sürenin ortalama değeri |

### Yanıt Hattı Süreleri (ms)

Backend'den dönen yanıtın, yanıt tarafı politikalarından (dönüşüm, maskeleme vb.) geçerek istemciye iletilmesine kadar geçen süre:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu süre için gözlemlenen en küçük değer |
| **Max.** | Bu süre için gözlemlenen en büyük değer |
| **Ort.** | Bu sürenin ortalama değeri |

### Toplam Süreler (ms)

İsteğin Apinizer'a ulaşmasından yanıtın istemciye döndürülmesine kadar geçen uçtan uca toplam süre (İstek Hattı + Routing + Yanıt Hattı):

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu süre için gözlemlenen en küçük değer |
| **Max.** | Bu süre için gözlemlenen en büyük değer |
| **Ort.** | Bu sürenin ortalama değeri |
