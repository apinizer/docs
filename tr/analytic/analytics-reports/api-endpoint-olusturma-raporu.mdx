:::note

Bu rapor Elasticsearch trafik verisi kullanmaz; endpoint meta verilerini (oluşturulma tarihi, HTTP metodu, bağlı API Proxy bilgisi) MongoDB üzerinden listeler. Metrikler sayfasının üstündeki ortam bu raporu filtrelemez.

:::

:::note

Raporun kendi oluşturulma tarihi alanları vardır. Metrikler sayfasının üstündeki paylaşılan tarih aralığı bu rapora uygulanmaz. Varsayılan oluşturulma penceresi **son 30 gün**, varsayılan aralık **Daily**'dir.

:::

## Raporu Nerede Bulursunuz

- **Yönetim:** **Yönetim > API Yönetişimi > Uç Nokta Büyümesi** menüsünü açın (**Envanter Raporları** bölümünde). Rapor tüm projeleri kapsar ve **Proje** filtresi vardır.
- **Proje menüsü:** **Metrikler** sayfasındaki **Uç Nokta Büyümesi** sekmesini açın (tam adı: **API Uç Nokta Büyümesi**). Rapor aktif projeyi kapsar.

**API Büyümesi** raporu da ilgilidir; proxy oluşturma metrikleri için [Proxy Oluşturma Raporu](/tr/analytic/analytics-reports/api-proxy-olusturma-raporu) sayfasına bakabilirsiniz.

## Arama

Rapor açıldığında bir arama çalıştırır. Sonrasında grafik ve liste yalnızca **Ara** düğmesine bastığınızda değişir. **Ara** düğmesi, henüz uygulanmamış filtre değişikliklerinin sayısını gösterir.

## Grafiği Gruplama

Grafik görünümünde çubukların nasıl oluşacağını **Gruplama** anahtarıyla seçersiniz:

- **Döneme göre**: Her aralık için bir çubuk.
- **Yönlendirme adresine göre**: Endpoint'lerin API Proxy'sinin yönlendirdiği her adres için bir çubuk. Rapor, seçilen tarih aralığında oluşturulan endpoint'leri her adresin altında sayar. HTTP adresinde adres `host:port` değeridir. AI proxy'de LLM sağlayıcısıdır. MCP veya A2A proxy'de bağlı sunucudur.

Adresleri birden fazla host'ta olan bir API Proxy, endpoint'lerini her host'un altına ekler. Grafik yönlendirme adresine göre gruplandığında **Interval** kullanılmaz.

## Filtreleme

### Paylaşılan filtre (Metrikler üst satırı)

| Seçenek | Açıklama |
|---------|----------|
| **Proje** | (Yalnızca Administration) Oluşturulma kayıtlarını seçilen projelerle sınırlar |
| **Interval** | **Daily**, **Weekly** veya **Monthly**; grafik döneme göre gruplandığında kullanılır |
| Created from / to | Endpoint'lerin oluşturulma tarih aralığı |
| **Excel Export** | Endpoint listesini ekrandaki filtrelerle dışa aktarır. ZIP dosya adı `apinizer-api-endpoint-report.zip` |

### Liste görünümü filtreleri

| Seçenek | Açıklama |
|---------|----------|
| **Proxy** | Belirli API Proxy'lerle listeyi daraltır |
| **Search by endpoint** | Endpoint yolunda metin araması |
| **HTTP Method: All** | GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS, TRACE, QUERY — çoklu seçim |
| **API Proxy Type** | REST, SOAP, gRPC — çoklu seçim; boş bırakılırsa endpoint tanımlayabilen tüm tipler |
| **API Proxy Creation Type** | WSDL, Swagger 2.x, Open API/Swagger 3.0.x, Reverse Proxy, No-Spec API, DB-2-API, Mock API, Script-2-API, Connector |
| **Protocol Transformation** | Exist / Not Exist |
| **Show route address** | Yönlendirme hedef adreslerini tabloya ekler (varsayılan: kapalı) |
| **Show route condition** | Adres açıkken koşul özetlerini ekler (varsayılan: kapalı) |
| **Temizle** | Rapor özel filtrelerini sıfırlar; proje kapsamı ve paylaşılan tarih aralığı korunur |

## Tablo Sütun Açıklamaları

| Sütun | Açıklama |
|-------|----------|
| **Created Date** | Endpoint'in oluşturulma zamanı (`dd/MM/yyyy HH:mm:ss`) |
| **API Proxy** | Endpoint'in bağlı olduğu API Proxy adı |
| **Endpoint** | Metot yolu (örn. `GET /pet/findByStatus` yol kısmı) |
| **HTTP Method** | HTTP metodu (GET, POST, PUT, DELETE vb.) |
| **API Proxy Type** | Bağlı proxy'nin tipi (REST, SOAP, gRPC) |
| **API Proxy Creation Type** | Proxy'nin oluşturulma kaynağı (Open API/Swagger 3.0.x, WSDL vb.) |
| **Protocol Transformation** | Protokol dönüşümü varsa yeşil onay simgesi; yoksa kırmızı çarpı |
| **Project** | (Yalnızca Administration) Endpoint'in ait olduğu proje |

Route toggle'ları açıkken ek sütunlar: **Route Address**, **Route Condition** (koşul yalnızca adres açıkken kullanılabilir).

Sayfalama seçenekleri: 10, 25, 50, 100 satır.

## API Proxy Tipine Göre Filtreleme

Liste görünümündeki **API Proxy Type** filtresi, endpoint tanımlayabilen tipleri sunar: **REST**, **SOAP** ve **gRPC**. AI, MCP, A2A ve WebSocket proxy'ler endpoint tanımı içermediğinden bu raporda listelenmez ve filtre seçeneği olarak sunulmaz. Birden fazla tip aynı anda seçilebilir; hiçbiri seçilmediğinde endpoint tanımlayabilen tüm tipler listelenir.

**API Proxy Type** sütunu, seçtiğiniz filtreden bağımsız olarak her satırda endpoint'in bağlı olduğu proxy tipini gösterir.

## Yönlendirme Bilgilerini Görüntüleme

Filtre satırındaki iki seçenek ile endpoint'lerin gerçekte hangi hedeflere yönlendirdiğini görebilirsiniz. Her ikisi de varsayılan olarak kapalıdır; açtığınızda hem ekrandaki listeye hem de Excel çıktısına yeni sütun olarak eklenir.

<CardGroup cols={2}>
  <Card title="Show route address" icon="route">
    Endpoint'e gelen isteğin iletildiği hedef adresi gösterir. Endpoint için ayrı bir arka uç yolu tanımlıysa bu yol adrese eklenerek gösterilir. Birden fazla hedef tanımlıysa alt alta listelenir.
  </Card>
  <Card title="Show route condition" icon="filter">
    Bir hedefe yalnızca belirli koşullar sağlandığında yönlendirme yapılıyorsa koşul özetini adresle aynı satırda gösterir. Koşulsuz hedeflerde hücre boş kalır.
  </Card>
</CardGroup>

Yönlendirme koşulu seçeneği, yönlendirme adresi açık olduğunda kullanılabilir. Koşul özetleri adres satırlarıyla hizalı üretildiği için adres sütunu olmadan anlam taşımaz.

:::note

Endpoint'e özel arka uç yolu yalnızca REST API Proxy'lerinde adrese eklenir. Diğer tiplerde API Proxy düzeyindeki hedef bilgisi olduğu gibi gösterilir.

:::

:::tip

Route sütunları varsayılan olarak kapalı olduğundan mevcut Excel çıktılarını işleyen betikleriniz etkilenmez; sütunlar yalnızca açtığınızda eklenir.

:::
