## API Proxy Tipine Göre Filtreleme

Liste görünümündeki tip filtresi, endpoint tanımlayabilen API Proxy tiplerini sunar: REST, SOAP ve gRPC. AI, MCP, A2A ve WebSocket proxy'ler endpoint tanımı içermediğinden bu raporda listelenmez ve filtre seçeneği olarak sunulmaz. Birden fazla tip aynı anda seçilebilir; hiçbiri seçilmediğinde endpoint tanımlayabilen tüm tipler listelenir.

Tip sütunu, seçtiğiniz filtreden bağımsız olarak her satırda endpoint'in bağlı olduğu API Proxy'nin tipini gösterir.

## Yönlendirme Bilgilerini Görüntüleme

Filtre alanındaki iki seçenek ile endpoint'lerin gerçekte hangi hedeflere yönlendirdiğini görebilirsiniz. Her ikisi de varsayılan olarak kapalıdır; açtığınızda hem ekrandaki listeye hem de Excel çıktısına yeni sütun olarak eklenir.

<CardGroup cols={2}>
  <Card title="Yönlendirme adresini göster" icon="route">
    Endpoint'e gelen isteğin iletildiği hedef adresi gösterir. Endpoint için ayrı bir arka uç yolu tanımlıysa bu yol adrese eklenerek gösterilir. Birden fazla hedef tanımlıysa hepsi alt alta listelenir.
  </Card>
  <Card title="Yönlendirme koşulunu göster" icon="filter">
    Bir hedefe yalnızca belirli koşullar sağlandığında yönlendirme yapılıyorsa, o koşulun özetini adresle aynı satırda gösterir. Koşulsuz hedeflerde bu hücre boş kalır. AI Proxy'lerinde koşul, alan karşılaştırmasıyla ya da anlamsal benzerlikle tanımlanabilir; her iki biçim de özetlenir.
  </Card>
</CardGroup>

Yönlendirme koşulu seçeneği, yönlendirme adresi seçeneği açık olduğunda kullanılabilir. Koşul özetleri adres satırlarıyla hizalı üretildiği için adres sütunu olmadan tek başına anlam taşımaz.

:::note
Endpoint'e özel arka uç yolu yalnızca REST API Proxy'lerinde adrese eklenir. Diğer tiplerde API Proxy düzeyindeki hedef bilgisi olduğu gibi gösterilir.
:::

:::tip
Bu iki sütun varsayılan olarak kapalı olduğundan mevcut Excel çıktılarını işleyen betikleriniz etkilenmez; sütunlar yalnızca siz açtığınızda eklenir.
:::
