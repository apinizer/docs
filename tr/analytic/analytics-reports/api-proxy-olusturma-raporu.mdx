## Metrikler Sayfası

Bu rapor **Metrikler** sayfasının **Growth** sekmesinde **API Proxy Growth** alt-raporu olarak yer alır (dokümantasyonda **Proxy Oluşturma Raporu**). Ekrana **Administration > Reports > Metrics** veya proje menüsünden **Analytic > Reports > Metrics** ile ulaşabilirsiniz.

Aynı sekmede **API Endpoint Growth** alt-raporu da bulunur; endpoint oluşturma metrikleri için [API Endpoint Oluşturma Raporu](/tr/analytic/analytics-reports/api-endpoint-olusturma-raporu) sayfasına bakabilirsiniz.

## Filtreleme

### Paylaşılan filtre (Metrikler üst satırı)

| Seçenek | Açıklama |
|---------|----------|
| **Ortam** | Diğer trafik raporları için geçerlidir; bu raporun listesini filtrelemez |
| **Proje** | (Yalnızca Administration) Oluşturulma kayıtlarını seçilen projelerle sınırlar |
| **Tarih Aralığı** | Proxy **createdDate** alanına uygulanır; ES date-math ifadesi yyyy-MM-dd oluşturulma tarihine dönüştürülür |
| **Yenile** | Aktif alt-raporu seçili filtrelerle yeniden sorgular |
| **Excel Export** | Aktif görünüme göre dışa aktarır: grafikte yalnızca proje + tarih; listede aşağıdaki tüm liste filtreleri de uygulanır. ZIP dosya adı `apinizer-api-proxy-report.zip` |

### Liste görünümü filtreleri

| Seçenek | Açıklama |
|---------|----------|
| **Proxy** | Belirli API Proxy'lerle listeyi daraltır |
| **API Proxy Type** | REST, SOAP, gRPC, WebSocket, AI, MCP, A2A — çoklu seçim; boş bırakılırsa tüm tipler |
| **API Proxy Creation Type** | WSDL, Swagger 2.x, Open API/Swagger 3.0.x, Reverse Proxy, No-Spec API, DB-2-API, Mock API, Script-2-API, Connector |
| **Protocol Transformation** | REST proxy'lerde protokol dönüşümü filtresi |
| **Show route address** | Yönlendirme hedef adreslerini tabloya ekler (varsayılan: kapalı) |
| **Show route condition** | Adres açıkken koşul özetlerini ekler (varsayılan: kapalı) |
| **Temizle** | Rapor özel filtrelerini sıfırlar; proje kapsamı ve paylaşılan tarih aralığı korunur |

## Tablo Sütun Açıklamaları

| Sütun | Açıklama |
|-------|----------|
| **Created Date** | Proxy'nin oluşturulma zamanı (`dd/MM/yyyy HH:mm:ss`) |
| **Principal** | Oluşturan kullanıcı / hesap |
| **API Proxy** | Proxy adı |
| **Type** | API tipi (REST, SOAP, gRPC, WebSocket, AI, MCP, A2A) |
| **Spec Type** | Oluşturulma kaynağı (Open API/Swagger 3.0.x, WSDL, No-Spec API vb.) |
| **Environment** | Her deploy satırında durum simgesi (deployed / redeploy required / undeployed), ortam adı ve tıklanabilir gateway erişim URL'si |
| **Category List** | Proxy'ye atanmış kategori etiketleri |
| **Project** | (Yalnızca Administration) Proxy'nin ait olduğu proje |

Route toggle'ları açıkken ek sütunlar: **Route Address**, **Route Condition** (koşul yalnızca adres açıkken kullanılabilir).

Sayfalama seçenekleri: 10, 25, 50, 100 satır.

## API Proxy Tipine Göre Filtreleme

Liste görünümündeki **API Proxy Type** filtresinden platformdaki tüm API Proxy tiplerini seçebilirsiniz. Birden fazla tip aynı anda seçilebilir; hiçbiri seçilmediğinde tüm tipler listelenir. **Type** sütunu, seçtiğiniz filtreden bağımsız olarak her satırda ilgili proxy'nin tipini gösterir.

## Yönlendirme Bilgilerini Görüntüleme

Filtre satırındaki iki seçenek ile API Proxy'lerin gerçekte hangi hedeflere yönlendirdiğini görebilirsiniz. Her ikisi de varsayılan olarak kapalıdır; açtığınızda hem ekrandaki listeye hem de Excel çıktısına yeni sütun olarak eklenir.

<CardGroup cols={2}>
  <Card title="Show route address" icon="route">
    API Proxy'nin isteği ilettiği hedef adresleri gösterir. Birden fazla hedef tanımlıysa alt alta listelenir; birincil, kanarya, yansıtma ve yedek hedefler ayrı etiketlenir.
  </Card>
  <Card title="Show route condition" icon="filter">
    Bir hedefe yalnızca belirli koşullar sağlandığında yönlendirme yapılıyorsa koşul özetini adresle aynı satırda gösterir. Koşulsuz hedeflerde hücre boş kalır. AI Proxy'lerinde koşul alan karşılaştırması veya anlamsal benzerlikle tanımlanabilir.
  </Card>
</CardGroup>

Yönlendirme koşulu seçeneği, yönlendirme adresi açık olduğunda kullanılabilir. Koşul özetleri adres satırlarıyla hizalı üretildiği için adres sütunu olmadan anlam taşımaz.

:::note

Hedef gösterimi API Proxy tipine göre değişir. REST, SOAP, gRPC ve WebSocket için arka uç adresleri; AI için sağlayıcı ve model bilgisi; MCP ve A2A için bağlanılan sunucu adı ve adresi gösterilir. Kendi araçlarını dışarıya sunan MCP yapılandırmalarında sütun sunulan araç sayısını belirtir. Kendi ajanını sunan A2A yapılandırmalarında sunum bilgisiyle birlikte ajanın kullandığı sağlayıcı ve model listelenir.

:::

:::tip

Route sütunları varsayılan olarak kapalı olduğundan mevcut Excel çıktılarını işleyen betikleriniz etkilenmez; sütunlar yalnızca açtığınızda eklenir.

:::
