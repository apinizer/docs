## API Proxy Tipine Göre Filtreleme

Liste görünümündeki tip filtresinden platformdaki tüm API Proxy tiplerini seçebilirsiniz: REST, SOAP, gRPC, WebSocket, AI, MCP ve A2A. Birden fazla tip aynı anda seçilebilir; hiçbiri seçilmediğinde tüm tipler listelenir.

Tip sütunu, seçtiğiniz filtreden bağımsız olarak her satırda ilgili API Proxy'nin tipini gösterir.

## Yönlendirme Bilgilerini Görüntüleme

Filtre alanındaki iki seçenek ile API Proxy'lerin gerçekte hangi hedeflere yönlendirdiğini görebilirsiniz. Her ikisi de varsayılan olarak kapalıdır; açtığınızda hem ekrandaki listeye hem de Excel çıktısına yeni sütun olarak eklenir.

<CardGroup cols={2}>
  <Card title="Yönlendirme adresini göster" icon="route">
    API Proxy'nin isteği ilettiği hedef adresleri gösterir. Bir API Proxy'de birden fazla hedef tanımlıysa hepsi alt alta listelenir; birincil, kanarya, yansıtma ve yedek hedefler ayrı ayrı etiketlenir.
  </Card>
  <Card title="Yönlendirme koşulunu göster" icon="filter">
    Bir hedefe yalnızca belirli koşullar sağlandığında yönlendirme yapılıyorsa, o koşulun özetini adresle aynı satırda gösterir. Koşulsuz hedeflerde bu hücre boş kalır. AI Proxy'lerinde koşul, alan karşılaştırmasıyla ya da anlamsal benzerlikle tanımlanabilir; her iki biçim de özetlenir.
  </Card>
</CardGroup>

Yönlendirme koşulu seçeneği, yönlendirme adresi seçeneği açık olduğunda kullanılabilir. Koşul özetleri adres satırlarıyla hizalı üretildiği için adres sütunu olmadan tek başına anlam taşımaz.

:::note
Hedef gösterimi API Proxy tipine göre değişir. REST, SOAP, gRPC ve WebSocket için arka uç adresleri; AI için sağlayıcı ve model bilgisi; MCP ve A2A için bağlanılan sunucu adı ve adresi gösterilir. Kendi araçlarını dışarıya sunan MCP yapılandırmalarında dış hedef bulunmadığından sütun, adres yerine sunulan araç sayısını belirtir. Kendi ajanını sunan A2A yapılandırmalarında ise sunum bilgisiyle birlikte ajanın kullandığı sağlayıcı ve model listelenir.
:::

:::tip
Bu iki sütun varsayılan olarak kapalı olduğundan mevcut Excel çıktılarını işleyen betikleriniz etkilenmez; sütunlar yalnızca siz açtığınızda eklenir.
:::
