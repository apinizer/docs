## Raporu Nerede Bulursunuz

- **Yönetim:** **Yönetim > API Yönetişimi > API Büyümesi** menüsünü açın (**Envanter Raporları** bölümünde). Rapor tüm projeleri kapsar ve **Proje** filtresi vardır.
- **Proje menüsü:** **Metrikler** sayfasındaki **API Büyümesi** sekmesini açın. Rapor aktif projeyi kapsar.

Rapor bir grafiktir. Tek tek API Proxy'leri görmek için API Proxy'ler listesini açın. **Yönetim** menüsünde de aynı liste vardır.

**Uç Nokta Büyümesi** raporu da ilgilidir; bkz. [API Endpoint Oluşturma Raporu](/tr/analytic/analytics-reports/api-endpoint-olusturma-raporu).

## Varsayılanlar ve Arama

Rapor açıldığında bir arama çalıştırır. Varsayılan oluşturulma penceresi son 30 gündür ve varsayılan aralık **Daily**'dir.

Sonrasında grafik yalnızca **Ara** düğmesine bastığınızda değişir. **Ara** düğmesi, henüz uygulanmamış filtre değişikliklerinin sayısını gösterir. **Ara** düğmesinin yanındaki **Temizle**, filtre öğelerini boşaltır ve aramayı çalıştırır.

**Metrikler** sayfasında raporun kendi oluşturulma tarihi alanları ve filtreleri vardır. Metrikler sayfasının üstündeki ortam ve tarih aralığı bu rapora uygulanmaz.

## Filtreleme

| Seçenek | Açıklama |
|---------|----------|
| **Proje** | (Yalnızca Administration) Sayımı seçilen projelerle sınırlar |
| **Interval** | **Daily**, **Weekly** veya **Monthly**. Grafik yönlendirme adresine göre gruplandığında kullanılmaz |
| Created from / to | Oluşturulma tarih aralığı |
| **API Proxy Type** | REST, SOAP, gRPC, WebSocket, AI, MCP, A2A. Boş bırakılırsa tüm tipler |
| **API Proxy Creation Type** | WSDL, Swagger 2.x, Open API/Swagger 3.0.x, Reverse Proxy, No-Spec API, DB-2-API, Mock API, Script-2-API, Connector |
| **Ortam** | Yalnızca seçilen ortamlara deploy edilmiş API Proxy'leri sayar |
| **Protocol Transformation** | REST proxy'lerde protokol dönüşümü filtresi |

## Gruplama

Çubukların nasıl oluşacağını grafiğin üstündeki **Gruplama** anahtarıyla seçersiniz.

<CardGroup cols={2}>
  <Card title="Döneme göre" icon="calendar">
    Her aralık için bir çubuk. Başlık "Dönem başına oluşturulan API proxy sayısı (mevcut kayıtlar)" olarak görünür.
  </Card>
  <Card title="Yönlendirme adresine göre" icon="route">
    API Proxy'lerin yönlendirdiği her adres için bir çubuk. Başlık "Yönlendirme adresine göre API proxy sayısı (mevcut kayıtlar)" olarak görünür.
  </Card>
</CardGroup>

Yönlendirme adresine göre gruplarsanız rapor, seçilen tarih aralığında oluşturulan API Proxy'leri her adresin altında sayar:

- HTTP adresinde adres `host:port` değeridir.
- AI proxy'de adres LLM sağlayıcısıdır.
- MCP veya A2A proxy'de adres bağlı sunucudur.
- Adresleri birden fazla host'ta olan bir API Proxy her host'un altında sayılır. Bu yüzden toplam, API Proxy sayısından büyük olabilir.
- Yönlendirme hedefi olmayan bir API Proxy "(yönlendirme adresi yok)" altında sayılır.

## Excel Export

Excel düğmesi grafiğin arkasındaki tabloyu `apinizer-api-growth.zip` olarak dışa aktarır. Dosya, ekrandaki filtreleri ve gruplamayı kullanır:

- Döneme göre gruplandığında dosyada **Dönem** ve **Yeni API proxy'ler** sütunları bulunur.
- Yönlendirme adresine göre gruplandığında dosyada **Yönlendirme adresi** ve **Yeni API proxy'ler** sütunları bulunur.

## Listede Yönlendirme Bilgilerini Görüntüleme

API Proxy'ler listesinde, API Proxy'lerinizin isteği nereye yönlendirdiğini gösteren iki seçenek vardır. İkisi de varsayılan olarak kapalıdır.

<CardGroup cols={2}>
  <Card title="Show route address" icon="route">
    Her API Proxy'nin hedef adreslerini içeren bir **Route Address** sütunu ekler.
  </Card>
  <Card title="Show route condition" icon="filter">
    Her hedefin koşul özetini içeren bir **Route Condition** sütunu ekler. Seçenek, **Show route address** açıkken kullanılabilir.
  </Card>
</CardGroup>

:::note

Hedef gösterimi API Proxy tipine göre değişir. REST, SOAP, gRPC ve WebSocket için arka uç adresleri; AI için sağlayıcı ve model bilgisi; MCP ve A2A için bağlanılan sunucu adı ve adresi gösterilir.

:::
