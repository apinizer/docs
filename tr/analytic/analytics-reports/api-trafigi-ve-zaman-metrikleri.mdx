:::info

Bir API Proxy birden fazla ortama yüklenebildiği için metrikleri de yüklendiği ortama göre değerlendirmek gerekir. Bu sebeple tüm analitik ekranlarında öncelikle ortam bilgisi seçilerek metrikler filtrelenir.

:::

:::warning

Elasticsearch entegrasyonu yapılandırılmamış ortamlar için metrik verileri görüntülenemez. Bu durumda ekranda uyarı mesajı gösterilir.

:::

## Metrikler Sayfası

Bu rapor **Metrikler** sayfasındaki **API Trafiği** sekmesidir (tam adı: **API Trafik Metrikleri**). Ekrana **Yönetim > Rapor > Metrikler** veya proje menüsünden **Rapor > Metrikler** ile ulaşabilirsiniz.

Metrikler sayfasında her rapor için bir sekme bulunur. Diğer trafik raporu **Trafik Eğilimi** sekmesidir; bkz. [Trafik (Zamana Göre)](/tr/analytic/analytics-reports/api-trafigi-zamana-gore).

## Filtreleme

**Metrikler** sayfasının üst kısmındaki filtre satırı tüm sekmeler ve alt-raporlar için ortaktır:

| Seçenek | Açıklama |
|---------|----------|
| **Ortam Seçimi** | Metrikleri görmek istediğiniz ortamı (environment) seçebilirsiniz |
| **Tarih Aralığı** | Metriklerinizi görmek istediğiniz zaman aralığını belirleyebilirsiniz (varsayılan: son 1 saat) |
| **Güncelle / Yenile** | Tarih aralığının yanındaki tek düğme. **Güncelle** (bekleyen değişiklik sayısı rozetiyle) filtre değişikliklerinizi uygular ve görüntülenen alt-raporu sorgular. **Yenile** alt-raporu uygulanmış filtrelerle yeniden sorgular |

**Proje** çipi (yalnızca Administration) ve raporda varsa **API Proxy** çipi, sekmelerin altındaki filtre kartında yer alır. Filtre kartının sağ ucundaki **Excel Export** düğmesi o an ekranda açık olan alt-raporun listesini indirir.

Düğmenin yanındaki **Choose Your Refresh Time** (varsayılan: Manual) otomatik yenilemeyi ayarlar; yalnızca seçili alt-raporu etkiler.

## Tablo Sütun Açıklamaları

Tablodaki sütunlar altı grup altında toplanır; her satır bir API Proxy'yi temsil eder.

### Bilgi

| Sütun | Açıklama |
|-------|----------|
| **Proje** | API Proxy'nin bağlı olduğu proje adı (sadece Admin menüsünde görünür) |
| **API Proxy** | API Proxy adı |

### Trafik Metrikleri (adet)

Seçilen ortam ve tarih aralığında, ilgili API Proxy'ye yapılan isteklerin sonuç durumuna göre sayısı:

| Sütun | Açıklama |
|-------|----------|
| **Başarılı** | Başarılı sonuçlanan istek sayısı |
| **Bloklanmış** | Politikalar tarafından (ör. güvenlik, rate limiting) bloklanan istek sayısı |
| **Hatalı** | Hata ile sonuçlanan istek sayısı |
| **Toplam** | Başarılı + Bloklanmış + Hatalı istek sayısı |

### Request Pipeline Time (ms)

İsteğin gateway'e ulaştıktan sonra backend'e yönlendirilmeden önce geçtiği istek (request) politikalarının işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Ort.** | Bu bölgede ölçülen ortalama süre (ms) |

### Routing Time (ms)

İsteğin backend'e gönderilip yanıtın geri alınmasına kadar geçen süre (backend gidiş-dönüş):

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Ort.** | Bu bölgede ölçülen ortalama süre (ms) |

### Response Pipeline Time (ms)

Backend'den dönen yanıtın istemciye iletilmeden önce geçtiği yanıt (response) politikalarının işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Ort.** | Bu bölgede ölçülen ortalama süre (ms) |

### Total Time (ms)

Request Pipeline + Routing + Response Pipeline toplamı; isteğin gateway'e ulaşmasından yanıtın istemciye dönmesine kadar geçen süre:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu API Proxy için ölçülen en kısa toplam süre (ms) |
| **Max.** | Bu API Proxy için ölçülen en uzun toplam süre (ms) |
| **Ort.** | Bu API Proxy için ölçülen ortalama toplam süre (ms) |
