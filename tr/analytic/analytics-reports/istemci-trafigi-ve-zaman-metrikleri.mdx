Bu rapor, **Metrikler** sayfasının **İstemciler** sekmesi altında **İstemci Trafik Metrikleri** alt-raporu olarak yer alır. Projedeki API çağrılarını yapan istemcileri (kullanıcı adı/kimlik bazında) satır satır listeler; her istemci satırı genişletilerek o istemcinin hangi API Proxy'leri, bu API Proxy'ler altında da hangi metot/endpoint'leri ne sıklıkla ve ne sürede kullandığı incelenebilir.

:::info

Bir API Proxy birden fazla ortama yüklenebildiği için metrikleri de yüklendiği ortama göre değerlendirmek gerekir. Bu sebeple tüm analitik ekranlarında öncelikle ortam bilgisi seçilerek metrikler filtrelenir.

:::

:::warning

Elasticsearch entegrasyonu yapılandırılmamış ortamlar için metrik verileri görüntülenemez. Bu durumda ekranda uyarı mesajı gösterilir.

:::

:::note

Kimlik doğrulama sırasında çözülebilen bir kullanıcı adı/anahtar olmadan gönderilen istekler **anonymous** olarak loglanır ve raporda tek bir `anonymous` satırında toplanır. (Bir politika -- örneğin rate limiting -- isteği kullanıcı kimliği henüz çözülmeden durdurursa istemci, o politikanın çözebildiği başka bir kimlik bilgisiyle gösterilir; `anonymous` yalnızca hiçbir kimlik çözülemediğinde kullanılır.) Kullanıcı adının yanında, ilgili istemcinin credential kaydında tanımlı bir organizasyon bilgisi varsa bu bilgi parantez içinde gösterilir (örn. `kullanici1 (ACME A.Ş.)`).

:::

## Filtreleme

**Metrikler** sayfasının üst kısmındaki filtre satırı tüm alt-raporlar için ortaktır:

| Seçenek | Açıklama |
|---------|----------|
| **Ortam Seçimi** | Metrikleri görmek istediğiniz ortamı (environment) seçebilirsiniz |
| **Proje Seçimi** | (Sadece Admin menüsünde) Birden fazla projeyi seçerek metrikleri filtreleyebilirsiniz |
| **Tarih Aralığı** | Metriklerinizi görmek istediğiniz zaman aralığını belirleyebilirsiniz (varsayılan: son 1 saat) |
| **Yenile Butonu** | O an görüntülenen raporu anında yeniden sorgulayıp verileri günceller |

Ayrıca alt-rapor satırında, o an görüntülenen raporun verisini dışa aktarmak için bir **Excel'e Aktar** butonu bulunur.

## Tablo Sütun Açıklamaları

Tablo, istemci bazında satırlardan oluşan üç seviyeli bir ağaç (tree table) yapısındadır; sütunlar altı grup altında toplanır.

### Bilgi

| Sütun | Açıklama |
|-------|----------|
| **İstemci (Kurumu)** | Ağaç yapısındaki satırın adı; değeri satırın seviyesine göre değişir (aşağıdaki "Satırları Genişletme" bölümüne bakınız) |
| **Proje** | (Sadece Admin menüsünde) Satırın ait olduğu proje adı -- yalnızca API Proxy seviyesindeki satırlarda dolu gelir, istemci ve metot/endpoint satırlarında boş görünür |

### Trafik Metrikleri (adet)

Seçilen ortam ve tarih aralığında, ilgili satıra ait isteklerin sonuç durumuna göre sayısı:

| Sütun | Açıklama |
|-------|----------|
| **Başarılı** | Başarılı sonuçlanan istek sayısı |
| **Bloklanmış** | Politikalar tarafından (ör. güvenlik, rate limiting) bloklanan istek sayısı |
| **Hatalı** | Hata ile sonuçlanan istek sayısı |
| **Toplam** | Başarılı + Bloklanmış + Hatalı istek sayısı |

### İstek Hattı Süreleri (ms)

İsteğin, gateway'e ulaştıktan sonra backend'e yönlendirilmeden önce üzerinden geçtiği istek (request) politikalarının işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Ort.** | Bu bölgede ölçülen ortalama süre (ms) |

### Routing Süreleri (ms)

İsteğin backend'e gönderilip yanıtın geri alınmasına kadar geçen süre (backend gidiş-dönüş süresi):

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Ort.** | Bu bölgede ölçülen ortalama süre (ms) |

### Yanıt Hattı Süreleri (ms)

Backend'den dönen yanıtın, istemciye iletilmeden önce üzerinden geçtiği yanıt (response) politikalarının işlenme süresi:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu bölgede ölçülen en kısa süre (ms) |
| **Max.** | Bu bölgede ölçülen en uzun süre (ms) |
| **Ort.** | Bu bölgede ölçülen ortalama süre (ms) |

### Toplam Süreler (ms)

İstek hattı + Routing + Yanıt hattı sürelerinin toplamı; isteğin gateway'e ulaşmasından yanıtın istemciye dönmesine kadar geçen toplam süre:

| Sütun | Açıklama |
|-------|----------|
| **Min.** | Bu satır için ölçülen en kısa toplam süre (ms) |
| **Max.** | Bu satır için ölçülen en uzun toplam süre (ms) |
| **Ort.** | Bu satır için ölçülen ortalama toplam süre (ms) |

## Satırları Genişletme: İstemci → API Proxy → Metot/Endpoint

Her satırın solundaki ok simgesine tıklanarak bir alt seviyeye inilebilir. Tablo üç seviyeden oluşur:

1. **İstemci satırı (1. seviye):** En üst seviyedeki satırlar, seçilen ortamda ve tarih aralığında istek gönderen her bir istemciyi (kullanıcı adı/kimlik, gerekirse organizasyon bilgisiyle) temsil eder. Sütun değerleri, o istemcinin **tüm** API Proxy'leri ve metotları için toplanmış metriklerdir.
2. **API Proxy satırı (2. seviye):** Bir istemci satırı genişletildiğinde, o istemcinin çağırdığı her API Proxy ayrı bir alt satır olarak listelenir. Sütun değerleri, o istemcinin **yalnızca o API Proxy'ye özel** metrikleridir. **Proje** sütunu yalnızca bu seviyede dolu gelir.
3. **Metot/Endpoint satırı (3. seviye):** Bir API Proxy satırı genişletildiğinde, o API Proxy altında istemci tarafından çağrılan her metot/endpoint ayrı bir alt satır olarak listelenir. Sütun değerleri, o istemcinin **yalnızca o metot/endpoint'e özel** metrikleridir.
