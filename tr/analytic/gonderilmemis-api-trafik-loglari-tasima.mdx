---
title: "Gönderilmemiş API Trafik Logları Taşıma"
description: "Failover konnektörde biriken API trafik loglarını esas konnektörlere taşıyabilirsiniz ve veri kaybını önleyebilirsiniz. Apinizer konfigürasyon veri tabanında biriken verileri esas konnektörlere taşıyabilirsiniz ve manuel olarak taşıma işlemini başlatabilirsiniz."
---


:::note

Bu ekran failover konnektör olarak **Apinizer konfigürasyon veri tabanı seçilmiş ise** Apinizer konfigürasyon veri tabanında biriken verileri esas gitmesi gereken konnektörlere taşımak için kullanılır.

:::

Bu işlem manuel olarak başlatılır ve eğer esas konnektörde hata alınırsa işlem veri kaybı olmayacak şekilde yarıda kesilir. Daha sonra yine bu ekrandan tekrar başlatılabilir.


API Trafik Logları gönderildikleri ortamda tanımlanan konnektöre gönderilemediğinde, eğer konnektör ayarında failover konnektör kullanılsın seçeneği aktifse, failover konnektöre gönderilir. Failover konnektöre gönderilen verilerin esas konnektör düzeltildikten sonra, esas konnektördeki hedefe taşınması ihtiyacı vardır.

    src="/images/yonetici/migrate.png"

  />

:::warning

Failover konnektör olarak **Apinizer konfigürasyon veri tabanı (MongoDB)** kullanıldığında, biriken loglar bu ekran üzerinden esas konnektörlere geri alınabilir. Ancak bu kayıtların gözden kaçırılması durumunda MongoDB, sistemi çökertecek kadar şişebilir ve tüm Apinizer platformu durabilir. Bu nedenle Apinizer konfigürasyon veri tabanının failover konnektör olarak kullanılması **tavsiye edilmemektedir**.

:::

:::info

**Alternatif:** Gönderilemeyen API trafik logları istenilen bir veritabanına yazılabilir. Hedef tabloların oluşturulması için [Apinizer Logları için Tablo Oluşturma Komutları](/tr/operations/yonetici-kilavuzlari/apinizer-log-tablolari-olusturma-komutlari) sayfasına bakabilirsiniz.

:::

:::info

Failover olarak Apinizer konfigürasyon veri tabanı yerine **ayrı bir MongoDB** kullanılıyorsa, biriken loglar Elasticsearch'e geri gönderilebilir. Detaylı bilgi için [Bash Script ile MongoDB'den Elasticsearch'e Log Yazma](/tr/operations/sorun-giderme/mongodb-loglarini-elasticsearch-yazma) sayfasına bakabilirsiniz.

:::
