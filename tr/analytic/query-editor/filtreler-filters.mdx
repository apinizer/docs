:::info

**Proje menüsü:** **Analitik → Sorgu Editorü → Filtreler** (`/custom-query-filter`)  
**Yönetim modu:** **Analitik → Sorgu Editorü → Filtreler** (`/admin/custom-query-filter`)  
Yeni filtre: listedeki **Oluştur**; düzenleme ekranında **Kaydet ve Yükle** ile kaydedilir. Kayıtlı filtrelerde **Denetim ve Geri Alma** sekmesi görünür.

:::

## Filtre Oluşturma

**Genel** sekmesinde ad, açıklama, proxy listesi, tarih aralığı, işlem sonuç tipi ve sıralama tanımlanır. Proxy tablosu boş bırakılırsa filtre tüm proxy'lere uygulanır.

## Konfigürasyon Alanları

| Alan | Açıklama |
| --- | --- |
| **Ad** | Filtrenin benzersiz adı. |
| **Açıklama** | İsteğe bağlı açıklama. |
| **Proxyler** | Filtrenin uygulanacağı API Proxy'ler. Tablo boşsa veya **Tüm Proxyler** satırı görünüyorsa kapsam tüm proxy'lerdir. **Ekle** ile proxy seçilir. |
| **Tarih Aralığı** | Filtrenin geçerli olduğu zaman penceresi (ör. son 30 dakika). |
| **İşlem Sonuç Tipi** | **Başarılı**, **Bloklanmış**, **Hatalı** — birden fazla seçilebilir. |
| **Sıralama** | Sonuç tablosunun sıralanacağı log alanları ve yön (artan/azalan). **Yeni Sıralama Oluştur** ile eklenir. |

:::
