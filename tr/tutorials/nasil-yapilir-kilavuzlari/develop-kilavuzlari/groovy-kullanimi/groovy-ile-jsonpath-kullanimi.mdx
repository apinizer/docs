Bir JSON mesajı içerisinden belirli alanların okunması gerektiğinde Groovy script içerisinde Apinizer'ın desteklediği [Jayway JsonPath](/tr/concepts/desteklenen-teknolojiler/desteklenen-kutuphaneler) kütüphanesi kullanılabilir. Script içerisinde `com.jayway.jsonpath.JsonPath` sınıfı import edilerek `JsonPath.read` metodu ile JsonPath ifadeleri çalıştırılabilir. JsonPath, request ve response hattındaki JSON gövde değişkenleri üzerinde kullanılabilir.

```groovy
import com.jayway.jsonpath.JsonPath

def orderId = JsonPath.read(requestBodyTextFromClient, '$.orderResponse.orderId')
requestHeaderMapToTargetAPI.put("orderId", orderId)
```

## Örnek Mesaj

Aşağıdaki örneklerde kullanılan JSON mesajı:

```json
{
  "orderResponse": {
    "orderId": "ORD-0000001",
    "orderType": "SAMPLE_ORDER_TYPE",
    "status": "COMPLETED",
    "customer": {
      "customerNumber": "CUST-0000001",
      "region": "SAMPLE-REGION"
    },
    "items": [
      {
        "productCode": "PRD-0000001",
        "quantity": 10,
        "active": true
      },
      {
        "productCode": "PRD-0000002",
        "quantity": 5,
        "active": false
      }
    ]
  }
}
```

## 1) `$` — Kök Eleman

- JsonPath ifadeleri `$` ile başlar.
- `$`, JSON belgesinin kökünü temsil eder.

```groovy
import com.jayway.jsonpath.JsonPath

def orderResponse = JsonPath.read(requestBodyTextFromClient, '$.orderResponse')

requestHeaderMapToTargetAPI.put("orderStatus", orderResponse.status)
// Çıktı: COMPLETED
```

## 2) `.` — Alt Eleman Erişimi

- Nokta operatörü, kökten itibaren iç içe alanlara erişmek için kullanılır.

```groovy
import com.jayway.jsonpath.JsonPath

def orderId = JsonPath.read(responseBodyTextFromTargetAPI, '$.orderResponse.orderId')

responseHeaderMapToClient.put("orderId", orderId)
// Çıktı: ORD-0000001
```

## 3) `*` — Joker Karakter

- Dizi veya nesne içindeki tüm eşleşen elemanları seçmek için kullanılır.

```groovy
import com.jayway.jsonpath.JsonPath

def productCodes = JsonPath.read(requestBodyTextFromClient, '$.orderResponse.items[*].productCode')

customVariableMap.put("productCodes", productCodes)
// Çıktı: [PRD-0000001, PRD-0000002]
```

## 4) `@` — Mevcut Düğüm

- Filtre ifadelerinde (`[?(...)]`) o an değerlendirilen dizi elemanını temsil eder.

```groovy
import com.jayway.jsonpath.JsonPath

def activeProductCode = JsonPath.read(responseBodyTextFromTargetAPI, '$.orderResponse.items[?(@.active == true)].productCode')

customVariableMap.put("activeProductCode", activeProductCode)
// Çıktı: [PRD-0000001]
```

## 5) Okunan Değerleri Custom Variable Olarak Kullanma

Okunan değerler `customVariableMap` içerisine eklenerek diğer politikalarda kullanılabilir:

```groovy
import com.jayway.jsonpath.JsonPath

def requestOrderId = JsonPath.read(requestBodyTextFromClient, '$.orderResponse.orderId')
def responseOrderId = JsonPath.read(responseBodyTextFromTargetAPI, '$.orderResponse.orderId')

customVariableMap.put("requestOrderId", requestOrderId)
customVariableMap.put("responseOrderId", responseOrderId)

// Çıktı:
// requestOrderId = ORD-0000001
// responseOrderId = ORD-0000001
```
